TeamCity CVE-2026-63077 未认证RCE 入KEV：构建服务器沦为供应链入口

CVSS 9.8 在野利用

JetBrains TeamCity On-Premises 的未认证反序列化 RCE（CWE-502）CVE-2026-63077 于 8 月 5 日纳入 CISA KEV，联邦大限 8 月 8 日。8 月 7 日 Rapid7 公开根因分析与 PoC，8 月 8 日 GitHub 出现批量利用工具。

漏洞机制：

  • 类型：Java 反序列化不受信任数据（XStream）
  • 根因：白名单未清 XStream 默认权限，Throwable/Map 整类可用
  • 利用链：异常类 → HSQL 数据源 → FreeMarker → 写 JSP webshell → SYSTEM 执行
  • 影响：早于 2026.1.3 / 2025.11.7 的所有 On-Premises 版本

值得关注的原因：

  • 构建服务器持源码、签名密钥、部署凭据，可投毒制品（类比 SolarWinds）
  • "披露即武器化"压至数日：7/27 披露 → 8/5 KEV → 8/7 PoC → 8/8 批量工具
  • 暴露过的实例应视为已沦陷，须审计 webroot 异常 JSP 与存储凭据
攻击者 伪agent注册 XStream反序列化 gadget链 写JSP SYSTEM RCE
2 严重

Progress Kemp LoadMaster CVE-2026-8037 预认证命令注入 入KEV

CISA KEV 8/7 · 大限 8/10

Progress Kemp LoadMaster（ADC / 负载均衡 / WAF）的未认证命令注入 RCE CVE-2026-8037 于 8 月 7 日纳入 KEV，联邦大限 8 月 10 日。攻击者在 API 凭据校验阶段即可注入任意 OS 命令。

根因：凭据转义函数遇引号重分配堆缓冲却未正确 null 终止，未终止字符串被拼入 system() 类命令，越界读相邻堆内容转化为命令注入（watchTowr 披露）。修复 GA 7.2.63.2 / LTS 7.2.54.18。

值得关注：LoadMaster 位于网络边界、终结 TLS、持内网信任连接，是比"又一台 Linux"更具战略价值的支点；边界固件缺陷成 2026 最长尾突破点，KEV 整改窗缩至 3 天。

3 高危

微软8月补丁星期二（8/11）预警：SharePoint链式RCE第二阶 + 内核提权

6 关键 · 约620+ CVE

微软 8 月补丁星期二定于 8 月 11 日，提前通告约 620+ CVE、6 个关键。最值得提前准备两项：

  • SharePoint 链式 RCE 第二阶补全：7 月 CVE-2026-55040（JWT 绕过 9.1）堵第一半，本月 RCE CVE 补第二半，零凭证即可从互联网打到代码执行；影响 SE/2019/2016。
  • Windows 内核本地提权：需紧急重启，低权代码即可提 SYSTEM。

值得关注：Storm-2603（Warlock）已猎杀本地 SharePoint；"补丁≠修复"——仍须轮换机器密钥并跑 PSConfig；MDASH AI 扫描致月度补丁量创新高。

UNC6671 语音钓鱼勒索华尔街：黑石、KKR、桥水等中招

Google TAG 8/7 报告

Google TAG 披露代号 UNC6671 的电话钓鱼勒索（Redact/Pink/Falcon/Helix 共享基础设施），过去一月瞄准黑石、KKR、Apollo、桥水、贝恩、TPG、CME、穆迪等；五周为 200+ 组织搭陷阱，用 72 个仿冒登录域，部分已付赎金（75万–300万美元）。

手法：致电个人手机冒充 IT 服务台 → 诱至 passkeyhelpdesk 伪造页 → AiTM 实时截 MFA → 拉取 M365/Okta 数据 → 威胁公开。

值得关注：最朴素手段击穿最贵防御，人因仍是最高杠杆攻击面；目标由科技/运输转向金融律所。
