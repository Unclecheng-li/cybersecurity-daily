1 严重

Ubiquiti UniFi 安全公告 067：22 漏洞一次性修复，三枚满分 10.0 无需认证即可接管设备（CVE-2026-77537/77550/77554）

CVSS 10.0 × 3 / CWE-20,93 网络可达·无需权限·边界/IoT

Ubiquiti 于 2026-08-26 发布 Security Advisory Bulletin 067，披露并修复 22 个漏洞（21 严重 + 1 高危），覆盖 UniFi Protect（视频监控）、UniFi OS、Talk（VoIP）、Access（门禁）、Network、Connect 等几乎整条产品线。其中 三枚达到 CVSS 10.0 满分且均为网络可达、无需权限、无需交互：CVE-2026-77537（Protect 命令注入，修复 7.2.105）、CVE-2026-77550（UniFi OS CRLF 注入致完整认证绕过，修复 5.1.37）、CVE-2026-77554（Talk 命令注入，修复 5.3.2）。Ubiquiti 称超 10 万 个 UniFi OS 实例可从公网看见，目前未确认在野，但今年早些时候同系满分漏洞曾在披露数周内被利用。

漏洞机制/攻击方式：

  • 类型：命令注入（CWE-20）+ CRLF 认证绕过（CWE-93）
  • 攻击方式：向暴露的 UniFi OS/Protect/Talk 发特制请求，绕过登录或注入 OS 命令
  • 影响范围：Cloud Key / NVR / Dream Machine / 网关等 UniFi OS 设备 + Protect/Talk 应用
  • 后果：接管管理控制台，控制网络、摄像头与门禁，建立持久驻留桥头堡

值得关注的原因：

  • UniFi 同时承载网络、视频与门禁，是"网络+物理安全"融合面，单点控制台沦陷即同时丢失多重控制权
  • 认证绕过（77550）+ 命令注入（77537/77554）可链式组合，把管理设备变成持久 foothold
  • 10 万+ 公网暴露 + 历史同类漏洞数周内被武器化，延迟修复即主动暴露；MSP 共享管理面放大跨客户影响
攻击者 公网暴露UniFi OS CRLF绕过认证 命令注入 设备沦陷
2 高危

CISA KEV 8/26 六漏洞批量入册：NetScaler 8452 与 SQL Server 2019-1068 为新晋，老漏洞长尾再被点名

CVSS 8.8–9.8 / KEV 在野 联邦大限 9/9（四项）

CISA 于 2026-08-26 一次性将 六个已遭利用漏洞纳入 KEV，覆盖 Citrix NetScaler、Microsoft SQL Server、Linux 内核、Ajax.NET 与 Red Hat：CVE-2026-8452（NetScaler ADC/Gateway 预认证堆溢出→root RCE，CISA CVSSv4 8.8 / watchTowr 9.8，公开 PoC）、CVE-2019-1068（SQL Server 低权 RCE）、CVE-2022-0995（Linux watch_queue 越界写本地提权）、CVE-2021-23758（Ajax.NET 反序列化）、CVE-2015-3246（Red Hat libuser，可结合 2015-3245 提权）+ CVE-2015-5287（ABRT 符号链接提权）。其中 NetScaler 8452 与 SQL 2019-1068 为真正新增；四项老漏洞为既有覆盖的"材料变更"——新增 KEV 身份 + 联邦大限 2026-09-09。

值得关注：KEV 入册即"已在野"官方背书；NetScaler 是边界、SQL 仅需低权，暴露面最高须优先盘点；四项 2015/2021/2022 老漏洞被重新点名，说明老内核/老 Web 组件 + 补丁绕过仍是长期被实际利用的长尾。

3 高危

Gitea CVE-2026-60004（CVSS 9.8）在野且联邦大限即今日：diffpatch 代码注入致服务账户 RCE，已观测挖矿

CVSS 9.8 / CWE-94 在野 · 大限 2026-08-28

CISA 于 2026-08-25 将 CVE-2026-60004 加入 KEV，联邦修复大限为今日 2026-08-28。该漏洞为 Gitea（自托管 Git 平台）代码注入：具备仓库写入权限者向 diffpatch API 提交恶意补丁，借仓库可控内容安装并执行恶意 Git hook，以 Gitea 服务账户运行任意 shell。影响 1.17–1.27.0，已在 1.27.1 修复（Shai Rod / NightRang3r 报告）。关键风险点是 默认开放注册——外部用户可自助注册、建仓拿到写权限，使攻击对未认证者同样可达。已有公开案例：某实例因开放注册被自动扫描器注册、建仓、RCE 容器内挖矿，宿主 CPU 长期 >70%。

值得关注：开发者基础设施成挖矿与供应链攻击首选靶点；默认开放注册把"需写权限"降格为完全未认证远程利用；挖矿只是早期载荷，同等访问可转向供应链篡改、凭据窃取与长期后门。

4 中高危

GitLab CVE-2026-18252（CVSS 8.7）：Duo Claude AI 代理误信用户可控配置，开发者角色可在 CI 执行任意命令

CVSS 8.7 / CWE-829 紧急补丁 8/26 · 未确认在野

GitLab 于 2026-08-26 发布紧急安全更新修复 CVE-2026-18252（GitLab 记 8.7，NVD 7.3）。受影响为 GitLab EE 18.9 至 19.1.6、19.2 至 19.2.4、19.3 之前：在部分条件下，具备 developer 角色权限的认证用户可因 Duo Claude AI 代理处理来自用户可控来源的配置（CWE-829 引入不可信控制域功能）而在 CI 上下文执行任意命令。修复版本 19.3.1 / 19.2.5 / 19.1.7（GitLab.com 与 Dedicated 已先行打补）。官方未确认在野，但 CI 处于软件供应链咽喉，自管理实例应立即升级。

值得关注：CI 是供应链 apex，CI 内命令执行等于可在构建产物投毒；AI 编码代理摄取用户可控配置是新型信任边界击穿，能驱动代理绕过代码审查；developer 角色即可触发，须收紧其对 CI 配置权限与隔离。

5 中高危

Storm-1175 借 N-central CVE-2026-18577 打供应链勒索：MSP"上帝模式"未认证接管，下游级联加密

CVE-2026-18577 / RMM StormEncryptor · 供应链勒索

Microsoft 威胁情报预警：与中国有关联、逐利的 Storm-1175 自 2026-08-02 起部署新勒索变种 StormEncryptor，疑似利用 CVE-2026-18577——N-able N-central（数千家 MSP 集中管理客户终端的 RMM 控制台）的认证绕过，是 CVE-2026-18556 的不完整补丁续作，被称未认证"上帝模式"：无需凭据即取得服务器完全管理员控制权。因 MSP 经 N-central 管理几十到上百客户端点，单点控制台沦陷即级联到全部下游客户（Kaseya/ConnectWise 先例）。N-able 于 8/2、8/6 连发两次紧急热修；Huntress 统计仍有超半数可达 N-central 云实例未打补。

值得关注：RMM/供应链式勒索反复出现，一次 MSP 失守 = 数十至上百家下游同步被加密；Storm-1175 从初始访问到全盘加密 < 24 小时且会早于披露用零日；漏洞多次被绕过补丁 + 半数云实例未修凸显"补丁≠修复"盲区。

速览区

6. TeamPCP 两名成员澳洲被捕（供应链投毒 Trivy，1000+ 组织）

澳联邦警察 8/27 在珀斯逮捕两名疑似 TeamPCP 成员，指控涵盖入侵、洗钱等；该组织专攻开源/CI 相邻工具投毒（含漏洞扫描器 Trivy），窃超 50 万凭据，目标涉 Mercor、LiteLLM、GitHub、OpenAI 乃至欧委会云，FBI 估计影响 1000+ 组织。

7. 美国查封中国背景 QTFY 僵尸网络域名（瞄准 NASA/参议院）

FBI 查封由中国背景组织 QTFY（南京新久维网络科技）运营的大型僵尸网络关键域名，该网络瞄准 NASA 与参议院等目标，C2 域名硬编码于恶意软件中，查封后网络与控制服务器瘫痪。

8. PostgreSQL CVE-2026-14669 公开 PoC（普通账号 RCE）

to_char() 的 TZ/TZtz 路径堆溢出（CWE-122），普通登录权限者用超长 POSIX 时区缩写即可触发，配合 ROP 以 postgres 系统账户执行任意命令；官方已在 14.24/15.19/16.15/17.11/18.5 修复，奇安信/360/比利时 CCB 已公开 PoC。

9. VMware vCenter CVE-2026-59310 在野延续（361 IP/47 国）

疑似中国背景 APT 借 vCenter 路径遍历（9.8）部署后门、反向 SSH 与 Babuk 衍生勒索，QUIRSO 评估其或为"清痕"而非目的；已攻陷 361 个独立 IP、横跨 47 国，互联网暴露的 vCenter 仍是高危面。

10. Microsoft 8 月补丁 421 CVE + Entra ID 69836（10.0 云身份）

Microsoft 8 月 Patch Tuesday 修复 421 个 CVE（含 1 已利用零日 + 3 披露零日）；最大关注点为 Entra ID CVE-2026-69836（CVSS 10.0 云身份层 RCE，被标记利用后微软又撤回其"在野"标识）——身份基础设施仍是攻防焦点。

11. 勒索 Week 34：物流供应链承压（海关经纪 + BitLocker LOLBin）

BlackNevas 勒索加拿大海关经纪商致跨境物流中断；另一起墨西哥物流 SME 遭原生 BitLocker 加密（Living-off-the-Land，规避 EDR 签名）锁定 5–6 台核心服务器，前期潜伏约三个月窃取云令牌与管理员凭据。
