1 严重

OPNsense 边界防火墙 Root RCE（CVE-2026-57155，CVSS 9.9）PoC 公开

CVSS 9.9 · CWE-22 / CWE-78 已修复（26.1.11 / 26.4.1p1）

研究人员 Jonas Ampferl（Hacking Cult）公开了 OPNsense 三枚漏洞的完整技术细节与可用 PoC，最严重的 CVE-2026-57155（CVSS 9.9）允许低权限账号升级为完整 root 远程代码执行。OPNsense 守护大量家庭与企业网络边界，防火墙 root 漏洞等于把整张网络边界交给攻击者，且公开 PoC 已让滥用门槛骤降。

漏洞机制/攻击方式：

  • 类型：权限提升 → 远程代码执行（CWE-22 路径穿越 / CWE-78 命令注入）
  • 攻击方式：GeoIP 别名导入器以 root 从用户提供的 URL 下载国家/IP 数据库，将 CSV 中 country_code 字段直接用作输出文件名且未净化，以 root 写任意路径；串联 newsyslog 定时任务实现 root 代码执行
  • 影响范围：OPNsense 26.1.10 及之前、26.4.1 及之前（社区/商业版均受影响），修复于 26.1.11 / 26.4.1p1
  • 后果：获防火墙 root shell → 接管边界、篡改路由/规则、作内网跳板

值得关注的原因：

  • 边界即命门：防火墙 root 沦陷=整张网络暴露，而非单点失守
  • "无害权限"变提权原语：Firewall: Alias: Edit 实为完整提权入口，印证最小权限配置重要性
  • PoC 公开=窗口骤缩：尚无在野但利用代码已释放，需立即升级并收紧相关权限
低权限账号 GeoIP别名导入 写入任意文件(root) newsyslog cron root RCE 边界沦陷

MCP 2026-07-28 无状态规范发布 + Akamai 揭示 5 类新攻击面

协议层重大转向 已发布待落地

MCP 于 2026-07-28 发布最大修订，正式转为无状态协议核心：移除握手与 Mcp-Session-Id、引入 Mcp-Method/Mcp-Name 强制头、强化 OAuth 2.1+PKCE。Akamai 指出其消除三类历史风险，但把安全边界责任转移到开发者实现，引入 5 类新攻击面。

CISA KEV 7/27 双漏洞在野：Arista VCO 10.0 + FortiOS 信息泄露

CVE-2026-16812 / CVE-2025-68686 已确认在野

Arista VeloCloud Orchestrator CVE-2026-16812（CVSS 10.0，OS 命令注入）已确认在野，7/27 入 KEV，联邦大限 7/30（仅 3 天）；VCO 5.2.3.14 / 6.1.3.4 / 6.4.2.4 / 7.0.0.1 已修。Fortinet FortiOS SSL-VPN CVE-2025-68686（CVSS 5.3，信息泄露）同为 7/27 入 KEV，大限 8/10，属后利用型漏洞。两者体现 BOD 26-04 风险分级——整改窗口按 composite 评分而非 CVSS。

4 中高危

Wazuh Manager NDJSON 注入（CVE-2026-56699，CVSS 10.0）操控 SIEM

暂无公开 PoC 已修复 5.0.0-beta3

Wazuh Manager 在 5.0.0-beta3 之前构造 OpenSearch bulk 请求时未转义 DataValue.index，已注册 agent 可注入任意 NDJSON 操作，以 Manager 管理员凭据执行，实现告警篡改、跨 agent SIEM 状态操纵。安全基础设施自身失守=蓝队眼睛被蒙，应先升 beta3 并收紧 agent 注册。

5 中高危

9Router AI 路由器 MCP 桥未授权 RCE（CVE-2026-46339，CVSS 10.0）

未授权 + 命令执行 已修复 0.4.37

9Router（AI 路由器/Token 节省器）在 0.4.30–0.4.37 的 src/proxy.js 未保护 /api/cli-tools/* 与 /api/mcp/*，允许未授权通过 cowork-settings 注册 customPlugins 并经 MCP 桥执行命令。AI 资产攻击面下沉到路由层，MCP 桥接成新型可执行入口。

速览区

6. Alibaba Fastjson CVE-2026-16723（CVSS 9.0）无补丁 RCE

Fastjson 1.2.68–1.2.83 无需交互/提权 RCE，仍无官方补丁，须启用 SafeMode 或切换不受影响构建。

7. JetBrains TeamCity RCE

CI/CD 平台需升级至 2025.11.7 / 2026.1.3，审查生产流水线的构建日志未授权访问痕迹。

8. Linux 内核 CVE-2026-53264 非特权提权

完整利用源码公开，需本地立足点 + 非特权 user namespaces，建议更新内核并酌情限制命名空间。

9. @fastify/http-proxy CVE-2026-16117（CVSS 10.0）前缀重写绕过

URL 编码未重写前缀可达 proxy 隐藏内部/管理端点，升级至 @fastify/http-proxy 11.6.0。
