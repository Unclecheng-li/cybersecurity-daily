1 严重

Zimbra 协作套件命令执行漏洞（CVE-2026-73570，CVSS 8.9）被波兰 CERT 确认为在野利用

CVSS 8.9 / CWE-78 在野 / 企业通信面

Zimbra 协作套件（ZCS）在启用了可选 zimbra-snmp 包且开启 SNMP 通知的部署中，未认证攻击者可通过特制请求触发操作系统命令执行。波兰 CERT 已发布在野利用预警，建议升级至 Zimbra Collaboration 10.1.20 或更高版本，并核查受影响 SNMP 功能是否启用。

漏洞机制/攻击方式：

  • 类型：OS 命令注入（CWE-78）
  • 攻击方式：向启用 SNMP 通知的 Zimbra 实例发送特制请求触发命令执行
  • 影响范围：启用 zimbra-snmp 且开启 SNMP 通知的 Zimbra 部署
  • 后果：获取邮件服务器权限，横向移动与通信数据窃取

值得关注的原因：

  • Zimbra 承载企业邮件与协作通信，常含大量敏感商业往来，是极具价值的初始入口
  • 利用无需认证、触发面为默认可能启用的 SNMP 组件，暴露实例风险陡增
  • 与 vCenter / SharePoint 等「管理平台被攻」趋势同频，集中管控面成首要靶心
未认证攻击者 特制请求 zimbra-snmp 命令注入 OS 命令执行 邮件服务器沦陷
2 严重

MLflow CVE-2026-64849（CVSS 9.3）未认证 SSRF 被用以窃取云凭证

CVSS 9.3 / CWE-918 披露即现利用尝试

MLflow（管理机器学习/AI 工作负载的开源平台）存在未认证服务端请求伪造（SSRF）缺陷，攻击者可借其访问内部服务与云元数据端点（169.254.169.254）。披露后短时间内即观测到扫描与利用尝试，建议升级至 3.15.0 或更高版本，并排查公网暴露的 MLflow 部署、轮换可能泄露的云凭证。

值得关注：云元数据服务常含临时凭证，暴露的 MLflow 直接成为云凭证窃取跳板；AI/ML 平台安全配置普遍薄弱，是 2026 年上升最快的攻击面之一，治理须前置到训练与推理平台。

3 严重

Gogs CVE-2026-52813（CVSS 10.0）满分 RCE，PoC 已公开

CVSS 10.0 / CWE-22 PoC 公开 / 自托管 Git

Gogs（轻量自托管 Git 服务）存在路径遍历漏洞，攻击者可通过在组织名中嵌入遍历序列经 Git hooks 实现远程代码执行。影响 Gogs < 0.14.3，已有公开 PoC。

值得关注：满分 CVSS + 公开 PoC + 自托管代码仓库，利用门槛极低；代码仓库是源码、CI 凭证与部署密钥的聚集地，沦陷即触发供应链级连锁风险。

4 高危

CI/CD 与 RMM 双重在野：TeamCity CVE-2026-63077（9.8）+ N-able N-central CVE-2026-18577

CVSS 9.8 / 认证绕过 在野 / 构建运维面

JetBrains TeamCity（本地部署）的 CVE-2026-63077（CVSS 9.8，不可信数据反序列化）已被确认在野利用——未认证攻击者访问 vulnerable 服务器即可绕过认证并以 TeamCity 服务进程权限执行任意系统命令。同期 N-able N-central 的认证绕过 CVE-2026-18577 也被在野利用，可获取远程管理权限并触达受管系统；首个不受影响版本为 2026.3.1.7（8 月 2 日发布），且初始补丁曾被指不完整，须核对实际安装版本而非仅确认「打过补丁」。

值得关注：二者均为「构建/运维管控平台」，沦陷可直接横向至源码、凭证、部署管道与生产基础设施；RMM 对海量终端具高特权控制，是最具性价比的横向妥协跳板。

5 高危

微软 Defender RoguePlanet 补丁绕过 CVE-2026-50656 —— 公开 PoC 可弹 SYSTEM shell

SYSTEM 权限 PoC 公开 / 端点防线

公开 PoC 展示了与微软 Defender 已知漏洞 RoguePlanet 相关的补丁绕过（CVE-2026-50656），成功利用可在受防护主机上以 SYSTEM 权限派生 shell。这延续了 8 月「ShieldBreak / RoguePlanet」端点绕过叙事线。

值得关注：EDR/Defender 是终端最后一道防线，能被本地绕过意味着检测与响应前提被削弱；公开 PoC + SYSTEM 权限组合，极易被勒索与后渗透工具链快速集成。

7. TrueConf Server CVE-2026-72529（Head Mare）

视频会议平台在野利用，联邦大限 8/23；会议基础设施成敏感通信拦截目标。

8. 9300+ 暴露 AWS 密钥仍有效

Truffle Security 研究显示，2022-2026 公开暴露于 GitHub 的 AWS 密钥仍有 9300+ 激活，其中 817 企业账户、526 为 root 级凭证。

9. 汽车中控首现恶意软件（DoFun/BADBOX）

Kaspersky 在车机固件内置更新器首次发现 Android 恶意软件，多阶段下载器部署反向代理模块用于广告欺诈与僵尸网络，归因 MoYu Group。

10. Check Point Security Management CVE-2026-16232 在野

认证绕过可令未认证远程攻击者获取应用登录令牌并以完全管理员权限认证，进而篡改安全策略——安全产品自身被攻。

11. macOS / SharePoint 在野延续

CVE-2026-65400 被用于投递门罗币挖矿程序；CVE-2026-55040 约 8500 个暴露实例仍处风险中，PoC 已公开。
