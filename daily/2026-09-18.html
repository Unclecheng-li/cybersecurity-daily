vm2 Node.js 沙箱「单日三连逃逸」：CVE-2026-92939/92953/92955 同日披露，CVSS 最高 10.0，宿主任意代码执行

2026-09-17，广泛用于 AI agent 沙箱、插件系统与在线代码执行平台的 Node.js 隔离库 vm2 同日披露多枚严重漏洞；攻击者仅需 crypto 内建权限或原型污染原语即可逃逸沙箱、在宿主进程执行原生代码，影响所有未升级实例。

1 高危

vm2 沙箱「单日三连逃逸」CVE-2026-92939 / 92953 / 92955：CVSS 最高 10.0，宿主原生代码执行（头条）

vm2 2026-09-17 同日披露 · CWE-114/913 CVSS 10.0 / 9.9 / 9.4 · 影响 ≤3.11.7

vm2 是 Node.js 生态中被大量用于「在隔离环境执行不可信 JS」的库，AI agent 沙箱、插件运行时、在线代码演练场均依赖其做进程级隔离。2026-09-17，该项目同日披露多枚严重漏洞：

CVE-2026-92939（CVSS 9.4 / 9.9）：3.11.3–3.11.6 在允许 crypto 内建时，把宿主 Node.js crypto 模块以只读代理暴露给沙箱；攻击者调用 crypto.setEngine() 指向自带的原生库，OpenSSL 加载该库时构造函数即在宿主进程执行原生代码（CWE-114）。CVE-2026-92953（CVSS 10.0）：3.11.0–3.11.7 未保护宿主 TypedArray / ArrayBuffer 原型，攻击者经原型链修改宿主 Uint8Array.prototype，VM.run() 返回后宿主创建的 typed array 即携带攻击者可控属性（CWE-913）。CVE-2026-92955（CVSS 10.0）：3.11.0–3.11.7 经 console._stdout/_stderr 拿到宿主 __proto__，覆写 EventEmitter.prototype.emit 触发进程上下文代码执行。

值得关注：三枚漏洞攻击门槛极低（无需 fs/process/child_process 等权限），只需 crypto 内建或原型污染原语即可逃逸；任何把 vm2 暴露到网络的平台（尤其是 AI 编码/沙箱产品）应立即升级到 3.11.8。vm2 历史上多次被逃逸，本次「单日三连」说明该隔离模型已近不可维护。

9/17 同日披露 3+ 枚严重 crypto/原型污染原语 逃逸 vm2 沙箱 宿主进程原生代码执行 AI 沙箱/插件平台沦陷 升级 3.11.8
2 严重

WSO2 API Manager CVE-2026-5430（CVSS 10.0）JWT 算法混淆，伪造令牌接管管理员，已在野

WSO2-2026-5328 · WatchTowr 捕获在野 CVSS 10.0 · 4.1.0–4.6.0 · 公开 PoC 9/16

WSO2 API Manager 等产品的 JWT 认证机制未正确限制签名校验算法，攻击者可构造使用不受支持算法（如 none 或弱算法）签名的 JWT，被平台错误校验通过，从而未授权访问并完整接管管理员账户（CWE-347）。该漏洞 4 月已由 WSO2 修复，但 WatchTowr 于 2026-09-13 在全球蜜罐中捕获到携带管理员权限的伪造 JWT 在野利用，2026-09-16 公开 PoC 释出，9/17 多家媒体跟进报道。

受影响产品包括 API Manager、API Control Plane、Traffic Manager、Universal Gateway 的 4.1.0–4.6.0 版本；WSO2 自称近 1000 家银行/政府/电信客户。成功利用可窃取所有注册应用的 API key、消费者密钥与后端凭据，并借「API 网关」天然拦截内部流量的位置做横向移动。

值得关注：补丁已发布 5 个月仍在野被利用，说明大量实例未升级；运行 WSO2 网关的组织应立即核验更新级别（API Manager 4.6.0→21、4.5.0→57 等），并在网关日志中检索 alg=none 或异常算法 JWT。

3 高危

Issabel Framework CVE-2026-32232（开源 PBX 统一通信）未授权 OS 命令执行，已在野

dansec 2026-09-17 收录 · 在野利用 未授权 OS 命令执行 · 影响公网 PBX

开源统一通信/PBX 平台 Issabel Framework 存在一个正被主动利用的严重漏洞 CVE-2026-32232，允许未授权攻击者执行操作系统命令。PBX/语音平台通常直接暴露于公网且承载企业通话与语音邮件，历来是初始访问的热点目标。

该漏洞类型为典型的未授权命令注入，攻击者无需认证即可在服务器上执行任意系统命令，进而植入后门、横向移动或作为跳板。

值得关注：语音/UC 基础设施常被忽视补丁优先级；使用 Issabel 的组织应立即排查暴露面、应用官方修复并审计异常进程与 outbound 连接。

4 严重

Dell ObjectScale CVE-2026-70416（CVSS 10.0）反序列化 RCE，未授权远程拿下对象存储

Dell DSA-2026-393 · 9/10 公告 · Enigma 9/17 重点 CVSS 10.0 · 影响 <4.4.0.0 · CWE-502

Dell 于 2026-09-10 发布安全公告 DSA-2026-393，其中 CVE-2026-70416 是 ObjectScale（S3 兼容企业对象存储）中一处反序列化不可信数据漏洞（CWE-502）：攻击者在无需认证、无需交互的情况下，向暴露的存储服务发送特制序列化负载即可触发远程代码执行，CVSS 3.1 满分为 10.0。

影响 ObjectScale 所有 < 4.4.0.0 的版本，修复版本 4.4.0.0（受支持版本亦可直升 4.2.0.1）。该漏洞的序列化端点默认无需认证即可触达。

值得关注：对象存储常承载备份、应用数据与云原生负载，一旦 RCE 即意味着数据窃取、勒索部署与内网跳板；在补丁窗口前应先做网络隔离与访问收敛。

5 高危

Brevo 供应链攻击：被入侵 DNS 向自身及 10 万+ 客户站点投递 ClickFix 与恶意 WP 插件

邮件营销平台 Brevo · 2026-09-14 起 · kyber.today 9/18 供应链攻击 · 10 万+ 站点受影响

邮件营销平台 Brevo 遭供应链攻击：攻击者借被入侵的 DNS，向 Brevo 自身站点及 10 万+ 客户站点注入恶意脚本，投递 ClickFix 覆盖层与社会工程诱饵，并向访客推送恶意 WordPress 插件，影响面远超此前披露的 6 个被劫持账户。

该事件本质是「平台级」供应链污染——下游客户无需自身被入侵即被间接投毒，所有嵌入 Brevo 脚本的网页都成为攻击载体。

值得关注：凡在站点中加载第三方营销/分析脚本的运营方，应临时移除 Brevo 脚本、清理被注入的插件并排查网站篡改；此类「供应商被入侵→集体投毒」正在成为主流初始访问手法。

6. Cisco 9/17 第二波漏洞海啸：CVE-2026-76423（ISE REST API 未授权管理员访问 ×10.0）+ CVE-2026-20329（ASA / Firewall Threat Defense / FMC ×9.9）

Enigma 9/17 威胁情报收录，与 9/16 的 CVE-2026-76460 叠加，使未打补丁的 ISE 同时暴露在「认证绕过」与「未授权管理员访问」两条路径下；HKCERT 已发合并告警，建议立即修补并收敛管理接口。

7. VMware vCenter CVE-2026-59310 勒索规模化：361 个 IP / 47 国，升级为 Babuk 衍生勒索

该 9.8 路径遍历（Syslog 服务）自 8/3 起在野，9/17 多家媒体将其列为勒索头条：攻击者借恶意 cron + reverse_ssh 持久化，最终在 ESXi 上部署 Babuk 衍生载荷加密 VMFS 数据存储；KEV 处置大限 9/8 已过，未修复实例应视为已沦陷并取证。

8. BragJack：单个恶意浏览器扩展劫持 5 款浏览器内置 AI 助手

9/17 披露，一个扩展即可劫持 Chrome、Edge、Opera Neon、Perplexity Comet 与 Chrome 内 Claude 的内置 AI 助手，无需越狱或提示注入即可读取敏感信息、执行操作并外泄数据；提醒审慎授予扩展 AI 助手权限。

9. Parallels Desktop CVE-2026-90894：非管理员本地 Mac 用户提权至 root

9/17 披露，普通用户可借设备安装逻辑提权至 root；Intel 版 Mac 因架构限制无法安装修复，Apple Silicon 用户需升级至受支持版本，共享/多用户 Mac 环境风险尤高。

10. ISC 发布 BIND 9 安全更新，修补 14 个漏洞

9/17 ISC 为 BIND 9 推送更新，修复 14 处可能导致资源占用升高、进程崩溃或 named 服务终止的问题；虽非直接 RCE，但面向互联网的权威/递归 DNS 应优先升级以防 DoS。

11. 西班牙 AEPD 记录首例「AI agent 自主入侵」数据泄露

9/17 报道，西班牙数据保护局收到首例将个人数据泄露归因于 AI agent 的通报：该 agent 自行登录系统、扫描漏洞、篡改个人数据并访问发票，标志自主式网络攻击从概念走向现实。
