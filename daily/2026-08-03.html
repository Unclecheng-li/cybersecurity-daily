CI/CD 与安全基础设施连遭满分漏洞：Wazuh GitHub Actions 命令注入 CVSS 10.0，Adobe Campaign 零点击 RCE 同日报出

1 严重

Wazuh GitHub Actions 命令注入 CVE-2026-67308（CVSS 10.0）：fork PR 窃取 GITHUB_TOKEN / AWS 凭据

Wazuh 工作流 < commit 44bf114 · 8/1 发布 CVSS 10.0 满分

Wazuh 工作流在 commit 44bf114 之前存在 GitHub Actions shell injection 漏洞（CVSS v3 10.0）。攻击者只需向运行脆弱工作流的仓库提交包含特制 VERSION.json 的 Pull Request，即可将 shell 元字符嵌入经环境变量直接插值进 run 步骤的上下文，在 runner 上执行任意命令，窃取 GITHUB_TOKEN、AWS 凭据等敏感密钥——自托管 runner 影响尤甚。CVE 于 2026-08-01 正式发布，暂无公开 PoC（Tenable 同时给出 v4 评分 5.3，口径差异显著）。

漏洞机制/攻击方式：

  • 类型：命令注入（CWE-78）+ CI/CD 供应链
  • 攻击方式：①fork PR 提交含 shell 元字符的 VERSION.json；②工作流读取并直接插值进环境变量；③run 步骤执行任意命令；④窃取令牌 → 仓库接管/云环境横向
  • 影响范围：所有运行脆弱 Wazuh 工作流、接受外部 PR 且用自托管 runner 的仓库
  • 后果：GITHUB_TOKEN/AWS 凭据泄露、仓库接管、runner 宿主机沦陷

值得关注的原因：

  • 继 7/25 Wazuh Manager NDJSON 注入（CVE-2026-56699，10.0）后第二枚满分，安全基础设施自身失守延续
  • 攻击面落在 pull_request 路径，外部贡献者即可触发，投毒门槛极低
  • 窃取令牌可直击类 SolarWinds 供应链场景
  • 缓解仅升级工作流，但存量 fork 与自托管 runner 清理常被忽视
fork PR 提交 恶意VERSION.json 环境变量插值 任意命令执行 令牌/仓库沦陷

Adobe Campaign Classic CVE-2026-48449（CVSS 10.0）：企业营销平台零点击 RCE

CVE-2026-48449 · 错误授权 零点击 · 无认证

Adobe 于 2026-08-01 紧急修复影响 Campaign Classic v7 的满分漏洞 CVE-2026-48449（错误授权 / Incorrect Authorization）。攻击者无需认证、无需用户交互（Zero-click），仅需发送精心构造的请求即可在目标系统执行任意代码；修复版本为 7.4.3 build 9398（Windows/Linux）。同期 CVE-2026-48448（CVSS 8.6）SQL 注入可致任意文件读取，Adobe Bridge 另有 8 个关键漏洞。

3 严重

Kubernetes bank-vaults vault-secrets-webhook CVE-2026-54725（CVSS 9.6）：SSRF + SA 令牌窃取

CVE-2026-54725 · < 1.23.1 公开 PoC · 9.6

bank-vaults/vault-secrets-webhook 在 1.23.1 之前存在 SSRF 与 ServiceAccount 令牌窃取（CVSS 9.6，已有公开利用）。攻击者通过 vault-addr 注解在准入 webhook 处理时触发 SSRF，向攻击者控制 URL 发起出站请求；vault-serviceaccount 注解则经 TokenRequest API 实现集群级 SA 令牌窃取。任意 Pod 准入请求即可触发，攻击复杂度低。

4 事件

泰国证券存管 TSD 投资者门户越权泄露 20 万投资者信息

Broken Access Control / IDOR 8/2 披露 · 约 20 万人

泰国证券交易所（SET）旗下泰国证券存管公司（TSD）于 2026-08-02 披露，其 Investor Portal 发生未授权访问，约 20 万名投资者个人信息外泄（占 500 万条股东资料约 4%）。公司 7/25 晚间发现异常、次日确认。根因为网站代码缺陷：攻击者用已登录账户，通过修改 URL 中用户 ID 等参数即可绕过权限验证读取他人数据（典型 IDOR）。泄露含姓名、出生日期、身份证号、住址、电话、邮箱及券商/交易账户名；持股记录、交易历史与密码等核心敏感信息未流出，暂无资金损失。

值得关注：关键金融基础设施因基础越权缺陷泄露，属"低技术高影响"典型；身份证号等不可逆 PII 后续钓鱼/诈骗风险高；与近期金融定向勒索（德意志银行、PSBank、巴罗达）共同指向金融机构暴露面升温。

5 高危

WooCommerce Social Login CVE-2026-8457（CVSS 9.8）：Apple JWT 伪造管理员认证绕过

CVE-2026-8457 · ≤ 2.8.7 无需认证 · 9.8

WooCommerce Social Login 插件（≤ 2.8.7）的 Apple 登录处理器接受 Apple id_token 后仅 base64 解码 payload，未校验 JWT 签名。攻击者可伪造 Apple 登录令牌，以任意用户（含管理员）身份登录，无需认证、利用极简。已有可用 exploit，预计针对安装该插件的 WordPress 站点发生大规模利用。

值得关注："只解码不验签"是 JWT 实现经典低级错误，但危害满分级身份绕过；WordPress + 电商插件覆盖面极广，伪造令牌即拿管理员 = 站点完全接管；临时缓解：立即禁用 Apple 社交登录并更新。

速览区

6. Cisco Secure FMC 硬编码密码 CVE-2026-20316 入 KEV（大限 8/1）

Cisco Secure Firewall Management Center 含硬编码密码，CISA 7/29 确认在野并加入 KEV，联邦整改大限恰为 8/1；边界管理平面沦陷 = 全网策略失守。

7. FreeRDP CVE-2026-67289（CVSS 9.8）HTTP 代理头注入

恶意/被控 RDP 服务器借重定向 TargetNetAddress 字段 CRLF 未过滤，向客户端经 HTTP 代理的 CONNECT 请求行注入任意头/请求；影响 < 3.29.0（接 8/2 CVE-2026-44421 客户端 RCE 系）。

8. Arch Linux 冻结 AUR 采纳 · Rust infostealer 经 Tor 第三波

继 6 月防御后第三波恶意提交绕过检测，Rust 载荷跨编译 + Tor C2 抗溯源；AUR 采纳流程史无前例冻结，开源信任模型被系统性利用。

9. Coldcard 硬件钱包固件缺陷致 $70M BTC 41 分钟失窃

2021-03 集成错误将种子生成路由到确定性软件 PRNG，熵降至低至 40 bit；攻击者 7/30 在 41 分钟内扫空 1,196 个地址、窃取 1,082.65 BTC（约 $70.2M），五年后才被利用。
