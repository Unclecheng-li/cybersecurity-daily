SonicWall SMA1000 双零日链 CVE-2026-83548(10.0)+83549：未授权RCE在野

CVE-2026-83548(10.0) SSRF 作跳板 + CVE-2026-83549(7.8) 命令注入收口 → 未授权 RCE；影响 6210/7210/8200v，SonicWall 确认在野，立即升级固件 + 重置凭据

1 严重

SonicWall SMA1000 双零日链 → 未授权 RCE 在野（CVE-2026-83548 CVSS 10.0 + CVE-2026-83549 CVSS 7.8）

CVSS 10.0/7.8 · CWE-918/78 在野利用 · KEV 9/2

SonicWall SMA1000 系列远程访问设备存在两个可链式利用的零日：面向用户的 Work Place 接口 SSRF（CVE-2026-83548，10.0）可作为前置支点读取内部功能并发起伪造请求；设备管理控制台的 OS 命令注入（CVE-2026-83549，7.8）以管理员身份执行任意系统命令。两者组合即实现全程未授权远程代码执行。SonicWall 已确认在野利用，受影响的 6210 / 7210 / 8200v 运行 12.4.3-03453 与 12.5.0-02835 及更早版本需立即升级固件、排查 IOC、必要时重装系统并重置全部凭据。目前暂无公开 PoC。

漏洞机制/攻击方式：

  • 类型：SSRF（CWE-918）+ OS 命令注入（CWE-78）链式 RCE
  • 攻击方式：SSRF 打穿边界拿到内部请求面，再借管理控制台命令注入以 SYSTEM/管理员执行
  • 影响范围：SMA1000 6210 / 7210 / 8200v，固件 ≤ 12.4.3-03453 与 12.5.0-02835
  • 后果：设备完全沦陷，成为内网横向移动与持久化支点

值得关注的原因：

  • 满分 SSRF 作跳板、命令注入收口，是教科书级"边界设备拿下即内网支点"
  • 互联网暴露的 VPN/远程访问设备长期是 APT 与勒索首选入口，重镜像 + 重置凭据才能清零
  • 与 CISA KEV 七漏洞同批在野，9 月初边界/网关类资产正被集中猎杀

2 高危

n8n 双周安全公告集群（9/2）—— AI 自动化平台 18 条通告含两枚 RCE

CVSS 8.7/7.7 · CWE-94 9/2 披露 · v2.37.7 修复

n8n 于 9/2 发布双周安全更新，一次性披露 18 条安全通告，其中两枚"高危"可直达代码执行：表达式沙箱逃逸（GHSA-hw8v-xxg5-vvvx，类字段消毒器重绑定）与共享内建篡改 + 代码打印机注入（GHSA-6xcw-7xm6-48c6）。对应 CVE 含 CVE-2026-85169（8.7 沙箱逃逸 RCE）、CVE-2026-85168（7.7 Git 节点 RCE）、CVE-2026-85166（7.2 凭据外泄）等。修复版本：v1.123.76 / v2.37.7（stable）/ v2.38.2（beta）。

n8n 是 AI Agent / 工作流自动化最流行的开源平台之一，常挂着模型密钥、云凭据与内部 API；沙箱逃逸类漏洞"修一个冒一个"，本期同时修多枚同类缺陷说明历史绕过仍在累积。自托管实例应视作准生产资产，尽快升级。

3 严重

Kestra OSS 未授权 OS 命令注入（CVE-2026-49869，CVSS 10.0）—— 工作流引擎后门，KEV 关联 Qilin 勒索

CVSS 10.0 · CWE-78 KEV 9/2 · 9/5 大限

开源工作流引擎 Kestra OSS 未授权 OS 命令注入，远程无认证攻击者可创建并执行任意工作流。已被纳入 CISA KEV（9/2 加入，FCEB 限 9/5 前修复）。微软溯源到 2026 年 6 月下旬入侵：攻击者开 reverse shell、探查 Docker 容器、部署 XMRig 矿机并借 Kestra 自带 KV 接口收割数据；Wiz 将该利用链关联至 Qilin（Agenda）勒索组织。

满分 + 未授权 + 编排中枢三位一体，等于"拿到编排层即拿到所有下游系统"；已明确与勒索挂钩，不再是纯研究 PoC。

4 高危

BerriAI LiteLLM MCP 端点认证绕过（CVE-2026-59822，CVSS 8.8）—— AI 网关全量密钥泄露

CVSS 8.8 · CWE-287 KEV 9/2 · 9/16 大限

流行 AI 网关 LiteLLM 的 MCP Streamable HTTP 端点认证缺陷，未认证攻击者可用任意 Bearer Token 建立会话。Wiz 观测到蜜罐中被针对性探测模型枚举端点；微软+Wiz 联合评估将 LiteLLM、Flowise、LangChain、Langflow、ChromaDB、Ollama、Marimo、MCP Server 等列为活跃目标——偷上游 Provider API Key、改 authorized_keys 持久化、部署 XMRig。

AI 网关集中托管大量高价值密钥，"认证绕过即全量密钥泄露"；与 CVE-2026-42271（8.7）可链式组合实现 RCE。

5 高危

All-in-One WP Migration 二阶 SQL 注入 → RCE（CVE-2026-19949，CVSS 8.8）—— 300 万+ 站点

CVSS 8.8 · CWE-89 9/3 告警 · 未授权 RCE

超 300 万站点使用的 WordPress 迁移/备份插件 All-in-One WP Migration and Backup 存在二阶 SQL 注入（归档恢复功能转义不足、预编译缺失），可导致未授权 RCE。Defiant（Wordfence）于 9/3 发出告警。

安装基数极大，"一个插件沦陷一片站"；二阶注入 + 恢复流程组合使利用路径隐蔽。站点运营方应立即更新插件并审计近期异常恢复/上传行为。

速览区

6. Sangoma Switchvox 未授权 SQLi → RCE 反向 shell（CVE-2026-9586，9.3，KEV）

企业 VoIP 管理平台未认证 SQL 注入可直达 RCE，Horizon3.ai 观测多数暴露实例已被打或即将被扫；与 CVE-2026-42271 链可全 RCE。

7. Avast "PrettyPrague" 提权零日公开 PoC（MSNightmare / Chaotic Eclipse）

滥用 Avast 沙箱组件 dump Windows SAM 并起 SYSTEM shell，完全补丁的 Avast + Win11 25H2 仍中招，无 CVE、无官方补丁；GenDigital 系 AVG/Norton 或同架构受累。

8. GitSpawn：恶意 .git/config 控制 7 款 AI 编码代理执行代码

Manifold Security 披露 8 个缺陷（goose/Codex/Cursor/Claude Code/Hermes/Qwen/Grok Build），经 core.fsmonitor 在信任提示前于沙箱外以用户权限执行仓库自带命令；Hermes/Qwen/Grok Build 及 Claude Code ultrareview 路径仍未修。

9. IXON VPN Client CRLF 注入 → root/SYSTEM RCE（CVE-2026-75925，9.6，CISA ICS 9/3）

本地服务接受的配置值未中和换行符，可注入指令以 root/SYSTEM 执行并持久化；建议升级至 1.4.7+。

10. Cisco IOS XR / Nexus 严重 RCE + 认证绕过；安全邮件 S/MIME 未补漏洞

思科就 IOS XR 与 Nexus 的 RCE/认证绕过发布修复（9/3），并警告安全邮件产品中尚未修补的 S/MIME 缺陷。

11. Dropbox ~5,000 账户经联想邮箱验证缺陷被控 + 曼彻斯特机场集团 86GB 勒索泄露

攻击者仅用邮箱即可借 Lenovo ID 验证缺陷注册伪造身份登录 Dropbox（8/4–8/21，约 1/3 下载文件）；FulcrumSec 声称窃取曼城/斯坦斯特德/东米德兰兹机场 86GB 客户数据。
