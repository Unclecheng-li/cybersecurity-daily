Linux 内核 Open vSwitch 本地提权 CVE-2026-64531：PoC 公开，云/容器主机 root 沦陷

CVSS 7.8（本地提权）· CWE-190 整数溢出 PoC公开·修 5.15.212/6.6.145+

安全研究员 Asim Manizada 于 7/29 公开披露 Linux 内核 Open vSwitch（OVS）组件本地权限提升漏洞 CVE-2026-64531 并利用细节与 PoC。该漏洞允许无特权本地用户在受影响 Linux 系统上稳定获取 root 权限，影响 AlmaLinux、Ubuntu、Debian、Fedora、Rocky、Amazon Linux 2023 等主流发行版。由于 OVS 作为可加载模块存在于绝大多数 Linux 发行版，攻击面远超专用网络主机，对云环境与容器平台构成直接威胁（NVD 尚未给出最终评分，研究者按本地提权评高危）。

漏洞机制/攻击方式：

  • 类型：整数溢出（CWE-190）→ 内核内存越界读写 → 凭据重写提权
  • 攻击方式：OVS 数据路径处理嵌套 Netlink 属性时存在整数溢出；2025 年 3 月变更移除 32KB 总操作流上限，攻击者可构造含大量 conntrack 的 CLONE 操作使长度字段 16 位回绕为极小值，后续代码信任该回绕长度越界解析，构建内核读取与定向递减，重写主机进程凭据
  • 影响范围：任何接受 2025 年 3 月变更的预修复内核；上游修复合入 5.15.212 / 6.1.178 / 6.6.145 / 6.12.97 / 6.18.40 / 7.1.5；仅需 CAP_NET_ADMIN + 可控命名空间
  • 后果：稳定可靠的本地提权（无需内存整理），云主机/容器宿主一旦被低权限落脚点即可提至 root

值得关注的原因：

  • 利用代码已公开、约 800 个内核构建记录佐证，云/容器平台默认暴露 OVS，提权原语价值极高
  • 无需 OVS 网桥或主机级管理员权限，默认启用非特权用户命名空间的系统上普通用户即可触发
  • 立即动作：安装含修复的内核更新，并评估收紧非特权命名空间
普通用户·命名空间+CAP_NET_ADMIN 构造CLONE+conntrack操作 16位长度回绕极小值 内核越界解析 读取+定向递减 重写进程凭据 获取root·宿主沦陷

Windows 事件日志服务 RCE CVE-2026-50502：PoC 公开，CVE-2025-29969 变体复活

CVSS 8.0 · CWE-20 · MS-EVEN RPC PoC公开·7/14已修

研究员 Pixis 于 7/30 公开 CVE-2026-50502 的完整技术细节与概念验证代码。该漏洞位于 Windows 事件日志服务（\pipe\eventlog 命名管道，ElfrOpenBELW / ElfrBackupELFW），CVSS 8.0，影响 Windows 10/11 及 Server 2012+ 所有受支持版本。攻击者可利用窃取的低权限凭据实现远程代码执行，无需交互式或远程会话。微软已于 7/14 安全更新修复，但 PoC 刚公开，缓解窗口重新收紧。

ShinyHunters 认领安永（EY）数据泄露，今日（7/31）到期公开数据

供应链攻击 · 凭证窃取 · 多云横向 今日大限·公开预警

ShinyHunters 将安永列入其泄露站点，声称通过供应链攻击获取登录凭证，得以访问其 Jira 项目管理、GitHub 代码托管与 Azure 云环境，并窃取大量内部凭证与客户数据；设定最后期限：若安永不主动联系，7/31 之后所有数据将被公开。安永此前仅确认第三方技术支持工单系统于 3/28–4/12 遭入侵、4/23 才发现异常，涉及客户姓名、地址、社安号、财务账户等税务申报信息。

CareCloud 超 34.5 万患者病历泄露：医疗云服务商被入侵 6 天

医疗数据泄露 · AWS 托管数据库 34.5万+PII/金融/健康

美国医疗 IT 服务商 CareCloud 本周向多州总检察长办公室提交披露文件，确认至少 34.5 万人的姓名、地址、社安号，以及护照、驾照、银行账户、支付卡号、大量健康档案在攻击中被窃。攻击者于 3/10–3/16 对其托管在 AWS 上的病人数据库拥有至少 6 天访问窗口；CareCloud 为全美超 4.5 万家医疗机构保存病历，迄今无勒索组织认领。

5 中高危

印度第二大国有银行 Bank of Baroda 1TB 数据外泄

员工邮箱失窃 · 内部文档外传 Triple X认领·9.2万文件

印度第二大国有银行 Bank of Baroda 7/29 公告称一名员工邮箱账号遭入侵导致部分数据泄露，银行直至黑客在暗网公开数据后才确认。勒索组织 Triple X 声称已收到约 1TB 机密数据、9.2 万份文件，含分行审计、贷款评估、监管调查、客户开户申请及 PII；核心银行系统未受影响。与 Tata Electronics 6 月底被攻形成印度关键产业连环泄露趋势。

7. Microsoft 8 月 Patch Tuesday 83 CVE 无活跃零日

微软发布 83 枚修复，逾半为权限提升；6 枚更易被利用，含 Excel 信息泄露（CVE-2026-26144，可驱动 Copilot Agent 零点击泄露）与 Office 预览窗格 RCE（CVE-2026-26110/26113，CVSS 8.4）。为半年来首个无活跃在野零日。

8. CISA KEV 持续扩充：ColdFusion / Joomla / SharePoint

近期新增 Adobe ColdFusion 路径遍历 RCE CVE-2026-48282（7/10 大限）、JoomShaper SP Page Builder 任意上传 CVE-2026-48908、Langflow 授权绕过 CVE-2026-55255、JoomlaCK 越权 CVE-2026-56290；SharePoint CVE-2026-50522（9.8）亦确认在野。

9. BlueNoroff 伪造 Zoom/Teams 钓加密货币 + BlueDash
