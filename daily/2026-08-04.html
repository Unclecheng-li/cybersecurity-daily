Rails Active Storage CVE-2026-66066 预认证 RCE

CVSS 9.5 Pre-auth RCE

Ruby on Rails 内置文件上传组件 Active Storage 被曝严重漏洞 CVE-2026-66066（CVSS 9.5，攻击链代号「KindaRails2Shell」）。当应用以 libvips（自 Rails 7.0 起默认图像处理器）处理用户上传图像、且允许未信任用户上传时，攻击者上传特制文件即可触发 libvips 中标记为「未模糊/不可信」的操作，读取 Rails 进程可访问的任意文件。

漏洞机制：

  • 类型：libvips 不安全操作 + 任意文件读取
  • 攻击方式：未认证上传特制图像，窃取进程环境变量
  • 核心战利品：secret_key_base、数据库与云存储凭据
  • 后果：伪造会话/全局ID → ImageProcessing 变体 RCE，完全接管服务器

值得关注的原因：

  • 预认证 + 默认处理器 = 海量 Rails 应用暴露面
  • 公开 PoC 与 Metasploit 模块已可用，无需 Marshal 反序列化
  • 补丁后必须轮换 secret_key_base 等密钥，否则凭据持续可利用
特制图像 libvips危险操作 读取密钥 伪造会话 RCE执行
2 严重

N-able N-central CVE-2026-18577 认证绕过入 KEV

KEV 8/3 · 大限 8/6 MSP级联

N-able N-central（RMM/监控平台）存在认证绕过漏洞 CVE-2026-18577（CWE-288），可未认证接管账户。该漏洞是 CVE-2026-18556 修复不完整的结果——此前补丁未封堵全部替代路径。CISA 于 8/3 加入 KEV，联邦整改大限仅 3 天（8/6）。

值得关注：

  • 「补丁后绕过」再现（接 Redis 双重释放、Cisco SD-WAN）
  • MSP 平台沦陷 = 下游成百上千客户网络级联失守
  • 认证绕过可绕过账号级 MFA，须依赖网络层控制
3 高危

macOS CUPS cupsd CVE-2026-39875 本地提权

CVSS 7.8 PoC公开

Apple 于 7 月底安全更新修复 macOS 打印子系统 cupsd 特权守护进程中的本地提权漏洞 CVE-2026-39875（CVSS 7.8）。研究员 Dallas Dubs 已公开完整细节与可用 PoC。

攻击链：

  • 未特权用户注册指向可控监听器的打印机
  • cupsd 错误泄露受信任认证令牌给该监听器
  • 重放令牌定位任意路径，以 root 写入可控内容
  • 全程无需用户交互
4 高危

LiteLLM Proxy CVE-2026-42203 SSTI 泄密钥

CVSS 8.6 GHSA-xqmj

热门 LLM 网关 LiteLLM Proxy 在 1.80.5–1.83.6 存在服务端模板注入（SSTI）RCE CVE-2026-42203（CVSS 8.6）。持有合法代理 API Key 的已认证用户向 POST /prompts/test 提交恶意模板即可读出提供商 API Key、数据库凭据，并在特定部署下于宿主执行命令。修复版本 1.83.7。

AI 中间件网关集中托管所有模型厂商密钥，「一处失守 = 全线密钥泄露」，接 Flowise/Orkes/bank-vaults 同类趋势。

5 事件

安进（Amgen）第三方云存储泄露 PHI

PHI泄露 · 7/31披露 重大事件

生物制药巨头安进（Amgen）于 7/31 披露重大数据安全事件：由第三方服务商运营的云存储系统遭入侵，大量企业内部资料与患者健康信息（PHI）被盗。公司 7/29 完成综合评估，已启动隔离管控并聘独立取证团队溯源。

暴露面落在第三方云存储，延续供应链/外包信任边界失守主线；医疗健康行业已成攻击重灾区（雅培、CloverHealth、诺和诺德等接连中招）。

6. Radia Inc. 遭 CHAOS 勒索（655GB）

华盛顿州大型医师自有放射科集团 Radia 被 CHAOS 团伙宣称窃取 655GB 数据，含患者 PHI（姓名/SSN/病历/影像/账单）、企业财务与 HR 记录；截至 8/1 尚未见监管报备。

7. Linux 内核 Copy Fail CVE-2026-31431 PoC

加密子系统 algif_aead 自 2017 年潜伏的 9 年提权缺陷，732 字节脚本篡改页缓存中 /usr/bin/su 映像直取 root；影响 Ubuntu 24.04、Amazon Linux 2023、RHEL 10.1、SUSE 16。

8. Cisco FMC CVE-2026-20316 KEV 大限（8/1）已过

Cisco Secure Firewall Management Center 含硬编码密码（CWE-259），未认证远程以低权账户登录读敏感数据；联邦整改大限 8/1 到期，未修设备即视为已沦陷。

9. FreeRDP CVE-2026-44421/67289 客户端 RCE

恶意/被控 RDP 服务器经通道数据流或 HTTP 代理 TargetNetAddress CRLF 注入，在连接方客户端执行代码；远程桌面客户端成反向执行入口，影响 3.x 系列。
