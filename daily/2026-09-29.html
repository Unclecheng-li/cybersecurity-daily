1 头条事件

Apple CoreGraphics 零日 CVE-2026-86950：处理恶意文件即 RCE，已确认在野（头条）

Apple 安全公告（support.apple.com/149226 等）· 影响 iOS<26.7.1 / iPadOS<26.7.1 / macOS Sequoia<15.8.1 / Tahoe<26.7.1 CVE-2026-86950 CVSS 8.8 · CoreGraphics OOB 写 · 已确认在野

2026-09-28/29，Apple 发布 iOS 26.7.1 / iPadOS 26.7.1、macOS Sequoia 15.8.1、macOS Tahoe 26.7.1 紧急安全更新，修复 CoreGraphics 一处越界写入漏洞（CVE-2026-86950，CWE-787）。Apple 在公告中明确："已知该问题可能已在针对特定个人的极复杂攻击中被利用（iOS 27 之前版本）"。HKCERT 将其评为高风险，CVE.org 与 CVE Brief 均已收录，且 GitHub 上已出现公开 PoC 仓库。

漏洞机制/攻击方式：

  • 类型：内存破坏（Out-of-bounds Write，CWE-787）
  • 攻击方式：处理特制恶意文件（图片等）触发越界写，导致任意代码执行；无需认证，仅需用户打开文件（UI:R）
  • 影响范围：iPhone / iPad / Mac 用户，iOS<26.7.1、iPadOS<26.7.1、macOS Sequoia<15.8.1、Tahoe<26.7.1
  • 后果：设备完全沦陷，可执行任意代码、窃取数据

值得关注的原因：

  • 消费级设备零日进入"在野 + 公开 PoC"阶段，攻击门槛快速降低，从定向攻击扩散为可规模化利用
  • Apple 罕见用"极其复杂攻击针对特定个人"措辞，暗示可能具定向 APT / 商业间谍性质
  • 企业应通过 MDM 批量推送 26.7.1 / 15.8.1，并核查受管设备上的异常进程与崩溃日志
2 公开 PoC

Apache Roller CVE-2026-82384（×9.8）XML-RPC 未认证反序列化 RCE，PoC 已公开

Apache Roller 6.1.5 · 修复 6.1.6 · CWE-502 CVE-2026-82384 CVSS 9.8 · 未认证 RCE · 公开 PoC

2026-09-28 披露的 Apache Roller 6.1.5 反序列化漏洞：XML-RPC 端点在认证前解析 vendor extension 类型，攻击者可发送特制序列化字节直接触发未认证远程代码执行。关键点在于——该端点即使管理员在配置中禁用 XML-RPC 仍可被触达（enabledForExtensions 默认 true、禁用开关仅在 handler 内部生效），因此仅靠改配置不足以缓解，必须升级到 6.1.6。目前已有 3 个公开 PoC 仓库。

值得关注：开源 Java 博客平台常暴露于公网；"禁用功能开关无效"是典型配置陷阱；无法立即升级时，应在反向代理 / 防火墙层封禁 /roller-services/xmlrpc 路径并部署 WAF 拦截可疑序列化对象。

3 高危

SailPoint IdentityIQ CVE-2026-12342（×9.6）未认证 RCE，影响所有版本

SailPoint IdentityIQ 全版本 · Web 服务 API 内容输入校验不当 CVE-2026-12342 CVSS 9.6 · 未认证 RCE

身份治理平台 SailPoint IdentityIQ 所有版本存在因 Web 服务 API 内容输入校验不当导致的未认证远程代码执行漏洞。IdentityIQ 掌管企业用户供给与访问权限，一旦被攻陷即可直接操纵特权访问流程。目前暂无公开 PoC，但"未经认证 + 9.6 高危 + 高价值目标"的组合使其成为攻击者优先尝试对象，应优先修补。

值得关注：身份平台是"拿下即控全局"的战略高点；其失陷往往意味着横向移动与权限提升的跳板，补丁紧迫度高。

4 默认凭据

Logsign SIEM CVE-2026-90924（×9.8）默认口令 → SIEM 全盘沦陷

Innotim Logsign SIEM 6.4.101–6.4.116 · 修复 6.4.117 · CWE-1392 CVE-2026-90924 CVSS 9.8 · 默认凭据 · 利用极简

土耳其 TR-CERT（USOM 通报 TR-26-1202）披露的 Logsign SIEM 默认凭据漏洞：产品出厂携带常见 / 默认管理员账号，且部署时不强制修改。远程未认证攻击者可直接用默认口令登录。攻陷 SIEM 意味着获得对全环境日志、告警的可见与篡改能力——攻击者能压制自身攻击痕迹。影响 6.4.101–6.4.116，修复版本 6.4.117。利用极简（尝试默认口令即可）。

值得关注：安全设备自身成了突破口，攻击者借 SIEM 实现"看得见你、改得了你"；临时缓解必须修改全部默认 / 常见口令，并将管理接口收敛至内网、启用 MFA。

5 AI 安全

mcp-remote CVE-2026-51996（×9.8）MCP 远程传输任意代码执行

geelen/mcp-remote 0.1.16–0.1.38 · CVSS 9.8（ADP） CVE-2026-51996 CVSS 9.8 · 远程任意代码执行

广用的 MCP 远程传输库 mcp-remote（0.1.16–0.1.38）因 src/lib/utils.ts 的 getServerUrlHash 函数缺陷，允许远程攻击者执行任意代码。MCP 是 AI agent 连接外部工具的核心协议，传输层 RCE 意味着"调用任意 MCP 服务即可能中招"。GitHub 安全公告 GHSA-mvq8-g2rm-4rhm 已收录该漏洞（CVSS 9.8）。

值得关注：AI agent 供应链攻击面持续扩大，传输层是高危入口；开发者集成 MCP 服务端须锁定版本并审查传输层实现，避免在 agent 运行环境加载不可信 MCP 服务。

速览区

6. ShinyHunters 攻陷 FBI 求职门户，荷兰逮捕嫌疑人

ShinyHunters 借 Oracle PeopleSoft CVE-2026-35273，仅做单字符替换即绕过各组织依赖的防火墙规则（而非 Oracle 6 月补丁），据称取得 2–3TB 数据并暴露 5000+ 官员 SSN；荷兰警方 9/28 逮捕嫌疑人 Pepijn van der Stap，但剩余成员随即升级活动。

7. Microsoft 披露 NeedyMantis 后渗透恶意软件（Storm-3069）

关联 Daemon Tools 供应链投毒：通过 Poedit / TightVNC 等合法软件目录进行 DLL 劫持，加密 WebSocket 通信，针对电信、高校、政府承包商长期驻留，模块化架构支持持久化。

8. JadePuffer 行动（Storm-3168）滥用 Azure 服务主体

攻击者使用被盗 Azure service principal，在约 18 小时内于受害者租户内收集凭据并销毁资源，展示云身份凭据被滥用的破坏性后果。

9. Windows BitLocker 零日 "YellowKey" CVE-2026-45585

研究员公开 PoC：借特制 FsTx 文件 + 在 WinRE 中按住 Ctrl 触发全权限 Shell 绕过磁盘加密；微软发布缓解（移除 BootExecute 中 autofstx.exe、改 TPM+PIN）。

10. OpenStack Glance CVE-2026-51772（×8.1）SSRF

show_multiple_locations 开启时，认证用户可经 crafted HTTP PATCH 操纵镜像 locations 触发服务端请求伪造，影响云基础设施镜像服务。

11. authentik / Discourse 等多款应用 9/29 曝未认证缺陷

authentik CVE-2026-94613（未认证）、Discourse CVE-2026-91134 / 91132（沙箱逃逸 / 通配符）等身份与论坛类组件持续成高危入口。
