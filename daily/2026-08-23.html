1 严重

Microsoft Entra ID 满分 RCE 披露（CVE-2026-69836，CVSS 10.0）：云身份层被击穿后由服务端秒级缓解

CVSS 10.0 / CWE-502 服务端已缓解 / 未入 KEV

微软修复了 Entra ID（原 Azure AD）中的一个反序列化远程代码执行漏洞，CVSS 满分 10.0，攻击向量为网络、无需认证、无需用户交互。该漏洞由微软首席安全工程师 Robert Fitzpatrick 发现，微软称已在服务端完全缓解、无需客户侧操作，且未确认在野利用，因此未进入 CISA KEV。先放出"在野利用"标记后又更正，使云身份层的满分漏洞进入"披露即敏感"区间。

漏洞机制/攻击方式：

  • 类型：不可信数据反序列化（CWE-502）
  • 攻击方式：未认证攻击者经网络发送特制序列化负载，在 Entra ID 服务端触发 RCE
  • 影响范围：使用 Entra ID 的所有租户（修复前）
  • 后果：服务端级代码执行可篡改认证/授权；微软已服务端兜底

值得关注的原因：

  • Entra ID 是企业登录与访问控制的"信任锚"，未认证网络 RCE 的爆炸半径等于整个云身份底座
  • 首次把"核心云身份平台出现 CWE-502 经典反序列化"摆上台面，自研/第三方 IDaaS 须同等强度审计
  • 即便本次由服务端兜底，也证明满分漏洞的披露节奏已被放到显微镜下，透明度即压力
未认证攻击者 特制序列化负载 CWE-502 反序列化 服务端 RCE 身份底座失守
2 严重

Cisco 安全加固：Crosswork / Secure Workload 9 个漏洞分组，5 个满分（CVSS 10.0）

9 分组 / 5×10.0 内部发现 / 无变通方案

思科 8/19 发布、8/21 定稿的"安全加固"公告修复 Crosswork 与 Secure Workload 共 9 个 CVE 分组，其中 5 个达 CVSS 10.0 满分。漏洞来自内部安全评审（含 AI 模型辅助），目前无在野利用证据、无变通方案。评分 10.0 代表该类目最严重潜在影响，实际可利用性需逐产品核对。

受影响组件：

组件风险
Cisco Crosswork（≤7.2.1，含 Workflow Manager）严重 · 3 个 10.0（20030/20357/20358）+ 20359(9.9)
Cisco Secure Workload（3.10 / 4.0）高危 · 2 个 10.0（20315/20317）+ 20231(9.9)/20318(9.6)/20319(7.5)

修复：Crosswork 升 7.2.1-SP；Secure Workload 升 3.10.9.1 / 4.0.4.16。无变通方案，必须升级。

3 严重

GitLab CVE-2026-19478（CVSS 9.4）披露 48 小时即在野，可伪造合并记录

CVSS 9.4 / CWE-94 在野 / 供应链信任层

GitLab CE/EE 的 GraphQL 接口存在未认证代码注入（CWE-94），攻击者可借特制指令远程修改/删除公开项目与用户数据。8/17 披露并修复（19.2.4/19.1.6/19.0.8/18.11.11），watchTowr 8/18 仅据公告+补丁 diff 数分钟复现，8/20 蜜罐即捕获首批在野利用。最危险的是可伪造 merge 记录——恶意提交看似已审查通过，CI/CD 照常构建下发，比删库更难察觉。

值得关注：排查指标 @gl_introduced 与未认证对 /api/graphql 的高频 POST；该 CVE 尚未入 KEV，不能等 KEV 才动。暴露实例须立即升修复版并审计公开项目的合并/封禁记录。

4 高危

软件供应链双袭：Rust crate（2.45 亿下载）+ 14 个 npm 包投递后门

Rust / npm 在野 / 朝鲜+AI

8/20–8/22 两条供应链攻击同窗爆发：攻击者攻陷 crates.io 维护者账号，向 arrayref（约 2.45 亿次下载）等高下载量包注入恶意依赖 proc-macro1，构建期投递负载，运营仅约 86 分钟即被发现，归因指向朝鲜；同期 Trend AI 识别 14 个伪装成日历/打卡工具的恶意 npm 包，导入即触发、绕过 --ignore-scripts，投递 RedShell——AI 驱动 RedC2 4.0 框架的 Linux 后门。

值得关注：两线分别打 Rust 构建期与 npm 导入期，传统 install-hook 防护失效；"国家级 + AI 自动化"组合标志供应链攻击进入新阶段，须把依赖来源可信度列为最高优先级。

5 高危

Windows Defender 自带驱动 BTR.sys 被武器化："BTR Reforged"（无 CVE）

Win7–25H2 PoC 公开 / 无补丁

Check Point 的 Jiří Vinopal 在 Black Hat USA 2026 / DEF CON 34 披露 BTR.sys（Defender 的 Boot Time Removal Tool，微软签名驱动）可被改造为内核级任意文件/注册表操作原语，并发布 PoC BTR_CLI。该驱动自 Win7 至 Win11 25H2 均内置、不利用任何缺陷、不导入外部驱动，可在 Defender 用户态启动前约 34 秒"黄金窗口"删除/篡改安全软件。MSRC 认定属"设计内特权边界"，无 CVE、无补丁计划。

值得关注：这是 BYOVD 的进化形态——直接用系统自带受信驱动关掉 EDR，哈希/发布者黑名单默认放行；缓解抓手是收紧 SeLoadDriverPrivilege 持有者，检测靠 Sysmon Event 15 的 .sys:changelist 等行为信号。

速览区

6. Citrix NetScaler 双漏洞（CVE-2026-19489 / 19490）

8/22 披露：前者为启用 SIP ALG 的大规格 NAT 下内存溢出致 DoS，后者为 Gateway/AAA 虚拟服务器认证绕过，已发布修复版本。

7. miniOrange SAML 2.0 WP 两绕过（61979 / 15981）

签名算法混淆 + 误读 OpenSSL 错误码为有效，可伪造断言登录任意用户（含管理员）；6 个付费版本线未纳入公开漏洞库。

8. 7 州水务系统遭协同入侵 + Siemens S7 AI 攻击

8/21 美多机构预警：OT/水厂运营技术环境被攻，叠加 Siemens S7 PLC 遭 AI 辅助攻击的紧急警示，关键基础设施成明确靶面。

9. Mailgun for WordPress SSRF（CVE-2026-78003，9.8）

路径遍历致未认证 SSRF，可拦截密码重置邮件实现管理员接管，影响 ≤2.2.0，8/22 公布。

10. DJI 无人机 BLE 泄露 Wi-Fi 凭据（CVE-2026-77812，9.4）

DUML 经 BLE 明文传输 Wi-Fi PSK/SSID，被动嗅探即可加入内网并重放信任 UUID，影响 Neo/Flip/Air 3/Mini 等多款，需固件升级。

11. CareCloud 数据泄露（375 万人）

未经授权访问 AWS 致医疗记录与社保号外泄，再次凸显云配置与凭证治理缺口。
