云原生数据库 ArcadeDB 爆出无认证接管漏洞簇：CVE-2026-67342 无需认证读写任意库，触发器脚本可 RCE

ArcadeDB < 26.7.2 · CVSS 9.3–9.8（含 9.8 无认证绕过）· 8/1 多源集中披露 · 接 Langflow/Flowise/Orkes 数据基础设施 RCE 潮

1 严重

云原生数据库 ArcadeDB 漏洞簇：无认证接管 + 触发器脚本 RCE（CVE-2026-67340/67341/67342/67344）

ArcadeDB < 26.7.2 · 8/1 多源披露 最高 9.8 无认证绕过

8/1 VulnCheck / Rapid7 / The Hacker Wire 集中披露 ArcadeDB（云原生多模型数据库）< 26.7.2 的四个严重缺陷：CVE-2026-67342（CVSS 9.8）为 time series/batch/Prometheus/Grafana 等 HTTP 处理器未校验库访问权限，无需认证即可读写任意数据库；CVE-2026-67340（CVSS 9.3/9.8）允许具备 UPDATE_SCHEMA 的用户创建 JS 触发器调用 java.lang.Runtime.exec() 以数据库进程权限执行 OS 命令；CVE-2026-67341（9.3）DEFINE FUNCTION 跳过脚本授权；CVE-2026-67344（8.x）ALTER TYPE 未强制 schema 权限。全部于 26.7.2 修复。

漏洞机制/攻击方式：

  • 类型：认证绕过（CWE-863）+ 代码注入（CWE-94）
  • 攻击方式：①直接打无认证 HTTP 接口接管任意库；②低权账户建恶意 JS 触发器/函数，借 DB 进程提权到宿主机命令执行
  • 影响范围：所有互联网可达、运行 ArcadeDB < 26.7.2 的实例（AI 知识库/图库/多模型后端）
  • 后果：任意库读写、以 DB 进程权限 RCE、窃取凭据与数据、横向移动

值得关注的原因：

  • 云原生/AI 中间件数据库接连成 RCE 重灾区（接 Langflow/Flowise/Orkes，本月第四类）
  • CVE-2026-67342「无认证」使暴露实例可直接被接管，无需任何凭据
  • 触发器/函数注入把「数据库权限」抬升为「宿主机命令执行」
  • 四漏洞同日披露、同版本修复（26.7.2），须整体升级而非单点打补丁
低权/无认证 接管任意库/建触发器 引用java.lang.Runtime DB进程RCE 横向移动
2 高危

Windows NT 内核提权 CVE-2026-42980：公开 PoC 发布，本地提权至 SYSTEM

CVE-2026-42980 · WMI 整数下溢 PoC 公开 · 6月补丁已修

研究员 G4sp4rCS 公开 CVE-2026-42980 可运行 PoC。漏洞位于 Windows NT 内核 WMI 序列化路径（ntoskrnl.exe，IOCTL 0x22812C/0x228130），32 位剩余输出计数器整数下溢回绕，导致越界写入内核 SystemBuffer，最终本地提权至 NT AUTHORITY\SYSTEM。微软已在 2026 年 6 月补丁星期二修复，利用可能性评估「更可能」。

受影响组件：

组件风险
Windows 10 / 11（含 24H2）高危 提权
多用户/终端服务器中高危
3 严重

FreeRDP 客户端 RCE CVE-2026-44421（CVSS 8.8）：恶意 RDP 服务器反打客户端

CVE-2026-44421 · gdi_CacheToSurface PoC 公开 · < 3.26.0

开源 RDP 实现 FreeRDP 堆溢出（CWE-122，CVSS 8.8）PoC 已公开。gdi_CacheToSurface 将目标矩形 clamp 到 UINT16_MAX，但拷贝仍用原始 cacheEntry 尺寸，超限时大规模越界堆写。攻击者为恶意 RDP 服务器，受害者客户端（启用 RDPGFX）连入即被在客户端设备执行任意代码。影响 FreeRDP < 3.26.0，3.26.0 修复。

组件风险
FreeRDP < 3.26.0（RDPGFX 启用）严重 8.8

4 中高危

新勒索团伙 Crpxo 宣称攻陷土耳其多家巨头（7/31）

双重勒索 · 声明待证实 THY/ASELSAN/三大行

新兴团伙 CRPxO 于 7/31 集中挂出约 10 家土耳其头部企业：土耳其航空 THY（4.2GB）、国防电子 ASELSAN（4.5GB）、三大银行 Kuveyt Turk/Finansbank/Anadolubank、保险 Anadolu Sigorta、零售 A101、传媒能源 Doğan Holding，以及 Hyundai、Johnson & Johnson。名单由 7/27 的 20 家美国小商户骤变为国家级巨头，最合理路径为共享供应商/集成商链式妥协。所有被点名企业均未确认入侵。

值得关注：名单画像跳跃需以 IOC 为准审慎研判；多家巨头同日出现强烈指向供应商链式妥协；新兴团伙借 trophy name 招募联盟，防御侧应按「待证实但需核查」前置排查。

5 高危

SharePoint CVE-2026-55040 链式 RCE 第二环随 8 月补丁补全

CVE-2026-55040 链 · JWT 绕过 9.1 无凭据 RCE · Storm-2603

8 月补丁星期二补齐 CVE-2026-55040（CVSS 9.1，SharePoint JWT 弱认证绕过）攻击链第二环——RCE 环节（此前 embargo，8/1 才随补丁公开）。第一环允许未认证攻击者凭目标 SID/UPN 伪造被接受的 JWT 冒充站点管理员；两环组合 = 完全无凭据 RCE，任何互联网可达的本地 SharePoint Server 皆是入口。CISA 曾给 3 天联邦大限（7/14 入 KEV，7/17 截止）；历史在野者 Storm-2603（Warlock 勒索）自 2025 年中猎杀本地 SharePoint。

值得关注：8/1 已覆盖「83 CVE 无活跃零日」，本链第二环「无凭据 RCE 补全」是 8/1 才解禁的关键增量；仅打 7 月认证绕过补丁不完整，须补 8 月 RCE 环节。

6. NGINX CVE-2026-42533 完整 PoC 预计 8/5 放出

自 2011 遗留的 map 正则堆溢出（CVSS 9.2），只读配置扫描器已发，完整 RCE PoC 窗口约 8/5 关闭；覆盖全球约 1/3 Web 服务器，须先按扫描器排查指令顺序。

7. @better-auth/scim CVE-2026-67330 授权绕过（9.4）

SCIM token 签发未拒绝与既有 SSO/SAML/OIDC 冲突的 provider ID，攻击者可铸造跨租户 SCIM token 越权操作用户与会话记录；影响 1.4.0-beta.27–1.6.21 等。

8. guzzlehttp CVE-2026-67355 主机作用域 cookie 泄露

未正确处理 host-only cookie，将请求 host 存入 Domain 字段，使父域凭据可被子域跨信任边界获取，泄露会话/令牌；影响 < 7.15.1，7.15.1 修复。

9. 菲律宾储蓄银行 PSBank 遭 THEGENTLEMEN 勒索（8/1）
