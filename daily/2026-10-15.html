JetBrains TeamCity 曝满分漏洞：Kotlin DSL 沙箱逃逸致未认证 RCE（CVSS 10.0）

CI/CD 平台单点失陷即可污染整条软件供应链交付环节；同期 CISA KEV 双零日 10-16 修复期限临近。

1 严重

JetBrains TeamCity CVE-2026-106218 — Kotlin DSL 沙箱逃逸，未认证 RCE

CVSS 10.0 未入KEV · 已修复 2026.1.3

JetBrains 在 2026.1.3 与 2025.11.7 修复了 TeamCity 的 Kotlin DSL 沙箱逃逸漏洞。攻击者可通过构造恶意的 Kotlin DSL 构建配置绕过沙箱限制，在 TeamCity 服务器上执行任意命令。NVD 与多家 CTI 平台标注其为 CRITICAL 10.0，无需认证、无需用户交互、网络可达即可触发（AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H）。

漏洞机制/攻击方式：

  • 类型：沙箱逃逸 / 不完整禁用输入清单（CWE-184）
  • 攻击方式：通过版本化设置的 Kotlin DSL 提交绕过沙箱，触发服务器端命令执行
  • 影响范围：所有公网可达或内网未隔离的 TeamCity 服务器（CI/CD 基础设施）
  • 后果：源码泄露、构建产物被植入后门、生产凭据与密钥失窃，构成典型供应链攻击面

值得关注的原因：

  • CI/CD 服务器属 Tier-0 资产，单一漏洞即可污染下游所有发布物
  • 无需认证即可触发，极适合自动化蠕虫式扫描与利用
  • 修复版本已发布，但大量老旧实例可能仍在运行受影响版本
攻击者 提交恶意Kotlin DSL 绕过沙箱 服务器RCE 供应链沦陷
2 高危

CISA KEV 双零日修复期限将至：Ivanti + 微软 Windows

CVE-2026-104935 / CVE-2026-96951 在野 · 10-16 截止

CISA 于 2026-10-13 将两枚在野零日加入 KEV 目录，修复期限定为 2026-10-16。CVE-2026-104935 为 Ivanti Connect Secure 认证绕过（冒名），确认在野、可未认证 RCE，属一个三零日链的一环且目前仅部分有补丁；CVE-2026-96951 为微软 Windows Shell 命令注入，可从网络侧绕过安全特性执行任意命令，与去除 Mark of the Web（MotW）的利用链相关。

受影响组件：

组件风险
Ivanti Connect Secure VPN严重 · 在野 · 部分链无补丁
Microsoft Windows（Shell）严重 · 在野 · 10-16 前须缓解
3 高危

Ahold Delhaize 跨国零售遭网络攻击：9400+ 门店数字服务中断

2026-10-12 披露 数字生态中断

荷兰食品零售巨头 Ahold Delhaize（运营 Albert Heijn、Delhaize、Stop & Shop、Food Lion 等，全球 9400+ 门店、近 40 万员工）于 2026-10-12 披露内部网络存在安全问题，为防扩散主动切断部分系统。事件波及荷兰、比利时、美国三地的网站、App、客户服务平台与线上杂货配送，门店虽正常营业但电子价签、个性化折扣与配送暂停。公司称暂无数据泄露证据，荷兰国家网络安全中心确认与同期法国超市制冷系统被篡改事件无关联。

4 中高危

朝鲜 IT 工人渗透计划遭美方打击：逮捕 2 人、缴获 187 台笔记本

2026-10-14 披露 执法行动

FBI 警告朝鲜 IT 工人正付费诱使美国人协助其使用被盗身份获取美国公司的远程岗位，朝鲜政府拿走 85–90% 收入用于武器计划。美司法部逮捕 2 名美国籍嫌疑人、突袭德州 40 处据点、缴获约 187 台笔记本（笔记本农场），波及 70+ 美国雇主、涉案约 300 万美元。部分工人被解雇后威胁前主管暴力与数据泄露，甚至瞄准需安全许可的岗位。

5 中高危

WordPress 插件连击：未认证文件删除（10.0）与任意文件读取（8.8）

CVE-2026-107594 / CVE-2026-91136 未认证

"File Upload to Order" 插件（< 1.1.4）未校验来自会话数据的文件路径，删除动作可由未认证用户触达（CVE-2026-107594，CVSS 10.0）；"Divi Plus" 插件（<= 2.4.0）通过 svg-animator 接口的 svg_image 参数存在未认证任意文件读取（CVE-2026-91136，CVSS 8.8）。

受影响组件：

组件风险
File Upload to Order < 1.1.4严重 · 未认证任意文件删除
Divi Plus <= 2.4.0中高危 · 未认证任意文件读取

速览区

6. @enmaso/node-convert（npm）命令注入 — CVE-2026-107703（8.6）

convert.js 未对 filepath 与 convertTo 参数做净化，攻击者可借此执行 shell 命令；影响 <= 1.0.0，属 npm 供应链风险。

7. Tuleap Enterprise OS 命令注入 — CVE-2026-105407（9.3）

Tuleap 企业版 17.0–17.5 的时间/区域管理子系统存在 OS 命令注入，可在服务器上执行任意命令。

8. Edimax BR-6208AC 路由器缓冲区溢出 — CVE-2026-108915（9.9）

/goform/formWlanMP 的 ateBW 参数可触发缓冲区溢出，厂商已停止维护、未回应披露；攻击者可远程执行，公开 PoC 已现。

9. 微软 Windows 补丁致 RDP 故障

近期 Windows 更新在启用 Administrator protection 时会导致非管理员用户远程桌面连接失败，影响 Win11 与 Server 2025；修复仍在调查中。
