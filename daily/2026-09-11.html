Cisco Secure FMC 认证绕过致未授权 root RCE：CVE-2026-20079（CVSS 10.0）已在野，KEV 9/12 大限临近

Cisco Secure Firewall Management Center（FMC）/ Security Cloud Control（SCC）防火墙管理组件存在认证绕过（CWE-288），未认证远程攻击者借构造 HTTP 请求绕过认证并执脚本文件，夺取设备 root。9/9 入 CISA KEV，修复截止 9/12；Talos 确认已被勒索软件与国家背景集群实际利用，且 Cisco 称无官方 workaround。

1 严重

Cisco Secure FMC 认证绕过未授权 root RCE（头条）：CVE-2026-20079 满分 10.0，已在野

CVE-2026-20079 · CWE-288 · FMC 7.0–10.0 / SCC CVSS 10.0 · KEV 9/9 · 截止 9/12

Cisco Secure Firewall Management Center（FMC）与 Security Cloud Control（SCC）防火墙管理组件存在认证绕过（CWE-288：Alternate Path/Channel）：因启动期创建的非法系统进程，未认证远程攻击者可发送构造 HTTP 请求绕过认证，在受影响设备上执行脚本文件并获取底层操作系统 root 权限。CVSS 3.1 10.0（AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H）。

该漏洞由 Cisco 于 2026 年 3 月披露，9 月 9 日被 CISA 列入 KEV，联邦修复截止日为 9 月 12 日（明日）。Cisco Talos 确认其已被实际利用：至少三个攻击集群（含勒索软件与疑似国家背景组织）借该漏洞部署 webshell、JAR 命令执行器与凭据窃取组件，部分集群将其与 CVE-2026-20316（静态凭据）组合部署反弹 shell 与 Cyclops Blink 变种。

值得关注的原因：FMC 是防火墙管理中枢，一旦被 root 接管，攻击者可篡改防火墙策略、清除痕迹并以此为跳板横向移动；公开利用代码已于 8 月出现（两份独立 PoC），且无官方缓解措施，必须升级固件。公网暴露实例应立即升级并排查异常 root 会话与 webshell。

2 严重

Forgejo 模板引擎注入 RCE CVE-2026-89094（CVSS 9.9）—— 9/10 新披露

CVE-2026-89094 · CWE-1336 · Forgejo < 16.0.4 CVSS 9.9 · 9/10 披露

Forgejo（自托管代码托管平台，Codeberg 底层）在 16.0.4 之前版本中，对 .forgejo/template 目录下的模板文件扩展处理不当，存在模板引擎注入（CWE-1336）：攻击者通过构造的模板仓库即可触发远程代码执行。影响 16.0.0–16.0.4 与 0–15.0.8，官方已发布 16.0.4 / 15.0.8 修复。

Forgejo 是大量开源项目与企业的代码托管底座，模板仓库 RCE 可借 CI/构建流程实现供应链投毒。该 CVE 尚不在 KEV，但 CVSS 9.9 且公网 Forgejo 实例众多，应优先升级。

3 严重

Adobe ColdFusion eval 注入 RCE CVE-2026-48273（CVSS 9.9）—— APSB26-119

CVE-2026-48273 · CWE-95 · CF 2025≤12 / 2023≤23 CVSS 9.9 · 9/8 披露

ColdFusion 存在动态代码 eval 注入（CWE-95）：低权限攻击者无需用户交互即可将指令注入动态求值代码，在 ColdFusion 服务账户上下文执行任意代码。影响 ColdFusion 2025 ≤ Update 12、2023 ≤ Update 23；修复于 2025 Update 13 / 2023 Update 24（APSB26-119）。

ColdFusion 常承载企业门户/API/认证服务，历史漏洞从披露到武器化极快，应与 8 月同批 CVE-2026-48362（CVSS 10.0 未认证 OS 命令注入）一并纳入最高优先级。

4 严重

AutoAgent 沙箱 TCP 服务未认证 root RCE CVE-2026-86124（CVSS 9.8）

CVE-2026-86124 · CWE-306 · HKUDS AutoAgent CVSS 9.8/9.3 · 9/5 披露

HKUDS 开源 AI Agent 框架 AutoAgent 的沙箱 TCP 命令服务（tcp_server.py）绑定 0.0.0.0 且完全不校验身份（CWE-306），任何能连上端口的客户端发送的命令都以 root 在容器内执行，并可借 bind-mount 的宿主机工作目录越出容器。CVSS 3.1 9.8 / 4.0 9.3，9 月 5 日由 VulnCheck 披露，尚无官方修复版本。

这是 2026 年第四波「AI Agent 基础设施默认可达」事件，同批还有 Cua computer-server、excel-mcp-server、TEN Framework 出现同类「认证检查仅在环境变量被设置时才运行」缺陷。

5 高危

cPanel EmailTrack SQL 注入致 root RCE CVE-2026-67401

CVE-2026-67401 · cPanel/WHM EmailTrack 9/8 披露 · 全版本受影响

cPanel/WHM 的 EmailTrack 功能存在 SQL 注入，拥有邮件权限的已认证 cPanel 账户可借此在服务器创建任意文件，进而以 root 身份执行代码、完全控制服务器。9 月 8 日披露，影响所有受支持版本，修复于 11.110.0.143 / 11.134.0.55 / 11.136.0.39 / 11.138.0.4（WP2 11.138.1.9）。

cPanel 支撑全球数百万网站，单账户→root 的链式利用对虚拟主机服务商、多租户服务器风险极高；凭据泄露/钓鱼即触发，应升级并核查异常邮件权限账户。

速览区

6. npm toml 原型污染 + DoS（CVE-2026-63376 / 77465）

toml.parse() 在 4.1.2 之前因路径去同步（逗号拼接跟踪路径 vs 点拼接遍历路径）将攻击者键写入 Object.prototype（CWE-1321，CVSS 8.2）；同包 CVE-2026-77465 为深层嵌套 payload 引发的不可捕获 RangeError（约 5–6KB 即令 Worker 崩溃）。toml 在 npm 月下载约 4700 万，大量 Next.js 构建链与 Node 服务间接依赖——凡解析不可信 TOML 输入者需固定至 4.1.2 并加深度/大小护栏。

7. Microsoft Entra ID 缺失授权提权 CVE-2026-83941（CVSS 9.9）

Entra ID（原 Azure AD）授权检查缺失（CWE-862），低权限已认证用户可跨租户范围提权，影响机密性/完整性。微软已于 9 月补丁中服务端修复，无需客户侧操作；应审计 Entra 审计日志与 PIM 告警排查异常角色分配。

8. Cua computer-server 未认证 RCE CVE-2026-86121（CVSS 9.8）

trycua/cua 的 computer-server 在 CONTAINER_NAME 环境变量未设置时静默跳过认证，且默认绑定 0.0.0.0（TCP/8000），未认证攻击者可直接 run_command / 读写任意文件 / 拿交互式 PTY。修复于 0.3.42（改默认绑定 127.0.0.1）。

9. AI Agent 无认证集群第二波（CVE-2026-85661 / 85688，均 9.8）

excel-mcp-server 在 EXCEL_FILES_PATH 留空时可读写任意文件；TEN Framework 的 TMAN Designer API 直接接受未认证文件读写请求。与 AutoAgent、Cua 同属「认证检查非 fail-safe」模式，AI 开发/自动化基础设施成为新攻击面。

10. WordPress 插件在野利用浪潮升级（Fruition 9/11）

Wordfence 观测 Elementor Pro（~600 万安装）、All-in-One WP Migration（~500 万）持续在野；新增 Gravity Forms（~100 万）未认证文件上传/SQLi 向量导致 RCE。运行大规模 WordPress 者应本周内完成插件盘点与升级。

11. Drupal contrib 16 项安全公告潮

Drupal 一次性发布 16 项咨询，含 Jsonapi Role Access 与 OTP Verification 模块的严重越权访问绕过，使用相关 contrib 模块站点需核对并更新，避免权限提升与账户接管。
