1 严重

ADFS CVE-2026-56155 整改大限今日到期，首例在野利用被捕获（身份枢纽沦陷）

CVE-2026-56155 · CVSS 7.8 (CWE-1220) 在野利用 · 联邦大限 2026-07-28

Microsoft ADFS 漏洞 CVE-2026-56155（CWE-1220 访问控制粒度不足，CVSS 7.8）的 CISA KEV 联邦整改大限 2026-07-28（今日）正式到期。多家联邦 SOC 与第三方遥测（Proofpoint、watchTowr 蜜罐）同步确认：自 7/25 起已出现针对暴露 ADFS 实例的针对性利用，攻击者借该缺陷提升权限并伪造联合安全令牌，横向打通 SAML 依赖方与 Entra ID 互信边界。该漏洞与 7 月补丁周期中的其他身份缺陷共同构成「身份基础设施在野」高峰。

漏洞机制/攻击方式：

  • 类型：访问控制粒度不足（CWE-1220）/ 身份权限提升
  • 攻击方式：越权读取联合配置与密钥材料，伪造 SAML/WS-Federation 安全令牌
  • 影响范围：所有暴露的 ADFS 实例及其 SAML/Entra 依赖方
  • 后果：令牌伪造、全域横向移动、持久化控制

值得关注的原因：

  • 身份即边界：ADFS 沦陷 = 下游所有依赖方信任链瓦解
  • 「大限」驱动暴露窗口：KEV 截止日成为攻击方收割节点
  • 补丁≠缓解：需评估云暴露面并重置联合信任，流程滞后
定位暴露 ADFS 提权读密钥 伪造联合令牌 登录依赖方 全域横向移动
2 严重

Citrix NetScaler ADC/Gateway 新预认证 RCE（CVE-2026-8865，CVSS 9.8）—— 第五代 CitrixBleed

CVE-2026-8865 · CVSS 9.8 PoC公开 · 24h在野

Citrix 于 7/28 披露 NetScaler ADC/Gateway 预认证内存越界读写漏洞 CVE-2026-8865（CVSS 9.8），根因为网关处理特定 SAML/认证上下文时未正确边界校验，攻击者可先越界读内存泄露会话与密钥，再借写原语落地预认证远程代码执行。被视为 CitrixBleed 系列「第五代」（继 CVE-2023-4966 / CVE-2025-5777 / CVE-2026-8451 之后），watchTowr 24 小时内释出可复现 PoC，首轮在野针对作为 SAML IdP 的 NetScaler 网关，影响 14.x/15.x 特定 build。

受影响组件：

组件风险
NetScaler ADC/Gateway 14.x / 15.x（特定 build）高危
作为 SAML IdP 暴露的网关中高危
3 高危

Ollama 推理服务未授权模型拉取致 RCE（CVE-2026-58842，CVSS 9.1）

CVE-2026-58842 · CVSS 9.1 PoC公开 · 默认暴露

本地大模型推理服务 Ollama 被披露未授权访问漏洞 CVE-2026-58842（CWE-284/CWE-94，CVSS 9.1）。在默认 0.0.0.0:11434 暴露且未启用鉴权的情况下，攻击者经 /api/pull 拉取特制 GGUF / safetensors 模型文件，触发加载器在模型解析阶段的任意代码执行。该缺陷与 7/22 的 vllm-serve 供应链投毒、7/25 的 Langflow RCE、7/27 的 Orkes Conductor 未认证 RCE 共同构成 2026 年 AI 资产攻击链。

受影响组件：

组件风险
Ollama（默认 0.0.0.0:11434 未鉴权暴露）高危
企业自托管推理集群 / AI 中台中高危
4 高危

containerd 容器运行时符号链接竞态逃逸（CVE-2026-57988，CVSS 8.8）

CVE-2026-57988 · CVSS 8.8 PoC公开

容器运行时 containerd 被披露镜像解包阶段符号链接竞态漏洞 CVE-2026-57988（CWE-59/CWE-362，CVSS 8.8）。攻击者在恶意镜像中构造指向宿主根的竞态符号链接，在解包时序窗口内写入宿主文件系统，实现容器逃逸 / 挂载逃逸，在已提权容器内进一步夺取宿主 root。PoC 已公开，主流红队框架已集成该模块；影响 1.x/2.x 多个小版本，官方已发布修复版本。

5 中高危

CISA 7/28 发布多项 ICS 警报，某 SCADA 平台零日在野（OT 暴露面放大）

CVE-2026-59123 · CVSS 9.1 在野利用

CISA 于 7/28 发布新一轮工业控制系统（ICS）安全公告与警报，覆盖能源、水务与制造领域。其中某 SCADA 平台未认证远程代码执行漏洞 CVE-2026-59123（CVSS 9.1）已确认在野，攻击者可经管理端口直接接管监控与数据采集设备。该动态延续 7/25「七项 ICS 公告 + Panduit IntraVUE 10.0 OT 网段绕过」的 OT 暴露面单日放大趋势。

速览区

6. Cisco IOS XE Web UI 提权（CVE-2026-89012，9.0）在野

Web 管理界面权限校验缺陷致低权用户提升至特权 exec，Cisco PSIRT 确认针对性利用，延续 7 月 Cisco 边界设备高危态势。

7. WordPress 流行插件连锁 RCE（CVE-2026-58633，9.8）

某装机量百万级页面构建插件未认证任意文件上传致完整 RCE，Exploit-DB/GitHub 多份 PoC，延续 wp2shell 后的 CMS 攻击面接力。

8. npm 供应链新投毒（AI 工具链 typosquat）

冒充主流向量数据库客户端的恶意包，安装钩子窃取 ~/.npmrc 与云凭证，归因与 7/22 vllm-serve 同一团伙手法。

9. 某区域医疗系统遭 BlackSuit 勒索

美国东南部医疗网络遭 BlackSuit 入侵，约 60 万患者记录与运营数据外泄，部分急诊调度一度降级，暗网放出样本。

10. 2026 Q2 勒索报告

未打补丁的边界 VPN/网关（NetScaler、SonicWall、Fortinet 系）仍占初始访问约三分之一，建议优先收敛暴露面。

11. AI Agent 自动化攻击新案例

观察到利用自主 AI 代理自动侦察并 chaining 公开 PoC 的攻击流量增多，提示「代理型攻击」已从概念常态化。
