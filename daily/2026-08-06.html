N-able N-central KEV 大限今日到期——MSP 管理平面级联失守进入倒计时

认证绕过 CVE-2026-18577（CVSS 9.6）整改大限 8/6 到期，补丁不完整变体 CVE-2026-18556 仍在野，下游成百上千客户网络级联风险未解除

1 严重

N-able N-central KEV 大限今日到期（CVE-2026-18577 + CVE-2026-18556）

CVSS 9.6 KEV大限8/6到期·补丁不完整仍在野

CISA 于 2026-08-03 将 N-able N-central 认证绕过漏洞 CVE-2026-18577（CVSS 9.6，CWE-288）纳入 KEV，联邦整改大限即为今日 8/6。该漏洞存在于 MSP 核心远程监控与管理（RMM）平台：攻击者无需有效凭据即可绕过身份验证直达管理平面，进而以 MSP 身份向所有被管客户终端下发恶意自动化策略 / 脚本，实现一对多的级联接管。官方针对 18577 的首个修复并不完整，催生 CVE-2026-18556（同一认证绕过面的补丁后绕过变体），二者当前均在野。

漏洞机制：

  • 类型：认证绕过（CWE-288）+ 补丁后绕过变体
  • 攻击方式：未授权进入 N-central Web 管理平面
  • 放大路径：以 MSP 身份下发恶意策略至下游客户终端
  • 后果：整张 MSP 客户网络在信任关系掩护下被静默横向

值得关注的原因：

  • KEV 大限今日到期 ≠ 风险解除，18556 补丁不完整仍在野，暴露窗口延续
  • MSP / RMM 是"防守者最信任的通道"，恶意策略经合法通道下发，EDR 难区分
  • 18577 → 18556 的"修复引入 / 补丁不完整"链式，再次印证"打补丁 ≠ 修复"
  • BOD 26-04 下整改窗口压缩至 3 天，须先排查是否已入侵再打补丁
攻击者 认证绕过18577/18556 进入MSP管理平面 下发恶意策略 下游客户级联失守
2 高危

Linux 内核 io_uring 提权 CVE-2026-51820

CVSS 8.8 PoC公开

研究员于 2026-08-05 公开 Linux 内核 io_uring 子系统本地提权漏洞 CVE-2026-51820（CVSS 8.8）的完整分析与可用 PoC。漏洞源于 io_uring 提交路径中一处释放后使用（UAF）：特定构造的异步请求序列在并发完成时，内核未能正确持有相关对象引用，导致后续代码在已释放内存上继续执行并篡改凭据结构，普通用户借此提权至 root。

io_uring 自 5.x 内核起默认编入并广泛启用，大量容器运行时、数据库与网络服务依赖其路径，攻击面远超传统系统调用。当前尚无在野利用，但 PoC 已公开，利用门槛低，容器逃逸路径值得警惕。

3 高危

恶意 MCP Server 包供应链攻击

无 CVE AI供应链

安全厂商于 2026-08-05 披露一类针对 MCP 生态的供应链攻击：攻击者发布与官方高度相似的 typosquat 恶意包，在 postinstall 安装钩子中植入后门——静默窃取 ~/.ssh/ 私钥、~/.aws/credentials 云凭据以及 VS Code / Claude Code / Cursor 等 AI 编码代理的配置与令牌，随后植入持久化钩子，使后续每一次 AI 代理会话都成为数据渗出通道。

该手法是 8/5 Keyv 关联 npm 蠕虫的自然演进，攻击目标从通用依赖精确下沉到"AI 代理可调用的工具包"，利用开发者对 MCP 生态的信任与自动安装习惯实现无感入侵。

4 严重

Apache Struts OGNL 注入 RCE CVE-2026-52410

CVSS 9.8 PoC传播

Apache 于 2026-08-05 发布 Struts 安全公告 S2-0xxx，披露新的 OGNL 表达式注入 RCE 漏洞 CVE-2026-52410（CVSS 9.8）。漏洞位于标签 / 参数处理路径，在特定条件下攻击者可将可控输入注入 OGNL 求值上下文，在服务器端执行任意命令。该变体绕过既有输入净化，影响仍在维护的多条 2.5.x / 6.x 分支，公开 PoC 已有传播迹象。

OGNL 注入是 Struts 历史反复出现的"祖传"高危面，命中即服务器沦陷；建议在无法立即升级时先用 WAF 规则阻断异常 OGNL 语法字符，并清点资产中 Struts 版本与暴露端点。

5 高危

CISA KEV 8/6 新增 Ivanti 零日 CVE-2026-65500

CVSS 9.1 KEV 8/6新增·大限8/27

CISA 于 2026-08-06 将 Ivanti Connect Secure 未认证 RCE 漏洞 CVE-2026-65500（CVSS 9.1）加入 KEV，联邦整改大限 8/27。该漏洞为边界 VPN / 网关设备的预认证 RCE，攻击者无需凭据即可在设备本体执行代码，进而控制企业出入站咽喉、窃取 VPN 会话与配置、植入持久化后门。

Ivanti 自 2023 年底起已是"边界零日常客"，2026 年亦多次在野（如 7/22 的 CVE-2026-64811）。官方明确"打补丁 ≠ 清除后门"，修复后须重镜像设备以清除潜在持久化。

速览区

6. 某医疗集团约 500 万患者 PHI 泄露

区域性医疗系统供应商确认其托管的第三方云存储桶配置失当，约 500 万患者健康信息（PHI）外泄，含姓名、诊疗与保险记录；接 8/4 安进、7/31 CareCloud 的"医疗云托管商长驻留泄露"线，第三方信任边界持续失守。

7. BlackSuit 认领某市政府网络入侵

勒索团伙 BlackSuit 将美国东南部一市政府列上泄露站，宣称窃取内部行政、财政与居民服务数据，双重勒索；地方政府因预算与暴露面成为勒索高频目标，远程服务暴露为主要入口。

8. Chromium 新沙箱逃逸 0day CVE-2026-51988

研究员公开一处 Chromium 渲染进程 UAF 导致的沙箱逃逸利用，影响全内核浏览器（Chrome / Edge 等），CVSS 9.0，补丁前窗口内存在在野风险；接 7/16 Chromium 9.6 系同类，浏览器内存安全漏洞高频且零交互利用。

9. 朝鲜 Lazarus 借"AI 招聘"钓鱼

朝鲜国家支持 APT Lazarus 伪造 AI / 机器学习工程师招聘流程，以"面试代码库""技术测评"为饵投递含恶意宏 / 脚本的文档与仓库，针对加密货币与科技企业研发人员，借人才市场热度精准社工。
