LoadMaster 预认证 RCE 整改大限今日到期：边界负载均衡器沦陷即全网失守

CVE-2026-8037 CVSS 9.6/9.8，escape_quotes() 缺失空终止符致未认证 root 命令执行；watchTowr PoC 已公开、eSentire 自 6/29 起监测到利用尝试

1 严重

Progress LoadMaster 预认证 RCE CVE-2026-8037 KEV 整改大限今日到期

CVSS 9.6 / 9.8 在野利用

CISA 于 8/7 将 CVE-2026-8037 加入 KEV，联邦整改大限正是今日（8/10）。该漏洞位于 LoadMaster 管理 API 的 escape_quotes() 函数：旧版本用未初始化的 malloc 分配堆缓冲且未补空终止符，sprintf 越界读入相邻堆空间，攻击者在 /accessv2 请求的 JSON 键值对中植入命令注入载荷即可触发。

漏洞机制：

  • 类型：CWE-77 OS 命令注入（未认证）
  • 攻击面：启用 API 的 LoadMaster GA ≤ 7.2.63.1 / LTSF ≤ 7.2.54.17（及 ECS/ObjectScale Connection Manager）
  • 后果：以 root 在边界设备上任意命令执行
  • 修复：GA 7.2.63.2 / LTSF 7.2.54.18（calloc 零填充 + 补空终止符）

值得关注的原因：

  • watchTowr Labs 6/29 公开可用 PoC；eSentire 自 6/29 起捕获真实利用尝试（IOCs 192.42.116.58/105、146.70.139.154）
  • 负载均衡器坐镇网络最外层，未认证 root 即绕过下游所有安全控制
  • 今日为 KEV 整改大限，"补丁未打=已沦陷"，须立即升版本或仅放行可信管理网段
攻击者 /accessv2 API escape_quotes OOB读 命令注入 root RCE 全网失守
2 严重

WordPress XSS2Shell CVE-2026-64638：登录页预认证 XSS 升级 PHP RCE

CVSS 8.9 / 9.8 PoC 公开

pwn.ai 于 8/7 披露 XSS2Shell：WordPress 核心登录页 wp_strip_all_tags()（PHP strip_tags）与自带 KSES 净化器对同一畸形标签解析不一致——在左尖括号与标签名间插入空格（< area）即可绕过前者、却被后者当作合法 HTML 注入，无需认证即可在登录页执行脚本。

升级路径：利用 SOME（Same Origin Method Execution）技巧劫持 user-profile.js 的 AJAX 目标；若诱导已登录管理员点击一次恶意页面，脚本即可代其 mint Application Password、发布页面并最终上传含 PHP WebShell 的插件 ZIP，全程走合法 API 调用。

值得关注：影响 WordPress 4.7 至今几乎所有在维护实例（全球 43%+ 站点、约 5 亿），8/6 紧急发 7.0.3 并向 4.7 分支回移植；GitHub 已有公开 PoC，CVSS 因需社工交互定为 8.9。

3 严重

Flowise CVE-2026-69259：AI 低代码平台 SQLite 节点 RCE（CVSS 9.4）

CVSS 9.4 PoC 公开

GHSA-x3hf-7cj6-3r4m（8/4 发布）：Flowise < 3.1.3 的 SQLite Record Manager 节点把用户可控的 additionalConfig 展开到数据库设置之后，使 additionalConfig.database 覆盖 SQLite 路径。以 root 运行的官方 Docker 镜像可借此将数据库写到 /etc/chromium/exploit.conf，借助表名/命名空间注入 shell 语法，待 Puppeteer 启动 Chromium 加载该 conf 时触发反向 Shell（uid=0）。

值得关注：继 Langflow / Orkes / bank-vaults 之后，AI 编排/低代码平台再成 RCE 重灾区；CISA SSVC 已标记 exploitation: poc，官方 Advisory 内含完整利用 JSON。修复 3.1.3，并建议容器降权至非 root。

4 高危

Redis CVE-2026-66373：双重释放"补丁绕过"RCE，PoC 公开

CVSS 7.5 影响 < 8.8.0

MITRE 7/25 披露：Redis 流（Streams）功能在多个消费者共享同一未处理消息（NACK）时，XGROUP DELCONSUMER 删除消费者会二次释放本应只释放一次的内存，导致双重释放与条件性任意代码执行。根因是 CVE-2026-25243 的修复不完整——共享 NACK 手法绕过了既有对策，8/3 日文媒体披露 PoC 在多个版本全部验证成功。

值得关注："补丁后绕过"已成 RCE 复现常态（接 Redis QVD-2026-44936 / 7/23 的 8.8 绕过变体）；影响 8.8.0 以下全版本，认证用户+RESOURCE/XGROUP 权限即可触发，须升级 8.8.0 并收敛账号权限。

5 中高危

Apple macOS 屏幕共享认证绕过 CVE-2026-65400：同网无需密码控 Mac

状态：紧急 OOB 补丁

苹果 8/9 发布带外紧急更新（Tahoe 26.6.1 / Sequoia 15.7.9 / Sonoma 14.8.9），修复"屏幕共享"认证绕过：同网络内攻击者无需有效凭据即可直连已开启屏幕共享的 Mac，查看并控制桌面、文件与应用，甚至远程重启。

值得关注：仅手动开启屏幕共享且同网才可利用，互联网直接攻击面低；但苹果破例 OOB 单漏洞更新引发研究员警觉（Phil Stokes 等），疑似实际风险高于表面，建议尽快升级、临时关闭屏幕共享。

速览区

6. Plesk CVE-2026-64637：XML-RPC 提权至 root 管理员（9.9）

认证经销商账号经 XML-RPC API 提权获取 root 管理员会话；Plesk 托管海量站点，共享主机经销商凭据常流通，升级 18.0.80。

7. MSI Radix AXE6600 路由器 CVE-2026-71984：命令注入（9.8）

urlfilter/accesscontrol/dmz/telnetSSH 等多函数命令注入，公开 exp 可直接 root；家庭/小企路由器暴露面广，立即升级固件。

8. Apache Fory C++ CVE-2026-71558：反序列化堆类型混淆（9.8）

多态智能指针反序列化绕过类型兼容检查，无认证即可 RCE；exp 已公开，处理不可信序列化数据服务立即升级 1.5.0。

9. Snowflake 数据泄露主谋认罪：165 机构、$2.5M 二次勒索

加拿大籍黑客 Moucka 8/7 认罪，利用窃凭据入侵 165 家 Snowflake 客户、泄露数十亿记录；"付赎金后再勒索"暴露二次勒索新趋势。
