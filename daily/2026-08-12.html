1 严重

Ivanti EPM 预认证命令注入 RCE 入 CISA KEV

CVE-2026-72110 CVSS 9.8 · 在野 / KEV 大限 9/2

Ivanti Endpoint Manager 被披露未认证命令注入漏洞，攻击者可经 epm-agent 管理接口发送特制请求以 SYSTEM 权限执行任意命令，进而接管管理平面并横向移动至内网域。CISA 于 8/12 将其加入 KEV，联邦整改大限 9/2。

漏洞机制/攻击方式：

  • 类型：未认证命令注入（CWE-77）
  • 攻击方式：经 epm-agent 接口特制请求触发，以 SYSTEM 执行
  • 影响范围：暴露管理接口的 EPM 服务器及所管辖终端
  • 后果：管理平面沦陷、域内横向移动、全盘失守

值得关注的原因：

  • 延续 Ivanti 零日轮替（接 Connect Secure CVE-2026-65500），边界 + 管理平面双高危
  • KEV 整改窗口约三周，"披露即武器化"压力升高
  • 官方明确须重镜像清后门——补丁 ≠ 缓解
未认证攻击者 epm-agent 接口 命令注入 SYSTEM 执行 域失守
2 高危

Windows 内核提权 CVE-2026-35416 PoC 公开

CVE-2026-35416 CVSS 7.8 · 补丁已出 / PoC 公开

8/11 月度补丁修复的 Windows 内核本地提权簇之一 CVE-2026-35416 利用代码今日公开，普通用户可借此提升至 SYSTEM；同期多家机构再现"补丁 ≠ 修复"迹象——SharePoint 链式 RCE（CVE-2026-55040）仅打断前半链，未轮换机器密钥仍可被用于后补丁持久化。

值得关注：补丁落地 ≠ 威胁消除，机器密钥 / 凭据轮换才是真正缓解；内核 LPE 是容器逃逸与沙箱突破的前置条件。

3 高危

Open WebUI 认证前 RCE 公开 PoC

CVE-2026-70618 CVSS 9.1 · 在野风险 / PoC 公开

自托管 AI 门户 Open WebUI 被披露认证前远程代码执行漏洞，默认暴露且未授权端点可触发沙箱逃逸并在宿主执行命令，PoC 已公开。

值得关注：接 Langflow / Flowise / Metabase 零日，AI 中间件已成 RCE 重灾区；自托管 AI 网关集中托管模型密钥，沦陷即密钥库失守。

4 中高危

北美公立医院系统遭 Interlock / Chaos 勒索

医疗关基 约 12 家医院 EHR 中断

勒索软件运营商 targeting 北美医疗系统，造成约 12 家医院电子病历与调度系统停摆，部分急诊被迫转院。

值得关注：医疗关基持续承压（接 Gunra 袭水厂、SilentRansomGroup 律所）；停机直接威胁生命安全，OT/IT 混杂放大影响。

5 中高危

Linux 内核 Safe-RET 绕过变体提权 PoC

CVE-2026-68480 CVSS 8.8 · PoC 公开

Linux 内核提权防护机制 Safe-RET 的绕过变体 CVE-2026-68480 利用代码公开，本地低权用户可借此提升至 root（接 8/11 速览提及）。

值得关注：内核提权 PoC 公开即现实威胁，是容器逃逸与云原生横向移动的前置条件；与 io_uring / OVSwrap / Bad Epoll 构成年内高频 LPE 线。
