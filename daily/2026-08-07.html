2 高危

Linux suTrap 本地提权 PoC 公开（shadow-utils，TIOCSTI 终端注入）

影响：RHEL 9 / Rocky / Alma / CentOS 7 / Amazon Linux 2023 PoC 公开

安恒威胁情报中心于 2026-08-06 披露 Linux suTrap 本地权限提升漏洞细节与可用 PoC。当 root 以交互方式运行 su 切换至普通用户时，进程跳过终端隔离代码，目标用户继承 root 控制终端；攻击者滥用传统 TIOCSTI ioctl 向共享终端缓冲区注入按键，管理员输入 exit 时 root shell 将其作为合法命令执行，从而获取完整 root 权限。

修复：升级 shadow-utils 至 4.20.0+，或设内核参数 dev.tty.legacy_tiocsti=0 禁用传统 TIOCSTI。

3 高危

Pass-ta-key：Unit 42 揭示 Passkey 劫持新方法（无需提权）

影响：Chrome 同步型 Passkey 已通报 Google

Unit 42 披露 Pass-ta-key 攻击：已植入的恶意软件可读取 Chrome 本地同步数据库，识别 Passkey 保护账户并复用加密凭据材料欺骗云端验证器接管账户。三条路径均无需提权、不触发 MFA：①复用同步密钥记录冒充解密；②删除 Chrome 特定文件强制重验证颁发新密钥；③初始注册窗口期拦截明文主密钥夺取整个密钥库。

4 中高危

Zbtlink 路由器出厂预装后门 ENDLESSDOORS（21 款固件）

状态：厂商已下架固件

至少 20 款中国产 Zbtlink 路由器在出厂固件中预装后门 ENDLESSDOORS，伪装成内核进程获取未授权 root shell，影响 21 个固件版本。设备出厂即"自带"远程可控高权限后门，购买即暴露，极难被普通用户发现。

出厂固件 伪装内核进程 未授权 root shell 内网跳板/僵尸
