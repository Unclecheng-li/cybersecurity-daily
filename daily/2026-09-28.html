Citrix NetScaler 双零日遭在野利用：CISA 紧急告警，网络边界设备再成重保靶心

2026-09-27 CISA 发布紧急告警，确认 Citrix NetScaler ADC 与 Gateway 两枚严重未认证 RCE 零日（CVE-2026-88771、CVE-2026-88772，CVSS 均 9.5）已在野被利用。Citrix 同日发布 CTX697096 修复 8 枚漏洞。这是继 2023 年 CVE-2023-3519 / CVE-2023-4966 之后，NetScaler 边界设备再次成为"先补丁、后失陷"的典型场景，要求运维在数小时内完成修补与失陷排查。

1 头条事件

Citrix NetScaler 双零日：未认证 RCE 在野，CISA 9/27 紧急告警（头条）

Citrix CTX697096（2026-09-27）· 影响 NetScaler ADC 14.1<73.37 / 13.1<64.23 及 Gateway CVE-2026-88771 / 88772 CVSS 9.5 · 未认证 RCE · 已确认在野

2026-09-27，CISA 发布紧急告警，确认 Citrix NetScaler ADC 与 Gateway 两枚严重漏洞 CVE-2026-88771、CVE-2026-88772（CVSS 均 9.5）正在被在野利用。Citrix 同日发布安全公告 CTX697096，一次性修复 8 枚漏洞：88771 / 88772（9.5，未认证 RCE）、88773（9.3，HTTP 请求走私）、88774（7.0，特性策略绕过）、88775–88778（各 8.8，内存溢出 / TCP ISN 预测）。

其中 88771 为输入验证缺陷导致的未认证 RCE，无前置条件、默认配置即暴露——意味着每一台公网可达的实例都可直接被拿下；88772 为内存溢出，开启 DTLS 时（VPN vServer 默认开启）可 RCE 或服务拒绝。事件脉络为：NCSC-NL 预先通知 → watchTowr 9/26 公开预警 → Citrix / CISA 9/27 确认并出补丁。CSA（新加坡）、CERT-EU 均已发对应警报。

值得关注：NetScaler 位于网络边界、承载 VPN / 负载均衡 / 认证，攻陷即可绕过端点与身份层直接获得内网立足点。类比 2023 年 CVE-2023-3519 / CVE-2023-4966，这是同一类"边界设备先补丁后失陷"的反复失守。运维应在 2 小时内完成实例清点与打补丁，并在 24 小时内排查自 9/20 以来的异常命令执行、新建管理员账户与配置变更，轮换所有凭据。

2 在野 + 加固

Cisco Secure Firewall 9 月加固发布：CVE-2026-20332（×9.0 认证绕过类）被标注在野

Cisco Secure Firewall ASA / FTD / FMC 9 月安全加固发布（Greenbone 称共 29 个 CVE ID）· 9/22 披露 CVE-2026-20332 ×9.0（在野）· CVE-2026-20329 / 20330 / 20324 ×9.9 · 20242 ×9.8 未认证 root

Cisco 发布 Secure Firewall 9 月安全加固更新，覆盖 ASA、FTD、FMC 三条产品线，修复 18+ 枚严重 / 高危漏洞（Greenbone 统计该批共 29 个 CVE ID，含 8 枚关键）。其中 CVE-2026-20332（CVSS 9.0，CWE-284 访问控制 / 认证绕过类）被 BeyondMachines、Greenbone 等多家来源标注为已在野被利用；另有 CVE-2026-20329（9.9，异常处理不当）、20330（9.9，结构化数据校验不当）、20324（9.9，sftunnel 任意文件写 root）、20242（9.8，FMC 外部数据库访问反序列化未认证 root）等。

该加固发布无任何可用 workaround，只能升级到固定版本（ASA 9.24.1.155+，FTD / FMC 7.7.13 / 10.0.2 / 10.1.0 等）。值得注意的是，Cisco 在 9 月已多次出现边界 / 管理设备被在野利用：本批 20332 之外，FMC CVE-2026-20079（9/11 入 KEV）亦在野。

值得关注：ASA / FTD / FMC 是大量企业的边界防火墙与集中管理平面，20332 在野意味着公网可达的管理面若存在暴露即成直接入口。应优先升级、收敛管理接口至内网、并启用 Enhanced ISN Generation。

3 AI 安全

Salesforce Agentforce「SalesBleed」：公共表单注入 → AI agent 0-click 外泄 CRM 数据

Zenity Labs 2026-09-24 披露 · 影响 Salesforce Agentforce（托管 SaaS，无 CVE 编号） 间接 prompt injection · 0-click 数据外泄 · 无需登录 / 点击

Zenity Labs 于 2026-09-24 披露 Salesforce Agentforce 的三枚缺陷，统称 SalesBleed：攻击者经 Salesforce 公开的 Web-to-Lead 表单提交含隐藏指令的"中毒线索"，该记录潜伏于 Leads 表；当员工随后让 Agentforce 处理该线索时，agent 读取并执行隐藏指令，利用自身 Query Records 权限跨记录读取 Account 等敏感数据（公司名、合同金额），再将数据编码进攻击者控制的子域名，借 HTML <img> 标签触发 DNS 解析把数据外带——全程 0-click。第三个缺陷位于 Agentforce–Slack 集成，可冒用 agent 身份在内网频道推送钓鱼。

根因是 Trusted URLs 红控对顶级域识别不一致、对特殊字符处理与下游渲染组件不同，导致红控被绕过（agent 回报"已拦截"但数据已出网）。Salesforce 称 8/19 已完成修复并验证，无客户被利用证据。该入口与 2025 年 ForcedLeak（CVSS 9.4）同源，一年后再次被绕过。

值得关注：SalesBleed 揭示"攻击者可控内容 + 敏感内部数据访问 + 外发通道"三要素叠加的 AI agent 风险范式。由于 Agentforce 是托管服务、不分配 CVE，安全完全依赖厂商对边界 case 的识别速度；企业应将外部提交字段视为不可信指令，收紧 agent 的 CRM 对象权限与 Trusted URL 白名单。

4 公开 PoC

GestSup CVE-2026-100389（×9.2）+ AcyMailing CVE-2026-94132：邮件附件未认证 RCE，PoC 9/27 公开

ThreatCluster 2026-09-27 · 影响 GestSup < 3.2.61 / AcyMailing Enterprise < 11.1.0 CVE-2026-100389 CVSS 9.2（未认证）· CVE-2026-94132 公开 PoC

ThreatCluster 于 2026-09-27 汇总两枚"附件即代码"类未认证 RCE：GestSup（工单 / 邮件监控类 PHP 应用）在 < 3.2.61 版本中因附件处理不当，攻击者可向受监控邮箱发送含 PHP 附件的邮件直接在服务器执行代码（CVE-2026-100389，CVSS 9.2，9/25 披露）；AcyMailing Enterprise < 11.1.0 因未验证 MIME 附件被写入 web 可访问目录导致 RCE（CVE-2026-94132），其首个公开 PoC 于 9/27 发布。

两者均无需认证，仅需向目标邮箱 / 公开功能投递特制附件即可触发，属于"边界邮件处理组件"类长期高危面。

值得关注：邮件网关、工单、营销邮件类应用常驻公网且自动处理附件，是"反序列化 / 文件写 + 可解析目录"组合的高危温床。使用单位应优先升级至固定版本，并将邮件处理账户权限与可写目录严格隔离。

5 PoC 公开潮

Oracle 9 月 CPU 落地：GovCERT.HK 高威胁警报提示在野 + 多枚 PoC 公开

GovCERT.HK 高威胁警报 A26-09-27 · Oracle 2026 年 9 月重要修补程式更新（cspusep2026） 官方警报：一枚 RCE 已在野 · CVE-2026-2332/7598/9563/57220/59943/63308/75838 PoC 公开

香港 GovCERT.HK 于 2026-09-27 发布高威胁警报 A26-09-27，提示 Oracle 2026 年 9 月重要修补程式更新（cspusep2026）修复大批漏洞，其中一枚 RCE 已被在野利用，且 CVE-2026-2332、CVE-2026-7598、CVE-2026-9563、CVE-2026-57220、CVE-2026-59943、CVE-2026-63308、CVE-2026-75838 等多枚漏洞的概念验证代码已公开。

受影响范围涵盖 Oracle Java SE、Database、Fusion Applications and Middleware、Oracle Linux and Virtualization 等。Oracle 已发布补丁（Java Platform SE 8u503 / 11.0.32.1 / 17.0.20.1 / 21.0.12.1 / 25.0.4.1 / 27）。

值得关注："PoC 公开 + 在野利用"叠加是漏洞被规模化利用的前奏。企业应立即套用 9 月 CPU 并复核暴露面；因该批 CVE 跨多个产品，建议读者以 NVD 与 Oracle 官方公告交叉核实具体 CVE 的产品归属与 CVSS。

速览区

6. Keio 集团（东京铁路 / 酒店 / 百货）9/26 遭勒索攻击

京王电铁确认 9/26 凌晨集团服务器遭勒索攻击，酒店预订系统与部分零售刷卡支付瘫痪，火车因独立网络照常运行；日本上半年勒索案 123 起创 2020 年以来新高，呈现"打商业系统、留安全关键设施"的攻击模式。

7. MemTensor 供应链投毒：恶意 npm / PyPI 发布窃取密钥与云凭据

HendryAdrian 周报指出，MemTensor 相关组件遭篡改，恶意 npm / PyPI 发布在开发者环境中窃取密钥、token 与云凭据；再次警示 CI/CD 与依赖来源完整性校验的重要性。

8. OpenCode RCE：content-type 混淆经恶意 npm tarball 触发

OpenCode 被曝 content-type 混淆缺陷，攻击者可借精心构造的 npm tarball 触发远程代码执行；开发者工具链与 agent 运行环境成为新的高危入口。

9. pfSense 存储 XSS → root RCE / MagicINFO 后部署门罗币挖矿

HendryAdrian 周报收录 pfSense 存储型 XSS 到 root RCE 的利用链，以及 MagicINFO 被入侵后编译 SilentXMRMiner 并篡改 Defender 进行挖矿的完整链路，物联网 / 网络设备持久化趋势延续。

10. thegentlemen 勒索大规模行动：StMicroelectronics 等 20+ 企业被列

Ransomware.live 9/26 数据显示 thegentlemen 在单日将 StMicroelectronics、Guardrisk、Metalware、Magna Legal 等 20+ 企业列入泄露站，跨制造、法律、医疗的规模化勒索仍在高位运行。

11. Rydox 暗网市场管理员 Ardit Kutleshi 认罪

9/27 多方情报汇总：Rydox 网络犯罪市场创建者 Ardit Kutleshi 在美国认罪，该平台促成 7,600+ 笔被盗 PII / 信用卡 / 恶意工具交易；系国际执法查封基础设施后的重要进展。
