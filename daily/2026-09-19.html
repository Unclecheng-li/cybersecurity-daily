Check Point 登录栈溢出 CVE-2026-91843（CVSS 9.8）预认证 root RCE：未认证发送超长用户名即可拿下安全管控平面

2026-09-16 披露，Check Point Security Management / Log Server / Multi-Domain Servers 登录进程存在 CWE-121 栈溢出；攻击者无需凭证即可触发 root 级代码执行，全球约 3,836 台主机暴露，官方已通过 LivePatch 热修。

1 高危

Check Point CVE-2026-91843：CVSS 9.8 预认证 root RCE，安全设备自身被攻破（头条）

Check Point 2026-09-16 披露 · CWE-121 CVSS 9.8 · 影响安全管理/日志/多域服务器

Check Point 多款安全管理产品的登录进程存在 CWE-121 栈缓冲区溢出：攻击者在未认证状态下发送超长 username 字段，即可覆盖返回地址、在宿主以 root 权限执行原生代码。2026-09-16 披露，官方通过 LivePatch 修复（R82.20 take 29、R82.10/R82/R81.20 take 28）。

全球约 3,836 台相关主机暴露，目前尚未观测到在野利用，但「预认证 + root RCE」意味着一旦被扫描利用即可直接接管安全管控平面——防御系统本身先被攻破。

值得关注：安全设备 RCE 历来是 APT 与勒索的优先目标；运行 Check Point 管理平台的组织应立即确认 LivePatch 已应用，并监控异常登录与 outbound 连接。

暴露登录接口 超长 username 触发 栈溢出 CWE-121 覆盖返回地址 预认证 root RCE 接管安全管控平面
2 严重

Azure AI Foundry CVE-2026-85889（CVSS 10.0）缺失认证提权，微软已在服务端缓解

Azure AI Foundry 2026-09-17 · CWE-306 CVSS 10.0 · 网络可达提权

Azure AI Foundry 存在 CWE-306 缺失身份验证漏洞，攻击者可借此在网络层面提升权限（CVSS 10.0）。该漏洞于 2026-09-17 由研究者 Rémy Marot 披露。

关键处置：微软已在服务端完成缓解，客户无需自行操作。关联披露还包括 CVE-2026-85885（Copilot 命令注入 9.9）、CVE-2026-85878（PostgreSQL 9.9）、CVE-2026-87701（Cosmos DB 9.6）。

值得关注：AI 基础设施平台正成为高危目标，但本次由云厂商兜底缓解，实际风险被大幅压低，体现「平台级责任共担」的价值。

3 严重

Prebid Server Java CVE-2026-54734（CVSS 10.0）SSRF，竞价服务端转向内网

Prebid Server Java 2026-09-17 · CWE-918 CVSS 10.0 · 影响 <3.43.0

Prebid Server Java 的 bidder adapters 将用户可控参数直接拼入 URL，未经过 HttpUtil 校验，导致 CWE-918 服务端请求伪造（CVSS 10.0）。影响 < 3.43.0，修复版本 3.43.0（2026-09-17 披露）。

SSRF 在广告/竞价服务端可转向云元数据 endpoint 与内网资产，进而窃取实例凭据、横向移动。

值得关注：广告技术栈常位于公网边界且信任内部网络，SSRF 是其经典高危面；运营方应升级 3.43.0 并启用出网白名单。

4 高危

Docker CVE-2026-77179（+ CVE-2026-79994）macOS 沙箱符号链接逃逸

Docker 2026-09-07/09-15 · CWE-59/367 CVSS 9.4(CVSS4) + 8.7 · 0.28.0–0.42.0

CVE-2026-77179（CVSS 9.4/CVSS 4.0，CWE-59 符号链接）：macOS Docker Sandboxes 的 virtio-fs 宿主服务端缺陷，影响 0.28.0–0.42.0，修复 0.42.0（2026-09-07 披露）。

同批 CVE-2026-79994（CVSS 8.7 High，CWE-367 TOCTOU）：Unix socket 中继缺陷，影响 0.37.0–0.42.0。

值得关注：容器/沙箱逃逸直接威胁宿主机隔离边界；开发机与 CI runners 应升级到 0.42.0 及以上。

5 高危

Linux 内核 CVE-2025-39964 + CVE-2026-53266 入 CISA KEV（9/18 新增，9/21 大限）

CISA KEV 2026-09-18 · BOD 26-04 CVSS 7.8 + 8.8 · 本地低权限

CVE-2025-39964：crypto af_alg 竞态条件（CWE-362，CVSS 7.8）。CVE-2026-53266：bridge netfilter ebtables 越界写（CVSS 8.8）。

两枚漏洞于 2026-09-18 加入 CISA KEV，修复截止日 2026-09-21，依据 BOD 26-04；均为本地攻击向量、低权限即可触发。

值得关注：联邦机构大限临近，Linux 提权链常被勒索软件与容器逃逸复用；云主机与多租户节点应优先打内核补丁。

速览区

6. WordPress Click2Shell：WP 7.1.1 强制安装主题链 RCE（暂无 CVE）

2026-09-17 披露，WordPress 7.1.1 可通过构造 URL 强制安装主题，单独 CVSS 7.1、链式可达 9.6（Mobile Repair Zone 主题）；尚无 CVE 编号，暂未在野，但已被列为需尽快修补的 Web 高危面。

7. CISA 发布 8 份 ICS 公告（9/17）：Hitachi Energy FACTS 最高 9.9

ICSA-26-260 系列含 Hitachi Energy FACTS（ICSA-26-260-03，最高 9.9，CVE-2024-4872/3980/3982/7940/7941）、Schneider Modicon M340（CVE-2025-6625 FTP DoS）、ABB Edgenius 等，覆盖电力与工业控制场景。

8. FamousSparrow SparroWocky：ESET 报告新模块化 C++ 后门

9/17 报告，取代 SparrowDoor，覆盖阿根廷、厄瓜多尔、危地马拉、洪都拉斯、巴拿马、秘鲁、波多黎各、委内瑞拉等 8 个拉美国家；DLL 侧加载三戟加载器（winfsp-x64.dll / DukeQt.dll），18 个 C2（443/8080）。

9. FBI 查封 NightmareStresser：行动 PowerOFF 拿下 DDoS-for-hire

2026-09-15 查封，566,000+ 用户、100+ 域名、12 人被诉；域名 nightmare-stresser.com / nightmarestresser.org 已被执法接管，是近年规模最大的 DDoS 租赁打击之一。

10. PhantomRaven：LLM 生成的 npm 窃密包，126 包 / 86K 下载

CrowdStrike 9/15 分析，借 preinstall 脚本与远程动态依赖外泄 CI/CD 密钥；疑似 bug-bounty 猎人动机（账户 jpdhellonpm1、jpd15），包名如 transform-jsbi-to-bigint、sort-imports-es6-autofix。

11. RatHat：Zimperium 报告 Android AI 木马

9/16–17 报告，滥用无障碍 + 无线 ADB；Go 代理 liblocal-service.so 与 FRP libmedia_codec.so，疑似中方关联（中文 LLM 提示词转 Google Gemini 做 UI 导航），硬件级键录 + 自恢复持久化。
