Cisco Secure Email Gateway 邮件解析 SQL 注入 CVE-2026-76461：未认证即可 root 执行命令，CISA 当日列入 KEV（CVSS 9.8）

攻击入口就是一封构造好的邮件——网关是否暴露公网都不豁免。Cisco 于 9/14 披露并同步被 CISA 纳入 KEV，要求 9/17 前完成处置；官方明确"无临时缓解措施，只能升级"。

1 严重

Cisco Secure Email Gateway CVE-2026-76461 — 未认证 root RCE（头条）

CVE-2026-76461 · CWE-89 SQL 注入 · AsyncOS 邮件解析 CVSS 9.8 · KEV 9/14 · 截止 9/17

Cisco Secure Email Gateway（物理与虚拟设备均受影响）的邮件解析逻辑存在 SQL 注入（CWE-89）：攻击者只需向网关投递一封含恶意 SQL 语句的邮件，解析校验不足即导致注入，进而以 root 权限在底层操作系统执行任意命令，完全控制这台处于互联网边界/管理边界的邮件安全网关。

Cisco 于 2026-09-14 披露（cisco-sa-esa-inj-2bLVGmhX），CVSS 3.1 基础分 9.8（AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H）；CISA 同日将其纳入 KEV，联邦处置截止 2026-09-17。Cisco PSIRT 确认已发现活跃在野利用，且无临时缓解措施，只能升级。

值得关注的原因：修复版本 15.5.5-014 / 16.0.4-302 / 16.5.0-780（Cisco 建议直接迁移）；Secure Email Cloud 已由 Cisco 后台升级。失陷后可直接触达远程访问、流量审计、凭据与下游系统信任。排查：核查 mail_logs 中 COPY ... TO PROGRAM 等可疑 SQL，比对设备外网/防火墙日志中的异常出站上传。

投递构造邮件(含恶意SQL) 邮件解析 SQL 注入 读写底层数据库 root 执行系统命令 接管邮件安全网关
2 严重

Linux 内核 ZDI 协调披露 22 项漏洞（ZDI-26-681 ~ ZDI-26-701）

NTFS3 / KSMBD / NFSv4 / OpenvSwitch / FUSE RCE + LPE · CVE-2026-72191×9.8

Zero Day Initiative 于 2026-09-14 一次性发布 22 份 Linux 内核协调披露通告，覆盖 NTFS3、KSMBD、NFSv4 server、OpenvSwitch、nftables、NFC NCI UART、FUSE、IPv6 组播路由等子系统。类型含本地提权（LPE）、远程代码执行（RCE）与信息泄露，根因涵盖竞态、UAF、越界读、未初始化内存。

NTFS3 类堆溢出（如 CVE-2026-72191 / CVE-2026-72192，CVSS 9.8）本地挂载恶意镜像即可触发内核内存破坏。Linux 是绝大多数服务器/云/容器基础设施的底座，KSMBD、NFSv4、NTFS3 直接关联 RCE 风险——建议优先修补并禁用未使用的内核模块。

3 高危

Vite 开发服务器大规模扫描窃取云凭据（CVE-2026-39364）

CVE-2026-39364 · CWE-200 · server.fs.deny 绕过 CVSS 7.5 · F5 蜜罐 807 攻击

Vite 开发服务器文件读取/访问绕过漏洞 CVE-2026-39364（CVSS 7.5），影响 7.1.0–7.3.2 与 8.x（<8.0.5）。通过 ?raw、?import&raw、?import&url&inline 等参数绕过 server.fs.deny，以 HTTP 200 明文返回本应受保护的文件。

F5 蜜罐 8 月捕获 807 次攻击会话、约 32,000 条原始事件；攻击者系统化拖取 .env、AWS/Azure 凭据、Terraform state、/proc/self/environ，并复用 CVE-2025-31125（已在 KEV）。修复：升级 8.0.5 / 7.3.3，封锁 5173 端口与可疑 /@fs/ 请求，轮换可能暴露的密钥。

4 严重

搜狗输入法 CVE-2026-51990 一键 RCE → GRAYRABBIT 后门（UNC3569）

CVE-2026-51990 · sgbiz: 协议 · CEF webview 一键 RCE · 中国关联 UNC3569

Tencent 搜狗输入法 Windows 版 CVE-2026-51990（一键 RCE）：sgbiz: 自定义协议处理器参数校验缺失 → 加载攻击者控制的 CEF webview（基于 Chromium 80，无沙箱、关闭多项安全保护）→ 利用已知 V8 类型混淆（CVE-2021-38003）实现代码执行 → 投放 GRAYRABBIT 后门（反向 shell / 文件传输 / 内存加载插件）。

中国关联组织 UNC3569 已在真实入侵中利用；搜狗装机量以亿计，单点一次点击即可系统级失陷。Tencent 已在 16.3.0.3498 修复协议滥用，但内嵌浏览器仍老旧且无沙箱，残余风险仍在。

5 中危

Apple macOS Tahoe 安全公报 SB2026091501（153 项漏洞）

SB2026091501 · macOS Tahoe · 153 漏洞 安全事件 · 9/15 发布

Apple 于 2026-09-15 发布 macOS Tahoe 安全更新，一次性修复 153 项漏洞（High 5% / Medium 9% / Low 86%）。其中 APFS 越界写 CVE-2026-84523（CVSS 4.8，本地提权）、Accelerate Framework 越界写 CVE-2026-86882 等。

虽以中低危为主，但涉及 APFS/Framework 提权与信息泄露，对企业 macOS fleet 的基线加固与统一补丁管理仍是刚需。

速览区

6. Microsoft 9/14 带外紧急更新修复 RDS 故障

修复 9 月补丁引发的 Windows Server RDS 连接/登录失败（含 MMC、文件资源管理器异常）及 Hyper-V 共享文件夹、部分 USB 音频问题；不要靠卸载 9 月安全更新来"修复"，否则丢掉本月 966 个漏洞修复。

7. 日本 Digital Agency 网络入侵

VPN 入口被突破，约 24.6 万条人事数据可能外泄，已通报隐私监管机构，影响评估持续升级。

8. Revolut 数据泄露

攻击者冒充政府机构实施社工，导致身份文件与金融记录暴露，资金虽未直接受影响，但身份与欺诈风险上升。

9. Twitch JeetBot OAuth token 泄露

恶意 Twitch 扩展（JeetBot）暴露近 31,000 名用户的 OAuth bearer token，账号接管风险持续，需吊销令牌并轮换凭据。

10. EFM ipTIME C200E CVE-2026-90847（公开 PoC）

系统设置 iux_set.cgi 操作系统命令注入（CVSS 9.1），exploit 已公开、远程可达，需尽快升级或限制管理面暴露。

11. 越南 APIS 2.2 亿旅客记录暴露

Kinryū Labs 发现一个暴露的 Elasticsearch 集群，含 2.2 亿+ 乘客与机组人员记录，演变为大规模隐私与身份风险事件。
