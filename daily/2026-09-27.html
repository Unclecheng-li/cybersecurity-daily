Kiteworks 全球紧急关停：疑似零日迫使客户停服 6–9 小时，安全文件共享 SaaS 再成重保靶心

2026-09-26 Kiteworks（原 Accellion）向全球客户下发紧急关停指令，要求将系统下线 6–9 小时以应对"迫在眉睫的疑似零日攻击"。这是近月来继多起供应链 SaaS 被袭后，又一例厂商以"预防性停机"应对未知在野利用的事件，凸显高价值文件交换平台的暴露风险。

1 头条事件

Kiteworks 紧急关停：疑似零日引发全球预防性停机（头条）

Kiteworks（原 Accellion）2026-09-26 安全通告 · 影响 Kiteworks 安全文件共享平台 疑似零日 · 预防性停机 6–9 小时 · 暂未分配 CVE

2026-09-26，企业安全文件共享厂商 Kiteworks（前身为 Accellion）向全球客户发出紧急指令，要求将系统下线 6–9 小时，原因是收到了关于"迫在眉睫的网络攻击"的可信威胁情报，疑似涉及零日漏洞。多家媒体（The Hacker News、BleepingComputer）确认该动作是预防性停机，而非已确认的入侵。

Kiteworks 平台长期承载法律、医疗、政府等敏感文件的跨方交换，是勒索与情报收集的高价值目标。2021 年其前身 Accellion FTA 曾因严重漏洞遭大规模勒索利用，本次事件显示同类"高价值文件交换 SaaS"仍是攻击焦点。在官方补丁与细节公布前，唯一可用的缓解即按厂商建议临时停机并保全日志。

值得关注：这是本月第二起"以停机应对疑似零日"的重大供应链事件，反映厂商对未知在野利用的处置正转向激进 Preventive Shutdown。运维方应在服务恢复前完成日志留存、认证与管理事件审查，排查未授权文件与配置变更，并将 Kiteworks 暴露面纳入持续监控。

2 KEV 在野

Microsoft SharePoint CVE-2026-65660：代码注入 RCE 入 CISA KEV，9/28 联邦大限

CISA KEV 2026-09-25 加入 · MSRC 8 月补丁（SE 16.0.19725.20522 / 2019 16.0.10417.20198 / 2016 16.0.5565.1001） CVSS 8.8 · CWE-94 代码注入 · 需低权限账户

Microsoft SharePoint Server 的代码注入漏洞 CVE-2026-65660（CWE-94）于 9/25 被 CISA 列入 KEV，联邦整改截止 9/28。该漏洞最初被标为"欺骗"（6.5），9/11 升级为 RCE（8.8），9/25 Microsoft 确认已观测到在野利用。影响 SharePoint Server 2016 / 2019 / Subscription Edition 本地部署。

漏洞位于网页部件（web part）编辑路径，允许已认证低权限用户绕过服务端安全检查执行任意代码，且可内存态利用，传统"查 LAYOUTS 目录异常 .aspx"的排查可能失效。研究者 Dinh Ho Anh Khoa（Viettel，ToolShell 链作者）发现。可结合 6/9 的身份认证绕过实现未认证利用。

值得关注：PR:L 不等于安全——低权限 SharePoint 账户极易经钓鱼 / 信息窃取器获得。CISA 将其技术影响评为 total，9/28 短窗口说明形势紧迫，所有本地场站应立即套用 8 月补丁。

3 在野

Oracle PeopleSoft CVE-2026-35273：ShinyHunters 借 /%50SEMHUB/ 编码绕过 WAF，数十台系统沦陷

Mandiant / Google TI 2026-09-26 披露 · Oracle 6/10 带外安全更新 CVSS 9.8 · 未认证 RCE · PSEMHUB 反序列化

UNC6240（ShinyHunters）重启对 Oracle PeopleSoft CVE-2026-35273（CVSS 9.8，Environment Management Hub 反序列化 RCE）的大规模利用。新手法仅将请求路径 /PSEMHUB/ 改为 /%50SEMHUB/——把字母 P 做 URL 编码——多数 WAF / 反代在解码前匹配字面量而放行，PeopleSoft（WebLogic）解码后照常路由到脆弱 servlet，使"已用 WAF 缓解"的系统重新暴露。

Mandiant 在高等教育、科技、IT 服务、医疗、农业、交通、政府等行业的数十台系统上发现 JSP webshell（x.jsp / u.jsp）与 SIDEYE 后门（Ple64.exe，带有效签名），并辅以 Neo-reGeorg 隧道与合法 MeshAgent 维持驻留。该团伙此前声称借 PeopleSoft 零日攻入 FBI 招聘门户。

值得关注：这是"补丁 + 路径封禁 ≠ 安全"的典型反面教材。Oracle 6/10 已发补丁，缓解还应禁用 EMHub、对规范化后路径做匹配、排查异常 .jsp 并轮换应用账号凭据。

4 批量内核

Linux 内核驱动簇 5 枚 CVE（9/26）：qla2xxx / SMB / HINIC / x86 内存损坏

kernel.org CNA 2026-09-25/26 披露 · 修复见各 stable 提交 CVSS 8.8×4 + 8.2 · 竞态 / UAF / 堆溢出

9/26 一批 Linux 内核漏洞集中披露：qla2xxx SCSI 驱动 CVE-2026-97527（竞态，fcport 未加锁，AV:A）、CVE-2026-97528（NVMe unsolicited ctx UAF，均 8.8）；SMB/CIFS 客户端 CVE-2026-97555（重写 DACL SID 时堆溢出 8.8）；HINIC 网卡驱动 CVE-2026-97957（邮箱段长校验不足 16 字节堆溢出 8.8）；x86 内存管理 CVE-2026-97525（拆分页表未标记内核页表，8.2）。

这些漏洞影响依赖 Fibre Channel / NVMe-oF 存储、Windows 文件共享客户端、HINIC 网卡及特定 x86 内存管理路径的系统；qla2xxx 与 HINIC 需邻接或本地加载驱动，SMB 客户端路径在频繁访问 Windows 共享时最危险。

值得关注：虽尚未入 KEV，但 CVSS 均 ≥8.2 且涉及内核内存破坏。应按实际驱动使用情况，优先应用发行版内核更新；HINIC / qla2xxx 在无法立即打补丁时可评估禁用驱动的业务影响。

5 重大事件

Bitget 3.516 亿美元失窃：疑似朝鲜 APT 入侵后端基础设施，部分地址已冻结

2026-09-26 多家媒体披露 · 中心化交易所 Bitget 供应链 / 入侵事件 · 热钱包 + 温钱包损失

加密货币交易所 Bitget 于 2026-09-26 遭未授权转账，损失约 3.516 亿美元。多家安全媒体将矛头指向疑似朝鲜相关威胁行为者——攻击者入侵了交易所后端基础设施，而非仅突破前端热钱包；部分与攻击者关联的链上地址已被冻结。

朝鲜 APT（如 TraderTraitor / Lazarus 关联集群）长期以交易所、跨链桥、托管平台为目标的手法高度吻合：通过社会工程或供应链渗透拿到后台权限，再直接操纵冷热钱包流转。此类事件往往伴随对开发人员与运维链路的初始入侵。

值得关注：继多起大型交易所被盗后，本次再次凸显"后端基础设施渗透 > 单点钱包漏洞"的趋势。交易所应强化后端最小权限、密钥分片与多签、以及针对内部研发 / 运维链路的供应链防护。

速览区

6. MikroTik RouterOS CVE-2026-67279 入 KEV（MikroTrick 链）

9/25 CISA 将 MikroTik RouterOS 的 CVE-2026-67279（×6.9，会话通道 exec 请求）与 CVE-2026-86060 串为 MikroTrick 链列入 KEV，9/28 截止；未认证即可无密码拿下管理控制台，Bishop Fox 已在 7.x 复现完整接管。

7. cPanel 提权簇 CVE-2026-87899 / 87900 / 68490

cPanel 修复多处高危：CalDAV/CardDAV 本地认证用户提权至 root（CVE-2026-87899）、WP Toolkit 跨账户数据库操作（CVE-2026-87900）、日历数据越权暴露（CVE-2026-68490）；托管面板应优先升级。

8. Google Chrome 154 修复 108 漏洞（含 11 严重）

Chrome 154 稳定版修复 108 枚漏洞，其中 11 枚为 ANGLE / WebGL / GPU / ServiceWorker 子系统内存破坏严重级；建议立即更新并重启浏览器进程。

9. Elementor WordPress 插件未认证 CSRF（×8.8，无 CVE）

高危 CSRF 允许管理员点击伪造链接后创建恶意管理员账号，导致整站沦陷；尚无 CVE 编号，WordPress 站点应更新 Elementor 并审计管理员账户与登录历史。

10. Mini Shai-Hulud 复活被破坏 GitHub Actions

此前在 Mini Shai-Hulud 供应链活动中被破坏、被维护者短暂恢复的 GitHub Actions 被重新激活，在下游 CI/CD 流水线中再次执行恶意代码，提示需全面审查仓库 Actions 与密钥。

11. 自主 AI agent 盗取 60 万张信用卡

一起自动化攻击利用 Strix / Cairn / Hermes(Claude-Opus-4.6) 等 AI 框架，自动扫描、利用并注入支付 skimmer，波及 27 家组织、119 个电商站点，盗取逾 60 万张信用卡，显示 AI agent 正规模化用于金融窃取。
