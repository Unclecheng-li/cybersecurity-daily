Ivanti Neurons for ITSM 九月补丁释出 8 漏洞簇：三枚 9.9 缺失授权 RCE + 两枚未认证 RCE + Sentry 8.1 认证绕过

9/8 Ivanti 一次性修复 Neurons for ITSM 8 个漏洞（6 个可 RCE），其中 CVE-2026-12744/12745 为无需凭据的未认证 RCE（9.8）、CVE-2026-12645/12646/12647 为 9.9 缺失授权 RCE；Sentry CVE-2026-83527（8.1）可未认证直取管理员。Enigma 将其标记为 exploit 公开可用，Ivanti 称暂无在野利用证据。

1 严重

Ivanti Neurons for ITSM 8 漏洞簇（头条）：三枚 9.9 RCE + 两枚未认证 RCE + Sentry 管理员接管

CVE-2026-12645/12646/12647 ×9.9 · 12744/12745 ×9.8 未认证 · Sentry 83527 ×8.1 9/8 披露 · 10 CVE 跨 3 产品

Ivanti 于 9/8 发布 2026 年 9 月安全更新，覆盖 Neurons for ITSM、Sentry、EPMM 三款企业产品，合计披露 10 个 CVE。Neurons for ITSM 一次性修复 8 个漏洞、6 个为可 RCE 的严重级：

  • CVE-2026-12645 / 12646 / 12647（CVSS 9.9，CWE-862 缺失授权）—— 已认证攻击者即可远程执行任意代码。
  • CVE-2026-12744 / 12745（CVSS 9.8，CWE-502 反序列化）—— 无需任何凭据即可在服务器执行任意代码。
  • 另含反序列化 CVE-2026-12650（9.9）、CVE-2026-12651 / 12648（高危）。
  • Sentry CVE-2026-83527（CVSS 8.1，CWE-288 认证绕过）—— 未认证远程攻击者直接拿到管理员权限（修复于 R10.8.2 / R10.7.3 / R10.6.4）。

值得注意的是：Ivanti 在公告中首次明确提及这些 ITSM 漏洞由内部 LLM 辅助发现。受影响范围为本地部署版 Neurons for ITSM 2025.2–2026.1（SaaS/云版已于 8/9 自动修复，2026.2 于 9/21 发布）。

值得关注的原因：ITSM/MDM 是企业内网核心基础设施，本地暴露实例一旦被 RCE 即成为立足点与横向跳板；Enigma 将缺失授权 RCE 标记为 exploit 公开可用，公网暴露的本地部署应立即升级并排查异常管理会话。

2 严重

Google Cloud ADK for Python CVE-2026-79696（CVSS 10.0）—— 不完整 denylist 致未认证 RCE

CVE-2026-79696 · CWE-184 · ADK 2.0.0-2.6.0 CVSS 10.0 · 9/9 披露

Google Cloud Agent Development Kit（ADK）for Python 的 adk web 组件存在代码注入（CWE-184 不完整禁用输入清单）：其 agent 配置的代码引用解析器依赖一份手工维护的「危险标准库」黑名单（拦了 profile 却漏了 cProfile），导致 cProfile.run / timeit.timeit / trace.Trace 等可在 pytest 安装的 OSS / Cloud Run / GKE 环境中，被未认证攻击者通过构造的 test session replay 执行任意代码。CVSS 4.0 满分 10.0。修复于 ADK 2.7.0（改为完整标准库全拦截）。

这是典型的「denylist vs allowlist」反模式在 AI Agent 框架上的真实翻车——AI 开发工具链（Agent SDK / MCP / tool-calling）正成为新攻击面，而 ADK 是云上 Agent 工作负载的主流底座。临时缓解：不把 adk web 暴露到不可信网络、生产环境去掉 pytest。

3 严重

Adobe Campaign Classic CVE-2026-82004（CVSS 10.0）—— 未认证 OS 命令注入 RCE

CVE-2026-82004 · CWE-78 · APSB26-142 CVSS 10.0 · Priority 1

Adobe 于 9/8 在 APSB26-142 修复 ACC 的 OS 命令注入（CWE-78），CVSS 3.1 10.0（AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H），影响 ACC v7 ≤ 7.4.4 build 9401，修复版本 7.4.4 build 9402（Adobe 标为 Priority 1，3 天内修复）。

无需认证、无需用户交互，攻击者可借未净化的输入在服务器以当前用户身份执行任意系统命令。Campaign Classic 是大量企业营销自动化底座、常驻敏感客户数据，完全本地部署实例若暴露公网即面临勒索 / 数据窃取 / 横向移动的直接风险；应即刻升级并收敛管理接口暴露面。

4 严重

Perforce Akana API Platform CVE-2026-85978（CVSS 10.0）—— 路径归一化绕过认证 → 未认证 RCE

CVE-2026-85978 · CWE-41/863/94 CVSS 10.0 · Policy Manager

Akana API Platform 的 Policy Manager 控制台存在认证过滤器与 servlet 分发器之间的路径归一化/等价性差异（CWE-41/CWE-863）：攻击者发送经特殊构造、被两者以不同方式解释的路径，即可绕过认证，触达一个无沙箱执行攻击者脚本代码的端点（CWE-94 代码注入），达成未认证、无交互的 RCE。CVSS 4.0 10.0。受影响的默认配置包括除 2024.1.6 / 2025.1.2 / 2026.2 之外的所有版本。

API 网关 / 策略管理控制台是微服务架构的「中枢」，且常面向内网甚至公网管理面；路径归一化绕过是认证绕过的经典高危模式。临时缓解：限制控制台至可信内网。

5 高危

ConnectWise ScreenConnect CVE-2026-84869（CVSS 9.9）—— 客户端未授权文件传输/执行（MSP 供应链风险）

CVE-2026-84869 · CWE-862/269 · 26.6.5 CVSS 9.9 · 仅客户端

ConnectWise 于 9/8 发布 26.6.5 安全补丁，修复 ScreenConnect 客户端的缺失授权（CWE-862）/ 不当权限管理（CWE-269）缺陷：在活跃远程会话中，文件可被无需授权、无需 Host 确认地传输并执行（CVSS 3.1 9.9，AV:N/AC:L/PR:L/UI:N/S:C）。服务端不受影响，仅客户端受影响。

ScreenConnect 是 MSP 管理数千终端的标配，单一被劫持的远程会话即可级联成供应链攻击；勒索团伙与初始访问经纪长期将其列为重点目标。临时缓解：在角色中取消 TransferFiles 权限、要求 Host 对所有文件传输/执行确认。云端已自动升级，本地需升 26.6.5 并重新部署客户端。

速览区

6. Dell Secure Connect Gateway CVE-2026-80172（CVSS 9.8）9/9 披露

数据真实性验证不足（CWE-345）：远程未认证攻击者在捕获单条合法请求后，可反复重放以生成有效的 ADMIN 访问与刷新令牌（DSA-2026-382）。SCG 是戴尔设备管理统一入口，管理员令牌被重放等于「前门钥匙被复制」，应升级固件、启用请求一次性校验。

7. Parse Server CVE-2026-87806（CVSS 9.1）9/9 披露

LDAP 认证适配器缺陷，未认证攻击者只要知道一个有效用户名即可拿到认证会话令牌，造成账户接管（影响 < 8.6.88、9.0.x）。开源后端框架的认证绕过，直接影响依赖其自建账号体系的应用。

8. Google Chrome CVE-2026-87491（CVSS 8.8）在野利用

V8 引擎越界写（OOB write），通过构造 HTML 页在沙箱内执行任意代码；Google 已于 Chrome 153.0.8010.36/.37 修复并确认已有在野利用——这是 2026 年第 7 个被在野利用的 Chrome 零日。Edge/Brave/Opera 等 Chromium 系需同步更新。

9. Microsoft Defender ShieldCrash 零日 PoC 公开

研究员 Chaotic Eclipse 放出 CVE-2026-69414（ShieldBreak，CVSS 7.8）补丁绕过 PoC（ShieldCrash），特定条件下仍可触发原问题，实现以 SYSTEM 身份任意文件读；所有受支持 Windows 桌面版本均受影响。

10. F5 BIG-IP APM webtop 无文件 rootkit

it-learn.io 报道，攻击者将无文件 rootkit 隐藏于 BIG-IP APM webtop（webtop_popup_css.php3 等）内存中，规避磁盘检测，服务于持久化与凭据窃取。需结合内存取证与异常进程排查。

11. SiYuan Note CVE-2026-87807 + PasswordPusher CVE-2026-87816

SiYuan Note < 3.8.2 全文检索 API 存在认证后 SQL 注入（可 UNION SELECT 读库）；PasswordPusher < 2.11.1 存在 TOCTOU 竞态（CVE-2026-87816，CVSS 8.7），并发请求可绕过「仅查看一次」限制多次窃取凭据。Adobe 同期还修 Acrobat Reader 多枚 UaF/Double Free、ColdFusion eval 注入。
