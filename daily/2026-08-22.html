1 严重

SPIP 双 CVE 未授权 RCE 已在野利用

CVE-2026-77806 / CVE-2026-77647 CVSS 9.8 · 在野利用

SPIP 连续披露两个未授权 RCE 漏洞并已出现实际利用：CVE-2026-77806（SPIP < 4.4.21，经 X-Spip-Filtre 头注入，8/21 披露）与 CVE-2026-77647（SPIP < 4.4.20，PHP 块识别缺陷，8/20 披露）。攻击者无需任何认证即可在服务器执行任意代码。

漏洞机制/攻击方式：

  • 类型：代码注入 → 远程代码执行（CWE-94）
  • 攻击方式：特制请求触发模板引擎未净化输入，注入 PHP 代码由 Web 服务器执行
  • 影响范围：所有未升级到 4.4.21 / 4.4.20 的 SPIP 公网站点
  • 后果：服务器完全沦陷，可挂后门、横向移动

值得关注的原因：

  • 已确认在野，披露即武器化（窗口仅 1 天）
  • 零认证 + 高覆盖 CMS，批量抓站门槛极低
  • 补丁窗口远短于传统周级节奏
攻击者 特制请求 模板引擎注入 PHP 执行 服务器沦陷

4 中高危

AI 推理基础设施 LMDeploy 反序列化 RCE

CVE-2026-76850 CVSS 9.8 · EPSS 0.98%

LMDeploy 分布式服务在 ZMQ p2p 通道以 pickle.loads() 反序列化对端消息且默认 api_keys=None 无认证；攻击者控制 zmq_address 即可在引擎进程执行任意代码。直击 LLM 推理核心进程。

5 中高危

Splunk AI Toolkit / SOAR 三连 RCE

CVE-2026-76395 / 76357 / 76356 8.8 / 7.6 / 8.1

Splunk AI Toolkit（<6.0.0）模型稀疏矩阵内嵌 pickle 致 RCE（8.8）；Splunk SOAR（<8.6.0）无角色 REST 路径遍历（7.6）与未认证 IP 欺骗 RCE（8.1）。安全运营中枢自身沦陷等于监控被一锅端。

速览区

6. n8n MCP 节点路径遍历 RCE（CVE-2026-77068，8.7）

node-schema 加载器未校验遍历序列，已认证 global:member 可借路径遍历在 n8n 主进程执行代码。

7. Gogs CVE-2026-52813（CVSS 10.0）Git hooks RCE 在野

Gogs < 0.14.3 因组织名遍历序列经 Git hooks 实现 RCE，列为 8 月在野最高危漏洞之一。

8. Zimbra 严重 RCE 现已在野利用

Week 34 威胁情报点名 Zimbra 严重 RCE 已被实际攻击利用，邮件基础设施再成重点目标。

9. ChainDrop npm 蠕虫劫持 GitHub Actions OIDC

供应链蠕虫向 444 个 npm 包注入恶意代码并带有效 SLSA 证明，签名校验难识别。

10. Medusa 勒索超 500 组织 CISA 联合警报

自 2021 年来 Medusa 入侵 500+ 关键基础设施组织，8 月 FBI/CISA/HHS 更新联合 advisory。

11. Cl0p 入侵 Shell/Philips/GE + MessiahGPT + SafePal

Cl0p 借 Windchill 声称入侵近 50 巨头；无限制 AI 模型 MessiahGPT 生成勒索/钓鱼工具包；SafePal 泄露 39,798 用户。
