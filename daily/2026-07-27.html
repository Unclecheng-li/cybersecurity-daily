1 严重

Gitea 仅公共令牌越权推私有仓库并触发 Actions RCE（CVE-2026-58443，CVSS 9.6）

CVE-2026-58443 · CVSS 9.6 (CWE-863) 修复版本 v1.27.0

Gitea 自托管 Git 服务曝出认证/授权绕过漏洞 CVE-2026-58443（CWE-863 权限检查不当，CVSS 9.6）。根因在 PR 更新端点的令牌权限校验逻辑缺陷：系统仅对「路由仓库」（公共基础仓库）执行「仅公共」限制，却忽略对「头仓库」（私有目标仓库）重新校验。攻击者只需持有效仅公共令牌、且令牌所有者在私有头分支有写入权限，即可把公共基础仓库的提交推入私有分支；当私有头仓库运行 Gitea Actions 时，该推送会直接触发工作流以仓库上下文执行恶意代码，将越权写入升级为 RCE。影响所有 ≤ v1.26.4 版本，官方已在 v1.27.0 修复，完整技术细节与 PoC 已于 7/21 公开，目前尚无野外利用报告。

漏洞机制/攻击方式：

  • 类型：授权绕过（CWE-863）/ 令牌权限校验缺失
  • 攻击方式：仅公共令牌向私有头分支发起 PR 更新，绕过私有仓库权限重检
  • 影响范围：所有自托管 Gitea ≤ v1.26.4、启用 Actions 的私有仓库
  • 后果：越权写私有仓库、以仓库身份运行工作流、窃取密钥/横向移动

值得关注的原因：

  • 代码托管平台是供应链与密钥心脏，越权写 = 污染源码与 CI/CD
  • Actions 链式放大：把「读权限缺陷」升级为「写 + 执行」全面沦陷
  • 存量长尾明显，PoC 公开后攻击门槛极低、自托管升级滞后
仅公共令牌 特制PR更新请求 绕过私有仓库校验 写入私有分支 触发Actions RCE
2 高危

Apache Camel camel-docling 参数注入 + 目录遍历（CVE-2026-40047，CVSS 9.1）

CVE-2026-40047 · CVSS 9.1 PoC公开 · 影响 4.15–4.18.1

集成框架 Apache Camel 的 camel-docling 组件被披露参数注入与目录遍历漏洞（CWE-88/CWE-22，CVSS 9.1），出现在 4.15.0、4.16.0、4.17.0、4.18.0、4.18.1。当应用调用外部 docling 工具时，攻击者可借特制组件参数注入非预期命令行标志或操纵文件路径，实现任意命令执行/文件读取。已被收录进 PoC Week 2026-07-13，GitHub PoC 已公开，官方已发布安全公告与修复版本。

受影响组件：

组件风险
camel-docling（Camel 4.15–4.18.1）高危
依赖外部 docling CLI 的集成流水线中高危
3 高危

CISA KEV 周报：ADFS CVE-2026-56155 整改大限 7/28 · SharePoint 45659 / Cisco UCM 20230 / Oracle EBS 46817

CVE-2026-56155 · 联邦大限 2026-07-28 在野利用

CISA 已知被利用漏洞（KEV）目录持续扩容。其中 Microsoft ADFS CVE-2026-56155（CWE-1220 访问控制粒度不足，本地权限提升）联邦整改大限为 2026-07-28（明日）；同期在野/已入 KEV 的还有 SharePoint Server CVE-2026-45659（反序列化 RCE）、Cisco Unified CM CVE-2026-20230（SSRF）、Oracle E-Business Suite CVE-2026-46817（权限管理不当，接管 Oracle Payments）等。ADFS 作为企业联合身份枢纽，一旦被绕过可签发/提升令牌横向打通大量依赖方。

受影响组件：

组件风险
Microsoft ADFS / SharePoint / Cisco UCM / Oracle EBS高危
依赖上述身份/业务枢纽的下游系统中高危
4 严重

Orkes Conductor 未认证 RCE（CVE-2026-58138，CVSS 9.8）

CVE-2026-58138 · CVSS 9.8 PoC公开

工作流编排平台 Orkes Conductor（3.21.21 之前、3.30.2）被披露未认证远程代码执行漏洞（CVSS 9.8）。攻击者在认证前即可向工作流 API 端点提交包含恶意 JavaScript/Python 表达式的内联工作流定义，服务端求值表达式时执行任意 OS 命令。已被 PoC Week 收录、PoC 已公开。Conductor 常直连生产系统与凭据，RCE 即全链路钥匙，与 Langflow、Flowise 等「AI/编排中间件」接力构成 2026 年最活跃 RCE 重灾区分支。

5 高危

Linux 内核双高危漏洞 PoC 公开，Debian 服务器已沦陷（CVE-2026-46242 / CVE-2026-53362）

CVE-2026-46242 · CVE-2026-53362 PoC公开 · 真实沦陷

Linux 内核两个高危漏洞 PoC 与技术细节已公开：Bad Epoll（CVE-2026-46242）为 epoll 清理路径 UAF 竞态，无权限用户可提权至 root，测试环境成功率高达 99%，甚至可从 Chrome 渲染器沙箱触发（影响 Android）；IPv6 Frag Escape（CVE-2026-53362）利用已修复 IPv6 分片漏洞溢出致页释放后使用，使网络隔离容器内无权限进程在宿主机拿到交互式 root shell（当前 PoC 针对 CentOS/RHEL 10）。7/14 一名 Debian 管理员报告其托管服务器遭攻陷，运行内核恰缺相关补丁，证明漏洞已具现实攻击价值；Bad Epoll 尚未入 CISA KEV。
