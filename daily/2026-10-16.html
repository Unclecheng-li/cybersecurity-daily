Cisco 邮件网关零日「一封邮件换 root」在野：CISA 大限 10-17（CVSS 9.8）

安全功能自身成为攻击面：邮件网关 root 权限外溢至集群 SSH 密钥与目录集成；同周 PAN-OS 管理面 RCE 亦入 KEV。

1 严重

Cisco Secure Email Gateway CVE-2026-76519 — 一封信件直达 root

CVSS 9.8 在野 · KEV 10-17 截止

Cisco 于 2026-10-14 更新公告，确认 CVE-2026-76519 已在野利用。该漏洞位于 Secure Email Gateway（AsyncOS）的高级恶意软件防护（AMP）文件信誉处理路径，属相对路径穿越（CWE-23）：攻击者无需认证，只需投递一封带特制附件的邮件，即可把文件写到操作系统任意路径，并进一步以 root 身份执行命令。这是继 9 月中旬 CVE-2026-76461 之后，同一产品的第二枚在野 root 级零日。

漏洞机制 / 攻击方式：

  • 触发条件：邮件策略中启用了 File Reputation，且 Content Scanner Tools 低于 25.3.0.5525
  • 修复路径：首选更新 Content Scanner Tools 至 25.3.0.5525+（无需重启），或升级 AsyncOS 15.5.5-014 / 16.5.0-780
  • 特例：16.0 分支的 16.0.4-302 单靠 AsyncOS 升级无效，需迁移；官方无 workaround
  • 事后处置：取证须放在设备外部的防火墙与链路日志（root 权限可改写本机日志），虚拟设备建议重建新 VM 并轮换全部凭据

值得关注的原因：

  • File Reputation 是客户为防恶意软件才开启的功能——越"买全功能"的部署越暴露
  • 邮件网关是天然的东西向跳板：一台机器拿到 root，等于同时掌握收发邮件、目录集成与集群互信的 SSH 密钥
  • 厂商按"处理过恶意附件即视为不可信"处理，口径更接近入侵事件而非普通漏洞
构造恶意附件邮件 投递到 Cisco SEG AMP 路径穿越 写入任意文件 root 命令执行
2 高危

Palo Alto PAN-OS CVE-2026-0322 — 管理面认证后 RCE 直达 root

CVE-2026-0322 在野 · KEV 10-17 截止

Palo Alto Networks 于 2026-10-14 披露 PAN-OS 管理界面远程代码执行漏洞（CWE-94），具备管理面网络访问权限的已认证攻击者可在防火墙上以 root 权限执行任意代码。厂商称观测到"非常有限"的利用，并给出三个美国境内 IP：66.42.72[.]14、208.83.239[.]114、149.248.47[.]234。CISA 同日收录 KEV，联邦修复大限同为 2026-10-17。

受影响与修复：

组件风险
PA-Series / VM-Series 防火墙、Panorama受影响 · 管理面 root RCE
Cloud NGFW / Prisma Access不受影响
修复版本12.2.4 及各分支热修复（11.2.16 预计 10-15）

无官方 workaround，只能把管理面收敛到可信内网 IP；Threat ID 510046 / 510047 覆盖有限且需 SSL 解密。虽然是认证后漏洞，但管理员凭据在信息窃取日志中成批在售，"需要登录"的安慰性极低；一旦被拿下，等于掌握流量编排、VPN 会话与设备内存储的秘密。

3 严重

Langflow CVE-2026-105740 — MCP Stdio 命令注入，蜜罐已见 1423 次利用

CVSS 9.9 认证后 RCE · 定在野

IBM / DataStax 旗下开源 AI 应用与智能体工作流平台 Langflow 存在 CVE-2026-105740（CWE-78）：MCP 服务器的 stdio 传输配置中，用户提交的 command 字段被直接交给 bash -c 执行，无校验、无白名单、无沙箱；env 字段还允许注入 LD_PRELOAD 或覆盖 PATH。任意认证用户（含非管理员）即可获得 OS 命令执行能力。修复版本 1.9.0，公告与 CVE 于 10-05 发布（GHSA-7w94-79vh-5mr2）。

在野态势：Previdian 蜜罐自 9-19 起记录 1,423 次利用尝试，来自 27 个 IP、覆盖 15 个国家/地区；10-11 起显著提速（单日 333 次），10-15 当天仍有 66 次。载荷包括窃取 LANGFLOW_SECRET_KEY 与 LANGFLOW_SUPERUSER_PASSWORD 并外传。攻击链为：查版本 → 尝试 /api/v1/auto_login（被禁用则 403）→ 常见弱口令登录 → 用 bearer token 打 /api/v2/mcp/servers/{name}。

恶意 MCP 配置存在项目设置里、不显示在流程编辑器，常规 code review 发现不了，且每次拉取服务器列表都会重新执行，等于固化后门；上月同族 CVE-2026-105697（同为 9.9）也走 MCP stdio 命令注入。

4 高危

Gitea CVE-2026-59774 — Org-mode INCLUDE 未认证任意文件读取，可链至 RCE

CVSS 9.8 未入 KEV · 修 1.27.1

Gitea 的 Org-mode 渲染器（go-org）未限制 #+INCLUDE 指令的本地文件读取回调（CWE-22）。攻击者只要在公开仓库提交含该指令的 Org-mode 标记，即可未认证读取 Gitea 服务账号可访问的任意文件。影响 1.22 至 1.27.0（含），修复版本 1.27.1。

从读文件到命令执行：

  • 未认证读取服务端任意文件
  • 读到 app.ini 的 INTERNAL_TOKEN
  • 配合内部 logger 接口 → 改写 Git Hook
  • 以 gitea 服务账号执行命令

前置条件极低——实例只要有一个公开仓库，后续步骤完全不需要身份认证；被读取的高价值文件还包括 CI/CD 变量、Runner 令牌与日志中的敏感内容。已暴露实例必须轮换 INTERNAL_TOKEN 并检查仓库 Git Hook 是否被改动。

5 中高危

日本个人信息泄露连环爆发：Sourcenext 2251 万条、汉堡王日本 1118 万条

2026-10-13 / 10-15 披露 个人数据泄露

据共同社 10-16 报道，日本软件企业 Sourcenext 于 10-13 上午 9 时许发现会员信息管理系统遭未授权访问并切断连接，最多约 2251 万条客户记录可能外泄，涉及姓名、住址、电话、密码，工作单位与职务信息也可能泄露（信用卡信息未受影响）。同日，汉堡王日本（BK Japan）宣布官方 App 约 1118 万条会员信息泄露；医疗 IT 企业 MEDLEY 业务支持系统遭未授权访问后暂停服务，全国 787 处医疗机构无法互联网预约；数字漫画平台 Comic Cmoa 暂停服务。发布防灾信息的 Arcadia 遭未授权访问后，多个地方政府居民已收到可疑邮件。

值得关注的原因：

  • 日本本轮泄露潮累计影响已达数千万级，此前已连续出现 JR 东日本、BOOKOFF、skyticket、罗森、第一兴商等大案
  • 攻击模式高度相似：直打存储个人信息的客户数据库，目的是批量数据变现而非勒索加密
  • "未授权访问 + 无篡改迹象"意味着受害企业往往数日后才发现，响应窗口几乎为零

速览区

6. Unit 42：CL-UNK-1211 用 AI 生成代码攻击政府 Linux 服务器

Unit 42 追踪 2025-10 至 2026-04 的长期活动，目标为政府与国家关联基础设施的 Linux 服务器与数据库。持久化靠篡改 /etc/php/ 下 auto_prepend_file，部署 Go 后门 SysGoRAT 与内存态反弹 shell；恶意脚本里残留对话式 LLM 推理注释，且跨越 PHP/JS/Bash/Python 时毫无开发摩擦，判定为 AI 辅助生成。IOC：104[.]194[.]158[.]65:443。

7. 零点击广告间谍软件 AdFection：Discover-Tech 把设备引向 Candiru

Citizen Lab 披露 Discover-Tech 的广告被用于将设备静默导向 Candiru 服务器，至少 45 台半岛电视台设备遭零点击攻击，与 Candiru 关联达高置信度。Confiant 发现同类广告还出现在美国国防部与北约网络中。Google 与 IAB Europe 已将 Discover-Tech 移出供应商名单。

8. GreyNoise：proxyjacking 借老旧漏洞劫持边缘设备转卖带宽

在 34 个国家发现至少 143 台被入侵设备，未经同意运行 Pawns.app 转卖带宽。入口为 CVE-2024-3272 / CVE-2024-3273（D-Link NAS）、CVE-2021-44228（Log4Shell）与 CVE-2025-31324（SAP NetWeaver Visual Composer），目标还包括 Hikvision / Dahua 录像机与 Ubiquiti UniFi Video NVR。

9. EvilTokens：设备代码钓鱼即服务，16 天打穿 344 家组织

自 2026-02 起在 Telegram 订阅制出售（1,500 美元启动 + 500 美元/月），滥用 OAuth 设备代码流程：受害者在真实微软页面输入代码，"正确完成了 MFA"，攻击者却拿到有效会话令牌，因此强制改密码无效，必须吊销令牌并终止会话。Huntress 追踪其约 16 天内打穿 5 国 344 家组织。缓解：条件访问屏蔽非必要的设备代码流程。

10. D-Link DIR-868L HNAP 命令注入 — CVE-2026-110536（CVSS 10.0）

/htdocs/cgibin 的 HNAP CGI 处理器未安全处理 SOAPACTION 参数，未认证、无需交互、网络可达即可触发，CVE 记录已列出 GitHub 公开 PoC。固件 2.01b05 受影响，D-Link 公告 SAP10189 确认该型号已停止支持 / 生命周期终止，无修复版本，建议规划替换。

11. 朝鲜 Kimsuky「Operation GitPower」打乌克兰政策专家

Genians 报告 Kimsuky 针对乌克兰外交、安全与国际政策专家，用"回复式"钓鱼建立信任后投递恶意 LNK 拉起 PowerShell，并把 GitHub 当作攻击基础设施（从 raw 内容拉取载荷）。建议对 LNK 附件与由快捷方式拉起的 PowerShell 直接告警，并监控终端向 GitHub raw 的异常访问。
