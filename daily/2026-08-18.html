单周 44 个在野零日：Defender「ShieldBreak」、VMware vCenter、macOS 屏幕共享三线 9.8 齐发

CVE-2026-69414（Defender 0day 无补丁）· CVE-2026-59310（vCenter 9.8 APT+勒索）· CVE-2026-65400（macOS 9.8 在野 root 挖矿，CISA 上调至 9.8 入 KEV）

1 严重

Microsoft Defender 零日「ShieldBreak」CVE-2026-69414：绕过 RoguePlanet 补丁、全补丁 Windows 100% 提权

CVSS 待定（研究者称 100% 可靠） 无补丁 / 微软确认调查中

安全研究员公开名为 ShieldBreak 的 Microsoft Defender 零日概念验证，声称可完全绕过此前针对 CVE-2026-50656（RoguePlanet）的修复，在 Defender 云扫描期间的用户态回调中动态改写文件内容，使本地低权用户提权至 NT AUTHORITY\SYSTEM。研究者称该 PoC 在 Windows 10、Windows 11 与 Windows Server 2025 全补丁环境成功率 100%。

漏洞机制/攻击方式：

  • 类型：端点防护平台权限提升 / 补丁绕过（CWE-269，绕过 RoguePlanet）
  • 攻击方式：利用 Windows Cloud Filter API，在 Defender 云扫描用户态回调中改写文件，使检测失效
  • 影响范围：启用 Microsoft Defender 的 Windows 10 / 11 / Server 2025
  • 后果：先 neutral 端点防护再投送载荷，依赖单一 EDR 的防御体系被致盲

值得关注的原因：

  • 防护产品自身成突破口，「打谁之前先废掉保镖」，签名/行为式 EDR 若无分层监测即变盲点
  • 绕过已发布修复的 RoguePlanet，属「补丁后再绕过」范式，补丁闭环仍有盲区
  • 无可用补丁、全补丁环境 100% 可靠的公开 PoC 极大压缩防御窗口
攻击者 低权本地 触发 Defender 云扫描 Cloud Filter 回调 绕过 RoguePlanet SYSTEM 提权
2 严重

VMware vCenter CVE-2026-59310（CVSS 9.8）目录遍历 RCE 在野，疑似 APT 部署 Babuk 衍生勒索

CVSS 9.8 在野利用 / APT + 勒索

VMware vCenter 曝出 CVSS 9.8 的目录遍历漏洞，网络可达的实例可经之执行任意代码。疑似与中国相关的 APT 借之入侵，植入恶意 Cron 与 reverse_ssh 持久化，并最终部署 Babuk 衍生勒索（被研判为掩盖入侵与反取证的烟幕）。已观测 361 个受害 IP、分布于 47 国。

受影响组件：

组件风险
VMware vCenter（暴露实例）严重 · 单点沦陷掌控全部虚拟机
vSphere 虚拟化基础设施高危 · 整片虚拟化底座失守
3 严重

macOS 屏幕共享 CVE-2026-65400（CVSS 9.8）在野 root + 门罗币挖矿，CISA 由 7.1 上调至 9.8 入 KEV

CVSS 9.8（原 7.1） 在野利用 / KEV

macOS 屏幕共享组件认证绕过漏洞，攻击者可对开启屏幕共享（TCP 5900 暴露）的 Mac 免凭据认证，取得 root 并安装门罗币挖矿程序。苹果 8/6 紧急 OOB 修复（Tahoe 26.6.1 / Sequoia 15.7.9 / Sonoma 14.8.9），CISA 8/14 将评分由 7.1 上调至 9.8 并认定可自动化利用，已入 KEV。

值得关注：所有观测案例均获 root；公开 PoC 出现后短时间内即在多台暴露主机实战，补丁窗口被压到数日；根因细节已在 Black Hat 现场演示，复用门槛极低。

4 高危

CISA KEV 8/11 三连：Lazarus 借 CVE-2026-68820、Cisco CVE-2026-20349、Metabase CVE-2026-72898

CVE-2026-68820 / 20349 / 72898 入 KEV

CISA 8/11 将三个在野漏洞纳入 KEV。Lazarus 借 Windows AFD.sys 释放后使用提权 CVE-2026-68820 打 Operation Dream Job，投递 ForestTiger 与新型后门 Troy，针对法/德/巴/印国防航天；Cisco ASA/FTD 堆检查漏洞 CVE-2026-20349 可未认证远程重载（DoS）；Metabase SQL 注入 CVE-2026-72898 可未认证拿管理员。

受影响组件：

组件风险
Windows AFD.sys（CVE-2026-68820）高危 · Lazarus 利用
Cisco ASA/FTD（CVE-2026-20349）中高危 · 边界 DoS
Metabase（CVE-2026-72898）中高危 · 未认证 SQLi
5 中高危

GeoServer 无 CVE 编号 SQL 注入 RCE 在野 + LiteLLM 供应链 153GB 凭据泄露

GeoServer / LiteLLM 披露即野 / 供应链

GeoServer 曝出 SQL 注入致 RCE 漏洞（尚未分配 CVE，已修于 3.0.1 / 2.28.5 / 2.27.6），公开披露后数小时内即遭在野利用（watchTowr 观测到来自少量 IP 的数百次尝试）。同期 LiteLLM AI 网关供应链事件披露：TeamPCP 攻陷 Trivy CI/CD 窃取 PyPI 凭据、发布木马化包，后续曝出 153GB 窃得凭据。

值得关注：「无 CVE 编号也在野」推翻「没编号=不紧急」的错觉；供应链攻击从投毒包升级到攻陷 CI/CD 偷凭据，受害面扩散至整个生态。
