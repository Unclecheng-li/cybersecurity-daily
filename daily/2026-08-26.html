CISA 四连击 KEV 合围(vCenter 59310 / IKE 33824 / macOS 65400 / SharePoint 55040)、SAP 58231 满分RCE披露3天在野、Citrix 8452 预认证RCE在野、Siemens S7 PLC 遭 AI 脚本攻击、PTC Windchill 12569(Cl0p)——企业应用·边界设备·OT 三线承压

CVE-2026-59310(VMware 9.8,中国APT 361IP) · CVE-2026-33824(Windows IKE 9.8,DeepSeek自主攻击) · CVE-2026-58231(SAP 10.0在野) · CVE-2026-8452(Citrix预认证RCE在野)+CVE-2026-19490(9.3) · CISA AA26-231A(S7 PLC AI)

1 严重

CISA KEV 四大在野漏洞合围：macOS / SharePoint / vCenter / Windows IKE（8/18 纳入，联邦大限已过）

三条 CVSS 9.8 / 全部在野 BOD 26-04 大限 8/21 已过

CISA 于 8/18 一次性将四条漏洞纳入 KEV，联邦机构修复大限（BOD 26-04）为 8/21，现已过期。其中三条 CVSS 均为 9.8，全部已确认在野利用，厂商补丁均已就绪。

漏洞机制/攻击方式：

  • 类型：vCenter 路径遍历→RCE(59310) / Windows IKE 双重释放→预认证RCE(33824) / macOS 身份绕过(65400) / SharePoint 弱认证绕过(55040)
  • 攻击方式：vCenter 被中国背景 APT 部署 reverse_ssh 后门（361 IP/47 国，Babuk 衍生勒索）；IKE 33824 由中文 actor 借 DeepSeek 等大模型实施 AI 赋能自主攻击
  • 影响范围：虚拟化管理层、VPN 边缘、终端、企业协作平台
  • 后果：管理平面整片沦陷、内网洞穿、门罗币挖矿与勒索

值得关注的原因：

  • vCenter 是整座虚拟化 estate 的管理平面，路径遍历直达 RCE = 一台失守全部 VM 失守
  • IKE 33824 被标注为 AI-enabled autonomous hacking campaign，攻击方用大模型调度利用脚本，降低高级漏洞门槛
  • 三条同为 9.8，CVSS 已失效能区分，修复须按"暴露面 × 爆炸半径 × 谁持有武器"重排
未认证攻击者 互联网暴露边界 59310/IKE 33824 触发 RCE / 后门 内网整片沦陷
2 严重

SAP Commerce Cloud CVE-2026-58231（CVSS 10.0）披露 3 天即在野，满分未认证 RCE

CVSS 10.0 / Data Hub Adapter 在野 / 4200+ 暴露

SAP Commerce Cloud 的 Data Hub Adapter 存在授权不足 + 输入校验缺失，未认证攻击者滥用默认认证客户端向 */datahub-webapp/v1/* 提交特制请求即可执行任意代码。SAP 8/11 发补丁，Defused 蜜罐 8/14 探测、KEVIntel 8/15 确认 PoC 可用；据报 4,200+ 实例暴露于公网。

值得关注：满分 + 无认证 + 电商核心 + 3 天武器化的四要素叠加，可直接导致 Magecart 实时窃卡、网站篡改、服务器勒索并作为内网跳板；缓解须升级版本后重建并重构建署，仅限 IP Filter Set 为临时暴露面收缩。

3 高危

Citrix NetScaler 双漏洞：CVE-2026-8452 预认证 RCE 在野 + CVE-2026-19490 认证绕过（9.3）

8452 v4 8.8 / NVD 9.8 · 19490 v4 9.3 8452 在野 / 19490 披露

CVE-2026-8452：SAML PrefixList 处理的内存溢出，watchTowr 已发布可抵达 root 的 PoC，加拿大网络安全中心 8/17 确认在野、已入 KEV（补丁 14.1-72.61 / 13.1-63.18）。CVE-2026-19490：认证绕过（CWE-288 备用路径）CVSS 9.3，8/19 披露（补丁 14.1-73.32 / 13.1-63.21）。两漏洞补丁版本不同，须分别核对实际安装版本。

值得关注：NetScaler 位于网络边界（SSL VPN / ZTNA），预认证 RCE 无需凭据与交互，等同把内网前门交出；Citrix Bleed 模式重演，边界设备认证绕过披露后利用窗口常被压缩到"天"级。

4 高危

CISA AA26-231A：AI 生成攻击脚本瞄准 Siemens S7 系列 PLC（能源 / 水务 / 制造）

NSA·CISA·FBI·DOE·EPA 联署 首次政府确认 AI 写 ICS

8/19 五部门联合公告，首次政府级确认威胁 actor 用 AI 生成利用脚本攻击 OT：Censys / ZoomEye 扫描暴露 PLC（端口 102 / S7comm）→ 基于 snap7 / python-snap7 由 AI 生成脚本 → 伪装为合法 OT 监控工具读写 PLC 内存 / 配置 / 梯形图。影响 S7-200/300/400/1200/1500（含 F 安全控制器）。

值得关注：AI 夷平了 ICS 攻击的专业门槛；当前处于"read 测绘 + 预置位"阶段，破坏动作尚未大规模落地，是防御黄金窗口；第三方集成商远程访问致资产所有者不知暴露。

5 中高危

PTC Windchill CVE-2026-12569（关键 RCE）—— Cl0p 网页 shell 定向企业 PLM

关键 RCE / Cl0p Windchill / FlexPLM

Cl0p 勒索团伙使用自定义 Java web shell 针对 PTC Windchill / FlexPLM 服务器：利用 CVE-2026-12569 关键 RCE 后连接 Windchill 数据库、解密存储凭据、搜索文件仓库窃密，并用自定义 X-windchill-req HTTP 头接收命令。

值得关注：PLM 承载产品生命周期与研发文档，沦陷即设计资产与供应链情报外泄；解密存储凭据将单点 RCE 升级为凭据泄露 + 内网横向 + 数据窃取的组合拳。
