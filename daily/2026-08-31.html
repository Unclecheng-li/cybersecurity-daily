VMware vCenter CVE-2026-59310：CVSS 9.8 路径遍历大规模在野，5 天沦陷 361 IP / 47 国，Babuk 加密 ESXi

CVSS 9.8 / CWE-23 361 IP·47 国·KEV 大限 9/8

VMware vCenter Server Syslog 组件的目录遍历漏洞 CVE-2026-59310（CVSS 9.8）自 Broadcom 7/29 发补丁后，被疑似中国背景 APT 在披露后第 5 天（8/3）即武器化。德国 QUIRSO 复盘：至 8/5 已 343 个受害 IP，至 8/7 累计 361 个独立 IP、横跨 47 国（德 55 / 美 41 / 土 38 / 伊朗 26 / 法 25）。

攻击链：路径遍历写入 /etc/cron.d 畸形 cron（引用 CVE/Syslog）→ 以 root 执行（无认证日志）→ 起 JSP webshell、伪造 vmware-* 服务启用 SSH 并植入 authorized_keys → 开源 reverse_ssh 反向隧道出网 C2 → 在 ESXi 建本地管理员、经 datastore browser 拷 Babuk 衍生加密器，停 VM、加密 VMFS、禁 HA 代理，文件打 .babyk。同批还扫 CVE-2026-59309（认证绕过 9.8）。CISA 8/18 入 KEV，FCEB 大限 2026-09-08，无规避方案只能升级。

值得关注：vCenter 是整片虚拟化资产的管理平面，单点沦陷即触达所有 VM 与域凭据，加密 + 持久化同步发生；披露→在野窗口 5 天快过周级补丁评审；已打补丁者仍要 assume compromise，排查 cron / authorized_keys / 出站 SSH。.babyk 可能是烟雾弹，真正目的或为潜伏窃密。

公网 vCenter 接口 CVE-2026-59310 路径遍历 root cron + JSP webshell reverse_ssh C2 出网 ESXi .babyk 加密
2 严重

Gogs CVE-2026-52813：CVSS 10.0 自托管 Git 满分 RCE，源码托管沦陷 = 供应链持久化

CVSS 10.0 / CWE-23 0.14.3 修复 · PoC 已公开

轻量级自托管 Git 服务 Gogs 创建组织时未过滤 username 的路径遍历字符，攻击者可借 ../ 把仓库写到任意文件系统位置；构造嵌套仓库即可覆盖其他仓库的 Git hooks，在受害者仓库下一次 push 时以 git 账户执行任意命令，达成 CVSS 10.0 未认证 RCE。官方于 0.14.3 修复（加 AlphaDashDot 绑定 + pathx 包规范化）。

Aikido 8/19 发布《Yet another RCE in Gogs, but it's fixed this time!》复现确认 0.14.3 封堵该链，但另一处此前报告的绕过仍未被修复（不应与 59310 混淆）。PoC 已公开，影响 < 0.14.3。

值得关注：满分且普通注册账号即可触发（多部署默认开放注册）；源码托管里躺着部署令牌、SSH 凭据、CI/CD 密钥与「被信任」的生产代码——仓库被控可在下游发布物埋持久后门，补丁修完漏洞也不代表供应链干净。处置：升级 0.14.3 + 关开放注册 + 锁 hooks 只读 + 审计异常组织名与新增 SSH key，并单独跟进 Aikido 指出的未修复绕过。

3 严重

Progress LoadMaster CVE-2026-8037：CVSS 9.8 未认证命令注入，792 次利用、EPSS 99.31% 的边缘设备沦陷

CVSS 9.8 / CWE-77 KEV · 大限 8/10 已过 · root

LoadMaster（及 ADC、ECS Connection Manager、MOVEit WAF）管理 API 的 escape_quotes() 分配未初始化堆缓冲且未写空终止符，产生越界读，攻击者可控内容流入 system() 以 root 执行任意命令——无需认证、凭据、交互，入口为 accessv2 API 的 apiuser 参数。补丁 6 月即出（GA 7.2.63.2 / LTSF 7.2.54.18），但 CISA 8/7 才因确认在野纳入 KEV、联邦大限 8/10 已过期。

DIESEC 统计 792 次利用、65 个 IP、横跨 41 天；Shadowserver 仍有约 300 台实例把管理 API 暴露公网。NVD 给 9.8、厂商标 9.6。

值得关注：负载均衡器坐镇网络边缘（SSL 终止 + 流量分发），root RCE = 看得见后端流量、可做 MITM、可横向进数据中心；「补丁可用两个月后才被大规模利用」是经典节奏陷阱，边缘设备「设好就忘」正中射程，2026 年已是第 14 个被规模化利用的边缘产品线。处置：立即升级、管理 API 收进管理 VLAN/仅 VPN、已暴露者按已沦陷取证。

4 严重

IBM Langflow CVE-2026-9198：CVSS 9.8 AI 基础设施未认证 RCE，auto_login 链 validate/code 直取主机

CVSS 9.8 / CWE-94 KEV · 已在野 · 修复 1.10.1

开源 AI/ML 低代码构建工具 IBM Langflow OSS（1.0.0–1.10.0）存在链式代码注入：/api/v1/auto_login 向任意网络调用者发放 SUPERUSER bearer 令牌，再借 /api/v1/validate/code（用 exec() 执行用户代码，并在函数定义时执行装饰器/默认参数/注解）提交恶意代码，即可在默认部署上拿到完整 RCE（CVSS 9.8，CWE-94）。IBM 已于 1.10.1 修复。

新加坡 CSA、台湾 FISAC、塞浦路斯 CSIRT 等多方确认已在野利用，CISA KEV 收录（8/4 入册）。

值得关注：AI/ML 基础设施成新攻击面，Langflow 常直连公网做 Agent/管线编排，默认即中招、未认证即主机级 RCE，可比传统 Web 漏洞更快触达训练数据与模型资产；漏洞本质是「自动登录发超权令牌 + 动态代码执行原语暴露」的组合。处置：升级 1.10.1、收进内网/VPN/零信任、WAF 拦敏感 API 路径、排查异常入站与 Python 运行时派生子进程。

5 严重

Metabase CVE-2026-72898：CVSS 10.0 未认证 SQL 注入，一键接管管理员、拖走全部连接数据库

CVSS 10.0 / CWE-89 KEV · 大限 8/14 · EPSS 10.40%

商业智能平台 Metabase 的 /reset_password 端点存在未认证 SQL 注入（CVE-2026-72898，CVSS 10.0，CWE-89），攻击者可注入任意 SQL 接管实例管理员账户，进而改配置、窃取所连数据库凭据、读取并导出所有可达数据。CISA 8/11 纳入 KEV、大限 8/14（EPSS 约 10.40%）；修复随 Metabase 安全更新发布。

值得关注：BI/analytics 平台汇聚多源数据库凭据与业务全量数据，管理员接管等于「数据总闸」失守，影响面远超单系统；满分 + 未认证 + SQLi 路径清晰，自动化扫描与定向入侵都极易命中，KEV 入册即「已被实际使用」官方背书。处置：应用安全更新、轮换所有被 Metabase 持有的数据库凭据、审计异常管理员与导出行为。

速览区

6. 哥伦比亚司法部遭勒索（Check Point 8/17 报告）

哥伦比亚司法部确认遭勒索攻击，政府法务与禁毒监控相关系统文件被加密、公共服务中断；初步调查称未发现数据外泄，但双 extortion 团伙惯用「先窃后加密」，未确认泄露不等于没有。

7. 柏林州政府遭 Rhysida 勒索并拒付，5.79 TB 数据被拍卖

8/28 Rhysida 宣布拍卖从柏林州机构窃取的 5.79 TB 数据（46,500 份合同、邮件、电话、密码与机密信息），索要约 30 BTC（≈7.76 万美元）；市长公开表态不向勒索低头，并确认 9 月大选前选举基础设施安全。

8. Qilin 攻陷德国公用事业 GSW（8/17）

Qilin 将北威州区域公用事业商 GSW（供电/气/水/热，覆盖 Kamen、Bönen、Bergkamen）列入受害者页；公用事业数字层一旦被控，即便物理设施未停，账单/调度/客服/认证系统也会失能，连锁冲击社区居民。

9. 美国水务技术商 Micro-Comm 遭 Barracuda 勒索，644 GB 泄露、200+ PLC 暴露

堪萨斯州水技术制造商 Micro-Comm 确认 7 月底被 Barracuda 勒索，8/6 泄露近 85 万文件、约 644 GB（含产品图纸、军政客户信息、员工 PII、管网地图）；约 200 台 SCADAview CSX 仍直连公网，CISA 呼吁收敛 PLC/SCADA 暴露面。

10. Windows AFD CVE-2026-68820（CVSS 7.0，KEV）WinSock 驱动 UAF 在野

Windows Ancillary Function Driver for WinSock 释放后使用漏洞（CWE-416），已认证本地提权，CISA 8/11 入 KEV、大限 8/25；随 8 月补丁星期二修复，属本月微软 421 个 CVE 中 3 个零日之一。

11. Cisco ASA/FTD CVE-2026-20349（CVSS 8.6，KEV）堆检测漏洞在野

Cisco ASA/FTD 的 Remote Access SSL VPN 服务存在不当错误检查（CWE-244 堆检测），未认证远程可触发设备重载造成 DoS，CISA 8/11 入 KEV、大限 8/14，已有在野证据；建议立即应用 Cisco 安全公告修复。
