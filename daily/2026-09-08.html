Adobe Commerce / Magento「StyleSmuggler」正式定级 CVE-2026-75650：CVSS 10.0 在野 RCE，热补丁 VULN-39341 已发

9/7 Adobe 发布 APSB26-146，为长期追踪的 StyleSmuggler 零日分配 CVE-2026-75650（CWE-1336 模板引擎注入）；未授权 RCE、确认在野，全系 2.4.4–2.4.9 须打热补丁并轮换凭据

1 严重

Adobe Commerce / Magento CVE-2026-75650（CVSS 10.0）—— 模板引擎注入导致未授权 RCE，在野利用

CVE-2026-75650 · CWE-1336 · APSB26-146 CVSS 10.0 · 在野 · 热补丁 VULN-39341

Adobe 于 9/7 发布安全公告 APSB26-146，为长期被追踪为「StyleSmuggler」的 Magento / Adobe Commerce 零日分配 CVE-2026-75650（CWE-1336 模板引擎特殊元素处理不当）。漏洞为未授权远程代码执行，CVSS 3.1 满分 10.0（AV:N/AC:L/PR:N/UI:N/S:C），Adobe 明确标注已在野利用。根因是攻击者通过 Store 的 Style / 模板属性注入恶意负载，借「Payment Transaction Failed Reminder」邮件渲染路径在服务端执行任意 PHP——无需登录、无需交互。

漏洞机制 / 攻击方式：

  • 类型：模板引擎注入 → 未授权 RCE（CWE-1336）
  • 触发：渲染标准邮件模板时执行攻击者注入的模板/代码，无需收件人打开邮件
  • 影响范围：Adobe Commerce 2.4.4–2.4.9（2026-aug 及更早）、B2B 1.3.3–1.5.3、Magento Open Source 2.4.6–2.4.9，含已打 8 月补丁的实例
  • 后果：支付/客户数据窃取、供应链跳板、持久化后门（伪装 kworker/fc-cache/chronyd、pub/media 下 WebShell）

值得关注的原因：

  • 昨日头条 0day 的「落槌」：从「无 CVE、无补丁」进入「有 CVE、有缓解」，但存量后门不会因打补丁自行清除，必须做失陷排查
  • 修复为热补丁 VULN-39341（非整版本升级），且必须轮换加密密钥与全部凭据——仅轮换密钥无法使攻击者已读取的密钥失效
  • 缓解：WAF 规则 + 临时关闭 GraphQL（经典/Hyvä 店面通常可关）+ 排查模板异常与已落地 WebShell 后再声明清白
恶意 Style/模板注入 CVE-2026-75650 模板引擎 未授权服务端代码执行 植入后门/WebShell 窃取支付/客户数据
2 严重

AI「记忆层」工具 knowns 一夜披露 4 个未授权严重漏洞（CVE-2026-86542/86543/86544/86538）

CVSS 9.8 / 9.1 / 8.7 / 7.2 · 修复 0.30.0 9/7 集中披露 · 无认证暴露

开源、可自托管的 AI 开发「记忆层」工具 knowns（npm: knowns-dev/knowns）于 9/7 集中披露 4 个严重漏洞，均影响 < 0.30.0，修复版本 0.30.0：CVE-2026-86543（9.8）管理 API 默认无认证监听所有网卡，可经 /api/tunnel/start 把未授权 API 反向隧道暴露公网；CVE-2026-86542（9.1）导入 name 参数路径穿越，未授权任意文件写/覆盖（可链 LSP 覆写升级 RCE）；CVE-2026-86544（7.2）code.replace 误分类为只读致低权越权改权限提权；CVE-2026-86538（8.7）/api/templates/preview 任意文件读。

knowns 常被接入本地代码库与 LLM 助手，一旦未设密码自托管即等于把项目源码与知识库裸奔到公网；「公网隧道暴露」尤其危险，等于主动把 RCE 面推向互联网。建议立即升 0.30.0、配置管理 API 密码、收口网络暴露面。

3 严重

libmodbus-secure 堆溢出 CVE-2026-0908（CVSS 9.8）—— 公开 PoC，OT/工业网关 RCE

CVSS 9.8 · CWE-122 · 公开 PoC 远程未授权 · OT/ICS

工业 Modbus/TLS 通信库 libmodbus-secure 3.2.4-rc1 的 modbus_reply_secure_exception() 存在堆溢出（CWE-122）。当处理异常负载超出协商 PDU 窗口时响应内存越界写入，远程未授权攻击者可执行任意代码或使现场网关崩溃；仅影响带 --with-secure-transport 编译的构建。secwatch-io 已放出 PoC（libmodbus-secure-poc）与扫描器，Debian、SUSE 已发安全更新。

这是典型的 OT/ICS 供应链单点失陷——一个被投毒/有缺陷的通信库即可让大量工业网关、PLC 前置机变成内网跳板，且修复常滞后于 IT 侧。使用方应升级库版本、收敛网关暴露面并部署协议层检测。

4 严重

JetBrains YouTrack Helpdesk 未授权账户接管 CVE-2026-86478（CVSS 9.8）

CVSS 9.8 · 未授权接管 影响 < 2025.3.16125

JetBrains YouTrack 的 Helpdesk 功能存在认证绕过，攻击者可借自断言的邮箱地址在未授权情况下接管任意用户账户（CVSS 9.8，无需权限/交互），影响 2025.3.16125 之前版本。

工单/客服系统是攻击者进入企业内部的经典入口（可重置密码、读取内部沟通、钓鱼员工）。该漏洞无需任何前置条件，暴露于公网的 Helpdesk 实例应立即升级并排查异常登录与密码重置记录。

5 高危

Next4Biz CSM 反序列化代码注入 CVE-2026-7861（CVSS 9.8）—— 厂商零回应

CVSS 9.8 · 反序列化/代码注入 9/7 披露 · 无官方补丁

Next4Biz Information Technologies 的 CSM（客户服务管理）存在不可信数据反序列化漏洞，可导致代码注入（CVSS 9.8），影响至 07092026 版本。披露方称厂商早期被联系但始终未回应。

反序列化 + 代码注入组合通常可直接 RCE；厂商沉默意味着无官方补丁、无缓解指引，使用方只能靠 WAF / 网络隔离 / 禁用暴露接口自救，风险窗口长期敞开。建议收敛 CSM 暴露面并监控异常反序列化请求。

速览区

6. Copy Fail（CVE-2026-31431）PoC 生态本周集中爆发

Linux 内核 algif_aead 页缓存投毒逻辑缺陷，未授权本地用户 4 字节受控写入任意可读文件页缓存（典型目标 /usr/bin/su），影响 2017 年来几乎所有发行版，100% 可靠、无竞态；本周 GitHub 涌现大量 C/Rust/Python PoC 与 K8s 节点级容器逃逸变种。

7. Apache Tomcat CVE-2026-34486 公开 PoC 可复现 RCE

修复 CVE-2026-29146 时回归，super.messageReceived() 被移出 try 块，解密失败仍把原始字节送入反序列化；集群端口（默认 4000）可达 + 存在 Gadget 链即 RCE，CVSS 7.5，360 已复现。

8. Windows Netlogon CLDAP 栈溢出 CVE-2026-41089（9.8）持续在野

域控 UDP/389 的 CLDAP DC Locator 响应 528 字节栈缓冲溢出（字节/WCHAR 长度混淆），一个 UDP 包即令 LSASS 崩溃、域控重启、全域认证中断；已有公开 PoC 与在野确认（比利时 CCB）。

9. GNU InetUtils telnetd CVE-2026-32746（9.8）预认证 RCE

telnetd 处理 LINEMODE SLC 时存在预认证栈溢出，可远程未授权执行代码，影响仍启用 telnet 的老旧/嵌入式设备，建议直接禁用 telnet 服务。

10. llama.cpp RPC CVE-2026-34159 0-click RCE

llama.cpp 的 RPC server 存在无需交互的远程代码执行，瞄准 AI 推理基础设施，凸显本地大模型服务暴露面与默认配置风险。

11. knowns 剩余两项（86544 提权 / 86538 任意文件读）

与 #2 同簇：CVE-2026-86544 低权会话越权改权限提权、CVE-2026-86538 未授权读主机任意文件，均应随 0.30.0 一并修复。
