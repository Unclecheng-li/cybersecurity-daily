Magento / Adobe Commerce「StyleSmuggler」零日 0day 无补丁在野：电商站点被批量植入后门

未授权攻击者经 GraphQL 在服务器执行任意代码并落地持久化后门；无 CVE、无补丁、无缓解方案，Adobe 下一安全更新窗口为 9/8，全系 2.4.6-p15~2.4.9 均暴露

1 严重

Magento / Adobe Commerce「StyleSmuggler」零日 RCE（无 CVE · 无补丁 · 在野）—— 电商服务器沦陷

无 CVE · 无官方补丁 · CWE 待定 在野利用 · 影响全系 2.4.6-p15~2.4.9

Magento Open Source 与 Adobe Commerce 曝出未分配 CVE、无官方补丁的零日漏洞（Sansec 命名为 StyleSmuggler），未授权攻击者可通过 GraphQL 接口在目标服务器执行任意代码并植入持久化后门。Sansec 于 9 月 5 日公开早期通告，称商店正被实时攻陷；Disrex Group 已在两个完全被控实例上复现。Adobe 尚未发布 CVE、补丁或临时缓解，下一次安全更新窗口为 2026-09-08。受影响版本涵盖 2.4.6-p15、2.4.7、2.4.8、2.4.9 等当前全系。

漏洞机制/攻击方式：

  • 类型：未授权远程代码执行（0day，CVE 待 Adobe 分配；估算严重，约 9.8）
  • 攻击方式：借 GraphQL 注入恶意负载，绕过鉴权直接执行服务端代码，植入 cron 后门与 WebShell
  • 影响范围：所有暴露 GraphQL 的 Magento / Adobe Commerce 在线商店（含已打补丁的 2.4.6-p15 线）
  • 后果：支付数据与客户信息窃取、供应链跳板、门店被用作进一步攻击起点

值得关注的原因：

  • 当前最危险的在野 0day 之一：无 CVE、无补丁、无缓解方案，商家处于「盲飞」状态
  • 影响面巨大且窗口期长——headless/PWA 架构难以关闭 GraphQL，只能靠 WAF + 轮换凭据临时挡
  • 缓解：暂时禁用 GraphQL（经典/Hyvä 店面通常可关），部署 WAF 规则，排查 /wp 层异常并立即轮换凭据
恶意 GraphQL 负载 StyleSmuggler 0day 无补丁 未授权服务端代码执行 植入后门/WebShell 窃取支付/客户数据
2 严重

CrowdStrike Falcon「FalconFlank」零日 LPE（无 CVE · PoC 公开）—— EDR 自身成攻击面

无 CVE · 本地提权 SYSTEM · Win11 25H2/Server 2025

研究员「Nightmare Eclipse / Chaotic Eclipse」于 9 月 3 日公开 PoC（命名 FalconFlank），滥用 CrowdStrike Falcon Sensor 的「Office 恶意宏清除」功能，将低权限本地用户提升为 SYSTEM。已在全新补丁的 Windows 11 25H2 / Windows Server 2025 + 最新 Falcon Sensor 上确认可用；Kevin Beaumont、Vega 均独立复现。暂无 CVE、暂无补丁。

该漏洞属同一研究员一周内连发的安全代理 0day 系列（Kaspersky HardBreacher、Avast PrettyPrague、Nvidia GreenSection），呈现针对 EDR 的协同打击趋势。缓解：临时关闭 Falcon「Office File Suspicious Macro Removal」策略，保留 Cloud Anti-malware，监控 SYSTEM shell 由 Falcon 进程派生。

3 严重

N-able N-central CVE-2026-86218（CVSS 10.0）—— 预认证 RCE，MSP 供应链放大

CVSS v4 10.0 / v3 9.8 · CWE-96 9/6 披露 · Huntress 观测在野

N-able N-central（MSP 远程监控与管理平台）存在 预认证远程代码执行，CWE-96（静态代码注入），影响所有 < 2026.3.1.14 版本。N-able 于 9 月 6 日发布 Hotfix 4（2026.3.1.14）修复；官方称暂无生产环境利用确认，但 Huntress 已观测到在野利用，HF3 仍暴露。

一台控制台失陷即波及其下所有客户网络（SolarWinds / Kaseya 式供应链逻辑），CISA 8 月曾给 N-central 旧洞仅 3 天修复期限。本地自托管 HF3 须紧急升 HF4；托管（NCOD）已由厂商先行修复。

4 高危

Elementor Pro WordPress CVE-2026-32475（CVSS 9.8）—— 未授权上传 → RCE 在野

CVSS 9.8 · 600 万+ 安装 8/19 起在野 · 近 20 万次拦截

知名 WordPress 插件 Elementor Pro 文件上传校验缺陷，未授权攻击者可上传恶意 PHP 文件并远程执行命令。影响 ≤ 4.2.1；Elementor 8 月 19 日发布 4.2.2 修复，但同一天起即在野利用。Wordfence 已拦截近 20 万次尝试（8/19–8/23 占 19 万+）。

Form 的 File Upload 字段以数组提交，首元素留空、次元素放 .php，校验循环提前退出使恶意 PHP 绕过检查落入 /wp-content/uploads/elementor/forms/ 被执行。需站点含带上传字段的 Pro Form；更新后仍需手动清理已落地 WebShell。

5 高危

VMware Workstation / Fusion CVE-2026-59346 + 59347（宿主机代码执行 / 虚拟机逃逸）

需本地管理员 · 无缓解方案 突破 VM 隔离 → 宿主机

VMware Workstation 与 Fusion 披露两个严重漏洞：CVE-2026-59346（VMXNET3 整数溢出）与 CVE-2026-59347（HGFS 栈溢出），本地管理员可借此在宿主机执行任意代码，突破虚拟机隔离。暂无公开 CVSS，需本地管理员权限（常经钓鱼或弱配置获取），无临时缓解方案。

虚拟化隔离是安全边界核心——宿主机失陷等于同机所有 VM 与底层网络一并暴露。依赖 VMware 的办公/研发环境应优先打补丁，无法立即更新时收紧 VM 管理面与本地管理员权限。

速览区

6. MikroTik RouterOS 6 漏洞（2 个严重）在野劫持

CERT Polska 确认多个 RouterOS 漏洞（含 2 个严重）正被利用，攻击者可借互联网暴露的 SSH 服务未授权夺取设备完全管理权，全球数十万设备面临风险。

7. JetBrains Cadence 遭 TeamCity CVE-2026-63077 攻破

攻击者利用 TeamCity 反序列化 RCE（CVSS 9.8）入侵 Cadence 云环境，提取多枚 AWS IAM 密钥与密钥对，波及用户源码与 S3 数据；用户须立即吊销并轮换凭据。

8. Trezor / ShipMonk 供应链泄露 6.7 万客户

硬件钱包厂商 Trezor 的物流服务商 ShipMonk 遭入侵，暴露其声称已删除的 6.7 万美国客户数据，凸显第三方供应链风险。

9. ClickFix 借 BNB 智能合约投递，5,400+ 站点成跳板

大规模犯罪行动中，5,400 余个被入侵小企业站点经 BNB Smart Chain 链上智能合约存储/分发 ClickFix 载荷，显著增加取证与溯源难度。

10. REVSTEALER 模块禁用 Windows Update / Defender 挖矿

四个此前未记录的模块在主程序移除后仍持久化，可禁用 Windows Update 与 Defender 以运行加密货币挖矿，加固终端防护。

11. Citrix NetScaler CVE-2026-19490 认证绕过转入在野

据威胁情报周报，NetScaler 严重认证绕过漏洞已由披露进入在野利用阶段，延续边界设备 0day 被快速武器化趋势，建议收敛管理面并升级。
