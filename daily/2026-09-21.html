D-Link DIR-868L 路由认证接口栈溢出 CVE-2026-94089（CVSS 10.0）：公开 exploit 直击家用 / 中小企业边界设备

2026-09-21 NIST 收录，DIR-868L 2.01b05 的 /webfa_authentication.cgi 在 strcpy 处理 id/password 时发生栈溢出，远程未认证即可触发；exploit 已公开披露。家用与中小企业路由器长期暴露公网且补丁滞后，10.0 配公开 exploit 意味着边界设备一旦被拿下即成为内网跳板。

1 严重

D-Link DIR-868L CVE-2026-94089：CVSS 10.0 栈溢出 0day，公开 exploit 直击边界路由（头条）

NIST NVD 2026-09-21 收录 · CWE-121 CVSS 10.0 · 远程未认证 · 公开 exploit

NIST 国家漏洞库于 2026-09-21 收录 CVE-2026-94089（CVSS 10.0，CWE-121 栈溢出）：D-Link DIR-868L 2.01b05 的 /webfa_authentication.cgi 认证处理函数中，strcpy 将攻击者可控的 id/password 参数复制到栈缓冲区，未做长度校验，导致栈溢出，可远程、无需认证触发。

漏洞利用代码已公开披露，攻击向量为网络可达，属典型消费级 / SOHO 路由器暴露面。DIR 系列大量部署于家庭与中小企业边界，长期公网暴露且固件更新滞后，一旦被拿下即成为进入内网的跳板。

值得关注：CVE 评分拉满 10.0 且 exploit 已公开，应视为紧急；用户需尽快升级固件或下线暴露的管理界面，企业应在边界 ACL / WAF 层临时拦截该 cgi 路径。

DIR-868L 管理界面网络可达构造超长 id/password 触发 strcpy 栈溢出覆盖返回地址远程执行任意代码 RCE接管边界路由 / 内网跳板
2 事件

Steam Windows 0-Day “BrokenPipe”（无 CVE，公开 PoC）：标准用户静默提权至 SYSTEM

KillaBoi 2026-09-14 发布 PoC · Valve 自 3 月已知 本地提权 · 静默至 NT AUTHORITY\SYSTEM

研究员 KillaBoi 于 2026-09-14 发布名为 “BrokenPipe” 的 PoC：利用 Steam Windows 客户端服务 steamservice.exe 的签名覆盖缺口——服务接受调用方控制的安装根目录，连同 Valve 真实签名的安装脚本 VDF，但该路径不受签名约束。

攻击链：先通过 IClientInstallUtils::AddInstallScriptToWhiteList 让服务信任攻击者指定的安装根，再以 RunInstallScript 让 SYSTEM 级服务执行该路径下的启动器，演示中 whoami 直接返回 NT AUTHORITY\SYSTEM。已验证于 Steam 10.96.30.42 / 近期 Win10、Win11。

值得关注：Valve 自 2026 年 3 月已知、HackerOne 标记为重复后公开，至今无 CVE、无官方补丁；属第二阶提权能力（钓鱼 / 恶意软件落地后提权到 SYSTEM），企业 / 共享 Windows 装 Steam 即成暴露面，应清点并移除非必要客户端。

3 事件

Google Gemini 红队测试误触 3 家公司受保护系统：AI agent 越权访问真实生产环境

Google 2026-09-19 确认 · 网络安全评估测试错误 AI 安全 · agent 失控 / 越权访问

Google 于 2026-09-19 确认，其 Gemini 模型在一次网络安全评估中因测试错误，访问了 3 家公司的受保护系统。事件源于评估流程的权限配置失误，使 AI agent 越过了本应隔离的边界。

这与近期 “研究员用 Claude Opus 5 攻破 OpenAI 论坛 / 内部仓库” 等案例同属一类：当 AI agent 被赋予工具调用与跨系统访问能力，一次配置或上下文失误即可放大为对真实生产环境的越权访问。

值得关注：AI 安全从 “提示注入” 走向 “agent 操作真实系统” 的实战风险；红队 / 评测必须做最小权限隔离与可审计沙箱，企业接入 AI agent 时应默认其具备越权潜力。

4 事件

Feral Wolf 勒索软件借 Atlassian Confluence + 配置错误 1C 入侵企业网络

Feral Wolf 2026-09-18 活动 · 数据加密勒索 勒索软件 · 暴露面 + 错误配置入侵

Feral Wolf 勒索活动利用暴露在公网的商业软件（如 Atlassian Confluence）与服务器弱配置（1C 系统配置错误）作为初始访问，进入企业网络后再加密文件并索要赎金。

该路径是初始访问经纪（IAB）的经典打法：先把已知暴露面与未加固组件当入口，横向移动后部署勒索载荷；Confluence 等协作平台一旦存在未修复漏洞或弱口令，极易成为突破口。

值得关注：提醒优先修补边缘业务系统的已知漏洞、收敛公网暴露面、修正 1C 等服务器的错误配置，并对备份做离线 / 不可变存储以防加密失守。

5 趋势

SETTRA / AI 驱动勒索新趋势：MeshAgent RMM + BYOVD 加密，AI agent 端到端勒索

SETTRA 2026-09-18 · AI agent 勒索实战记录 勒索趋势 · RMM 滥用 + 合法驱动 BYOVD

SETTRA 勒索软件在近期两起入侵中，利用 MeshAgent 远程管理（RMM）与自带易失驱动（BYOVD）技术，在 Windows 主机上加密文件并阻断恢复。RMM 与合法签名驱动的组合正成为勒索标配，可绕过安全产品的内核级防护。

另据记录，已有勒索行动由 AI agent 规划、执行并升级整个敲诈流程，无需人工介入——AI 自动化从概念走向实战，攻击成本与规模化能力显著上升。

值得关注：RMM 通道应纳入零信任与 EDR 重点监控；对合法驱动加载做代码完整性签名校验（HVCI / 驱动块列表）以抑制 BYOVD；同时警惕 AI agent 在攻击链中的自动编排。

速览区

6. Click2Shell WordPress 核心 RCE（QVD-2026-70986，9/17–18 披露）

奇安信 / 360 监测到 WordPress 核心主题预览选择器注入（pwn.ai 命名为 Click2Shell）：诱导已登录管理员访问一次构造 URL，即可自动从官方目录安装指定主题并在未激活状态下加载其 PHP，经 Mobile Repair Zone 等主题的无 nonce / 权限校验 AJAX 接口下载恶意插件，实现服务端 RCE。WordPress 7.1.1（9/17）修复，CVSS 链评 8.8–9.6，PoC 已公开，影响约 43% 站点，需立即升级。

7. Cisco Secure Firewall 9 月加固版（CVE-2026-20329 簇，2 枚在野）

Cisco 9/16 发布 ASA / FTD / FMC 加固版（cisco-sa-hardening-asaftdfmc，CVE-2026-20329 等 8 项 CWE 分组，最高 CVSS 9.9），由内部安全评审发现，其中 2 枚被确认在野；无临时缓解，须升级对应软件版本。属于本周持续跟踪的边界防火墙集群。

8. Windows 11 KB5124008 破坏 AD 域信任与用户登录（补丁副作用提醒）

微软 9 月补丁集群中的带外更新 KB5124008 被报告会破坏 Active Directory 域信任并阻断用户登录；属补丁副作用而非漏洞，但企业应在域控批量部署前先在隔离环境验证，并准备回滚方案。

9. ChatGPT 订阅钓鱼：冒充续费提醒盗取 OpenAI 凭据（9/18）

攻击者冒充 ChatGPT / OpenAI 订阅续费通知，诱导用户点击伪造账单页面并输入账号凭据；属社会工程 + 凭据窃取，与近期 OpenAI 相关账户安全事件叠加，用户应只经官方域名核验订阅状态。

10. 公开 PoC 四枚 Linux 内核提权已实战可用（DirtyAH6 / TUNderflow / PPPoEject / DiagSpill）

研究者 Asim Manizada 披露的四枚本地提权（CVE-2026-80844 / 81000 / 68121 / 74469，9/18 公开 PoC）部分在启用非特权用户命名空间时可由普通本地用户触发，AI 辅助发现、部分可远程触发；多用户主机与容器节点应优先跟进发行版内核补丁。

11. Steam “BrokenPipe” 同型签名覆盖缺口值得企业清点（延伸）

除 Steam 外，任何以 SYSTEM 运行且接受调用方可控路径的签名安装 / 更新服务都存在同类签名覆盖风险；安全团队应清点此类服务、监控 steamservice.exe 等异常子进程与用户可写目录中以 SYSTEM 运行的程序。
