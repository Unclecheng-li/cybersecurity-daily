1 严重

CISA 8/18 KEV 纳入 Windows IKE 满分 RCE 与 SharePoint 认证绕过，8/21 大限逼近

CVSS 9.8 / 9.1 KEV / 8/21 大限

CISA 于 8/18 一次性将 4 个漏洞加入已知被利用漏洞目录（KEV），联邦机构须依 BOD 26-04 于 8/21 前修复。其中两个是 8/12 Patch Tuesday 刚修补、当时无在野标记、如今确认被利用的「新晋紧急项」：CVE-2026-33824（Windows IKE 双释放，9.8 未认证网络 RCE）与 CVE-2026-55040（SharePoint JWT 认证绕过，9.1，Rapid7 已公开 PoC）。

漏洞机制/攻击方式：

  • IKE 33824 类型：双释放（CWE-415），位于 ikeext.dll 的 IKEv2 分片重组，攻击者在 peer 认证完成前即可触达脆弱解析路径
  • IKE 攻击方式：IKE_SA_INIT 携带 Security Realm VID → 分片 IKE_AUTH（SKF）→ 堆指针浅拷贝致二次释放 → 内存破坏 → IKEEXT（SYSTEM）RCE
  • SharePoint 55040 类型：JWT 验证管线四连弱点（alg:none、x5t 指向自身证书、签发者校验未命中、签名仅要求非空）致未认证冒充管理员
  • 影响范围：暴露 UDP/500、UDP/4500 的 Windows VPN/IPsec 主机；SharePoint 2016/2019/Subscription Edition 场
  • 后果：IKE 项可直接拿下边界 Windows；SharePoint 项可链式拼接未修复 RCE 达完整未认证 RCE

值得关注的原因：

  • 两者同属 8/12 批次、修补时「无 flag」，仅 7 天即被确认利用——再次印证「Patch Tuesday 当天无标记 ≠ 安全」
  • IKE 项属「单一未打补丁的暴露 Windows = 直接利用路径」的最高危档，8/21 大限迫近须即刻提优先级
  • SharePoint 项是大型企业协作中枢，认证绕过历来是数据外泄入口，公开 PoC 已把利用门槛打到底
攻击者 IKE_SA_INIT(安全域VID) 分片IKE_AUTH(SKF) 双重释放 SYSTEM RCE
2 严重

VMware vCenter CVE-2026-59310（9.8）KEV 正式化：361 受害 / 47 国，中国背景 APT 部署 Babuk 勒索

CVSS 9.8 在野 / 勒索关联

vCenter Syslog 服务目录遍历漏洞 CVE-2026-59310（CVSS 9.8）在 8/18 被正式纳入 KEV，固化了 QUIRSO 事件响应已确认的结论：361 个受害 IP、覆盖 47 国。德国 IR 厂商 QUIRSO 以中等置信度评估该活动由中国背景威胁者运营，利用该漏洞执行任意代码并部署 Babuk 衍生勒索软件。Broadcom 已于 7/29 发布修复，但无官方变通方案，Metasploit / Nuclei 等公开框架集成后自动化扫描规模持续放大。

组件风险
VMware vCenter（暴露实例）严重 · 单点沦陷掌控全部虚拟机
vSphere 虚拟化基础设施高危 · 整片虚拟化底座失守
3 严重

macOS 屏幕共享 CVE-2026-65400（9.8）KEV 正式化：预认证 root + 门罗币挖矿

CVSS 9.8 在野 / KEV 级

macOS 屏幕共享 SRP 握手帧长校验错误致预认证认证绕过（CVE-2026-65400，9.8），攻击者可免凭据以 root 登录并植入 XMRig 挖矿。苹果 8/6 紧急 OOB 修复（Tahoe 26.6.1 / Sequoia 15.7.9 / Sonoma 14.8.9），NCSC-NL 8/12 发红色警报，公开 PoC 出现后数日内即在野，8/18 入 KEV 固化在野状态。

组件风险
macOS Screen Sharing（≤上述版本）严重 · 预认证 root

4 严重

Forminator WordPress 插件 CVE-2026-15748（9.8）公开修复：60 万+ 安装未认证 RCE

CVSS 9.8 已修复 / 批量风险

Forminator Forms 插件（影响 60 万+ 安装）存在未认证任意文件上传漏洞（CVE-2026-15748，CVSS 9.8），攻击者可上传含 PHP 的可执行文件导致远程代码执行与整站沦陷。影响 1.56.1 及之前版本，已于 1.56.2（7/31）修复。WordPress 插件是 Web 应用层最高频的未认证 RCE 入口之一，60 万级基数意味着 PoC 一旦扩散，自动化沦陷规模巨大。

值得关注：须立即核对版本并排查已上传的 webshell；仅升级不扫马会留潜伏后门。

5 高危

SAP Commerce Cloud CVE-2026-58231（CVSS 10.0）在野利用：企业级电商成新靶面

CVSS 10.0 在野 / 满分

SAP Commerce Cloud 满分严重性漏洞（CVE-2026-58231，CVSS 10.0）已被监测到针对性攻击尝试——补丁发布仅数日便出现利用，企业级电商 / 订单平台成为新靶面。电商系统直接关联交易、用户与支付数据，满分 RCE 在野意味着高价值数据外泄与供应链下游风险。

值得关注：开学季 / 大促前尤需优先核验补丁与入侵迹象，电商场须把「连接器与编排组件未授权访问」列为最高优先级加固项。
