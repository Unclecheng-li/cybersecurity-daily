1 高危

Apple iOS 27 / macOS Golden Gate 27 — 创纪录 261 CVE 批量修复（头条）

Apple 9/14 八产品线更新 · 内核级密集 261+ CVE · 最高 7.5 · 无在野

Apple 2026-09-14 一次性发布 iOS 27、iPadOS 27、macOS Golden Gate 27 及配套 5 个版本，修复超过 261 个 CVE，为苹果史上最大单次补丁周期。iOS 27 约 126 CVE（20 个内核），macOS 金门 27 达 210 CVE（内核 33、CUPS 10、SMB 9、WebDAV 4），Tahoe 26.7 另有 153 CVE。

关键漏洞：CoreMedia CVE-2026-64752（恶意图片即攻陷 iPhone，Apple 直接删代码）、CUPS CVE-2026-43692（远程 RCE）/ CVE-2026-64790（提权）、SMB CVE-2026-43690（内核内存读）。已核实最高 CVSS 仅 7.5，Apple 与 SANS ISC 均未标记在野。

值得关注：内核级修复密集，企业需同日内 MDM 推送（Jamf：这是内核版而非浏览器版）；本次 10 个漏洞由 AI（Claude/Anthropic、Nvidia AI Red Team）直接发现，AI 辅助漏洞狩猎进入主流。细节公开即打开攻击窗口。

2 高危

Angular SSR 双高危 CVE-2026-88060（XSS）+ CVE-2026-88056（SSRF/凭据泄露）

@angular/platform-server · CWE-79 / CWE-918 CVSS 8.6 · 修复 20.3.30/21.2.22/22.1.4

Angular 服务端渲染（@angular/platform-server）两枚高危，CVSS 4.0 均 8.6，9/10 披露、修复版本 20.3.30 / 21.2.22 / 22.1.4。

CVE-2026-88060：SSR 序列化时 noscript/iframe 等 fallback raw-content 元素内未转义用户内容 → XSS；CVE-2026-88056：URL 解析对 Unicode 空白（U+00A0/U+FEFF）的 trim() 差异绕过同源校验 → SSRF 并泄露 Authorization 等后端凭据。Renderer2 命令式 DOM 构造无条件受影响。

3 高危

Google Chrome 153.0.8010.47 批量修复约 42 个 CVE

CVE-2026-91708 ~ 91749 · ServiceWorker / V8 / PDF 多 High · 含沙箱外 UAF

Chrome 153.0.8010.47 一次性修复约 42 个 CVE（CVE-2026-91708~91749）。含 ServiceWorker 类型混淆 CVE-2026-91715（8.8）、V8 UAF CVE-2026-91745、PDF UAF CVE-2026-91737。

尤为关键的是两个沙箱外 UAF：DigitalCredentials CVE-2026-91729 与 Auth CVE-2026-91716 可在沙箱外执行代码。浏览器是首要客户端攻击面，Chrome / Edge / Opera 需同步升级。

4 严重

Marimo CVE-2026-39987（9.8）预认证 RCE → 8 秒拿下 SSH 堡垒机

CVE-2026-39987 · 终端 WebSocket 端点缺鉴权 CVSS 9.8 · CISA KEV（4月起）

Marimo notebook 的终端 WebSocket 端点跳过鉴权（其他端点有），任意连接者即获 Marimo 进程用户的交互式 shell。Sysdig 观测到人类攻击者 8 秒从 RCE 跳到 SSH 堡垒机，从进程环境/Redis 拖走云凭据，并用 AWS Secrets Manager 私钥认证；自 2026-04 已在 CISA KEV。

Marimo 常跑在 ML 训练管线、持云凭据；单点未授权 shell 直接变云账号沦陷。修复：升级 0.23.0，并对终端 WS 端点加鉴权或禁用。

5 中危

WSO2 Integrator MI VS Code 扩展 CVE-2026-19515（OS 命令注入）

CVE-2026-19515 · CWE-78 · workspace trust CVSS 7.0 · 开发者工具链

WSO2 Integrator MI 的 VS Code 扩展在处理不可信 Micro Integrator 项目时，单元测试执行流可注入任意 OS 命令（CWE-78）；需用户授予 workspace trust 后触发（CVSS 3.1 7.0）。

开发者工具链是供应链入口，CI/开发工作站凭据暴露风险；升级扩展并谨慎授予 workspace trust。

速览区

6. AWS TEAM 86830 + Kiro IDE 89332

AWS TEAM 样本方案 CVE-2026-86830（认证用户获取非预期临时提权）+ Kiro IDE CVE-2026-89332（恶意仓库重定向 Kiro Powers registry 请求、窃取工作区数据）；升级 TEAM <1.5.1、Kiro IDE <0.8.135。

7. WordPress CVE-2026-65640 — Author+ RCE

经 Imagick + Ghostscript 恶意文件上传触发的作者级 RCE（需作者权限 + 图像处理路径），暴露站点应升级至当前维护版本。

8. ShinyHunters 攻破 Odido，约 600 万客户数据泄露

典型大规模数据泄露事件，需关注凭据重置与钓鱼次生风险，受影响用户应警惕针对性社工。

9. CISA KEV 9/16 截止双漏洞

BerriAI LiteLLM CVE-2026-59822（8.8，MCP 认证绕过）与 Kludex Starlette CVE-2026-48710（HTTP 走私）今日处置大限，联邦机构须完成修复。

10. "漏洞潮"(vulnpocalypse) 趋势确立

Apple 本次 10 个漏洞由 AI（Claude/Anthropic 协同 Calif、Nvidia AI Red Team）直接发现，AI 辅助漏洞狩猎进入主流，攻击方同样在用 AI。
