Spring Security Authorization Server CVE-2026-22752 认证绕过（CVSS 9.6）

CVE-2026-22752 · CVSS 9.6 (CWE-287) 修复版本已发布

Spring 官方披露 Spring Security Authorization Server 的「主认证弱点导致的认证绕过」漏洞（CWE-287），影响 7.0.0–7.0.4、1.5.0–1.5.6、1.4.0–1.4.9、1.3.0–1.3.10。攻击者只需低权限用户身份即可构造特制授权请求绕过主认证路径，签发高权限访问令牌，横向接管基于 OAuth2/OIDC 的微服务与资源服务器。

漏洞机制/攻击方式：

  • 类型：认证绕过（CWE-287）/ 授权服务器主认证弱点
  • 攻击方式：低权限用户构造特制授权请求，被误判为已认证主键
  • 影响范围：所有依赖该授权服务器的 OAuth2/OIDC 资源服务器、API 网关、SSO
  • 后果：签发高权限令牌、横向接管微服务、作用域变更（S:C）放大爆炸半径

值得关注的原因：

  • 身份信任根沦陷：下游所有依赖方同步失守，云原生/多租户尤甚
  • CVSS 9.6 且作用域变更，存量老版本（1.3/1.4/1.5）长尾未升级
  • 官方已修复但私有化部署升级滞后，攻击窗口较长
低权限用户 特制授权请求 绕过主认证 签发高权令牌 接管OAuth/OIDC资源
2 高危

Google Chrome 7 月稳定版更新：12 漏洞 / 9 高危含 RCE 簇

CVE-2026-16418 / 16423 / 16424 等 Chrome 150.0.7871.181

谷歌 7 月推送 Chrome 稳定版紧急补丁，Windows/macOS 升至 150.0.7871.181/.182、Linux 同步至 150.0.7871.181，一次性修复 12 处漏洞（9 个高危）。核心风险集中在内存安全：V8 引擎栈缓冲区溢出 CVE-2026-16418、GPU/UI 模块释放后重用 CVE-2026-16423 / CVE-2026-16424，并可串联 ANGLE 越界读写、Skia 未初始化变量、WebAudio 类型混淆等；其中 2 个由 AI 安全研究系统 XBOW 发现。

受影响组件：

组件风险
V8 引擎 / GPU / UI 模块高危
ANGLE / Skia / WebAudio / 扩展中高危
3 高危

Cisco SD-WAN Manager 零日在野（CVE-2026-20245，CVSS 7.8）

CVE-2026-20245 · CVSS 7.8 在野利用 · root

Mandiant 披露 Cisco Catalyst SD-WAN Manager（原 vManage）CLI 命令注入漏洞 CVE-2026-20245（CWE-116）曾被当零日利用至少两个月，早于思科 6/4 披露。攻击者 3 月以合法管理员凭据（疑似借 CVE-2026-20127 / CVE-2026-20182 认证绕过）登入，上传 evil_tenant.csv 触发命令注入以 root 执行，创建 UID 0 隐藏账户 troot 并反取证。SD-WAN Manager 是企业广域网「大脑」，root 失守等于重定流量、禁用安全策略、向所有边缘设备下发恶意配置。

受影响组件：

组件风险
Catalyst SD-WAN Manager/Controller/Validator高危
本地/云托管/FedRAMP 全部署形态中高危
4 高危

Redis 认证 RCE 绕过变体（QVD-2026-44936 / CVE-2026-25589，CVSS 8.8）

QVD-2026-44936 · CVSS 8.8 PoC公开 · 7/23七版本修

奇安信 CERT 监测到官方修复的 Redis 认证 RCE 漏洞 QVD-2026-44936——CVE-2026-25589 的绕过变体。根因在 Streams 消费者组处理共享 NACK 时的内存释放逻辑缺陷致双重释放，攻击者可借 XGROUP、XACK、RESTORE 等命令构造 payload 实现任意代码执行。PoC 与技术细节 7/23 公开，影响 6.2.22 / 7.4.9 / 8.6.4，官方以七个版本修复。

5 中高危

Coolify 认证后命令注入 RCE（CVE-2026-34038）

CVE-2026-34038 · 影响 < 4.0.0-beta.469 密钥外泄 · PoC公开

自托管 PaaS 平台 Coolify 被披露认证后远程命令注入漏洞 CVE-2026-34038，已认证攻击者触发 RCE 并外泄密钥/环境变量。GitHub PoC 与 Tenable、NVD 记录就位，修复版本 v4.0.0-beta.469 已于 7/6 发布（GHSA-qqrq-r9h4-x6wp）。开发者/DevOps 工具链常驻云凭证与生产环境变量，RCE 即钥匙串沦陷。
