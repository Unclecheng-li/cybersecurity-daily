BlueMoon 利用套件：Chrome V8 + Windows ALPC 零日链被 4 个国家级 APT 一周内复用（CVE-2026-85046 / 87491 / 85880）

Proofpoint 9/11 披露 BlueMoon 套件串联 Chrome V8 类型混淆（CVE-2026-85046）+ V8 沙箱逃逸（CVE-2026-87491）+ Windows ALPC 提权（CVE-2026-85880）；前两个为「补丁间隙」零日，APT31/TA412 自 8/28 起钓鱼投递，12 天内至少 4 个国家级集群原样复用，疑似 AI 辅助开发。

1 严重

BlueMoon 利用套件 — Chrome + Windows 零日链（头条）：APT31 等 4 集群 12 天内复用

CVE-2026-85046 / 87491 / 85880 · V8 类型混淆 + 沙箱逃逸 + ALPC 提权 KEV · 三个均已修复

Proofpoint 将这套被至少 4 个国家级 APT 采用的浏览器+系统利用链命名为 BlueMoon。它把三个漏洞串成完整链路：CVE-2026-85046（Chromium V8 类型混淆，可越 V8 沙箱读写堆内存）、CVE-2026-87491（V8 沙箱逃逸，覆写 WebAssembly 元数据执行 shellcode）、CVE-2026-85880（Windows ALPC 堆溢出本地提权，逃逸渲染进程拿 SYSTEM）。前两个 V8 漏洞在被利用时是「补丁间隙（patch-gap）」零日：上游 Chromium 已公开修复，但稳定版 Chrome/Edge 尚未合入，攻击者直接逆向公开补丁造链。

首个使用者是中国背景 APT31 / TA412（JungleBamboo，紫光台风），8/28 起经钓鱼邮件投递，目标含美国 NGO、矿业与大宗商品交易商；随后 UNK_LateNight（对美航空航天投 ShadowPad）、UNK_DoubleCheck（越南制造）、UNK_QuietRacket（印尼/新加坡政府金融）在 12 天内几乎原样复用同一套代码。工具链里发现详尽调试日志、markdown 交接文档与「请把完整 log 发回」注释，高度疑似 AI 辅助开发。

值得关注的原因：这是 2026 年首次出现「公开补丁→快速武器化→多国 APT 同日复用」的浏览器零日扩散模式；三个漏洞现均已修复并进入 CISA KEV，但已中招主机仍可能残留载荷与持久化。默认载荷只是 curl 下载执行木马（高检出信号），说明开发者优先抢在 9/3、9/8 Chrome 补丁前铺开。

2 严重

FortiGate CVE-2025-25249 在野：PivotC2 RAT 把边界防火墙变内网支点（CVSS 9.8）

CVE-2025-25249 · FortiOS/FortiSwitchManager cw_acd CVSS 9.8 · KEV · 截止 9/12

FortiOS / FortiSwitchManager cw_acd 守护进程存在堆溢出（CWE-122/787），攻击者可借发往 UDP/5246 CAPWAP 控制端口 的特制包实现未认证 RCE。2026 年 1 月已由 Fortinet 修复，但 SOCRadar 确认 至少自 2026 年 7 月起在野利用，通过 fortirun.bin + Bash/Python 自动化反复扫描，目标超 3 万个 FortiGate IP，确认 178 台被植入 PivotC2。

PivotC2 是专为 FortiGate 后渗透定制的 Node.js RAT：外连 TLS C2、交互式 shell、SOCKS5/HTTP 代理隧道、CIDR 扫描，并能解密设备配置与凭据（SSL-VPN、LDAP、无线 PSK、IPsec）。其 --auto 模式可自动收割配置、解密凭据并横向扫描内网。归因指向俄语背景、逐利型团伙，已造成两起美国机构全网入侵与数据外泄。修复至 FortiOS 7.6.4/7.4.9/7.2.12/7.0.18+，并限制 CAPWAP 暴露、轮换所有相关凭据。

3 严重

MikroTik RouterOS 双漏洞入 KEV（CVE-2026-67277 + 86060，截止日即今日 9/13）

CVE-2026-67277 / 86060 · MikroTrick 链 CVSS 8.8 / 9.2 · 截止 9/13

CERT Polska 命名的 MikroTrick 链含三洞，其中两个于 9/10 入 KEV、修复截止日正是 2026-09-13：CVE-2026-67277（CWE-306 缺失认证，CVSS 8.8）btest 服务可被未授权连接拖入登录后状态，泄露内核内存或令路由重启；CVE-2026-86060（CWE-88 参数注入，CVSS 9.2）通过构造用户名篡改策略掩码提权至管理员；外加 CVE-2026-67276（CWE-347 签名校验缺陷，CVSS 9.2，未入 KEV）仅匹配 RSA 模数即可伪造密钥登录，与 86060 组成完整链（需 7.9+）。

受影响 6.x < 6.49.21、7.x < 7.23.4/7.24.2 及 7.25 beta3 之前。加拿大网络安全中心（AL26-020）9/10 警告 SSH 公网暴露设备风险最高。6.x 仅 6.49.21 一个修复线，更老的 6.48 等已 EOL 无补丁。

4 高危

微软 Defender 第 11 个零日 ShieldCrash（Nightmare Eclipse，9/11 披露）

ShieldCrash · 绕过 ShieldBreak CVE-2026-69414 无 CVE · 9/11 披露

知名零日猎人 Nightmare Eclipse（又名 MSNightmare）9/11 再发 ShieldCrash 概念验证，据称可绕过 9 月刚修的 ShieldBreak（CVE-2026-69414）补丁，以 SYSTEM 权限读取任意文件（暂不支持任意写入或完整 SYSTEM shell），在已打 9 月补丁的 Windows 10/11/Server 上仍有效。它延续 RoguePlanet（CVE-2026-50656）→ ShieldBreak → ShieldCrash 的「补丁绕过」链路，是该研究员第 11 个微软零日。

目标已从 Defender/BitLocker 扩展到 CrowdStrike Falcon（FalconFlank）、Avast（PrettyPrague）、NVIDIA（GreenSection）、Kaspersky（HardBreacher）。微软尚未回应修复时间。企业应将「安全 agent 派生异常 SYSTEM 进程/文件读取」纳入检测。

5 严重

GitLab 路径遍历未授权读文件 CVE-2026-85706（CVSS 10.0，已入 KEV 在野）

CVE-2026-85706 · GitLab CE/EE < 19.1.8/19.2.6/19.3.2 CVSS 10.0 · KEV 在野

GitLab CE/EE 在 18.7 至 19.1.8/19.2.6/19.3.2 之前，因 commits API 的路径限制缺失 + 认证强制缺失，未认证用户可读服务器任意文件。CISA 已确认在野并列入 KEV，多国 CERT 发布紧急通告；同批 GitLab EE 还修了 Duo Chat 凭据泄露（CVE-2026-87719，CVSS 9.9）。

GitLab 常承载源码与 CI 密钥，未授权文件读取可直接外泄 config/secrets、CI 变量与私钥；公网暴露实例应立即升级并排查异常文件读取日志。

速览区

6. Citrix NetScaler CVE-2026-19490（CVSS 9.3 v4，KEV，截止 9/12）

Gateway/AAA vserver 认证绕过（CWE-288），无 workaround；Previdian 蜜罐自 9/3 起记录 56 次利用尝试、9/8 单日 36 次。升级至 14.1-73.32 / 13.1-63.21+。

7. Progress Chef Automate CVE-2026-80462（CVSS 10.0）

API 网关/身份校验绕过致未认证提权，管理大规模基础设施的实例风险极高，已有可用利用；Chef Automate 控全域配置，失陷即失整个机群管理权。

8. Plesk Backup Manager CVE-2026-68487（CVSS 9.9）+ CVE-2026-68488

认证客户可借路径遍历以 root 写任意文件，与 TOCTOU 提权（68488）叠加；共享主机环境下任意客户可升至 root，影响数百万托管站点。

9. WordPress Everest Forms CVE-2026-62103（CVSS 9.8）

≤3.6.0 未认证 PHP 对象注入 → 任意代码执行，流行表单插件、利用门槛极低；WordPress 插件通常在披露数小时内被大规模利用。

10. AI/ML 漏洞浪潮：OpenNLP 82617×10.0 + Mistral Vibe 87988×10.0

Apache OpenNLP 与 Mistral AI Mistral Vibe 同日披露 CVSS 10.0 漏洞，Mistral Vibe 已有公开利用；AI 编码/推理链路成为新攻击面。

11. 勒索态势（Ransomware.live 9/12）：24 名受害者

krybit（12）、medusalocker（4）领先；制造业/专业技术服务持续承压，边缘设备漏洞（Citrix/Fortinet/MikroTik）仍是主要入口。
