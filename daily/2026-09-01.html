1 严重

PaperCut NG/MF 双零日链式 RCE 在野，CISA KEV 8/31 正式收录（CVE-2026-81578 8.8 + CVE-2026-82078 9.4）

CVSS 8.8 / 9.4 · CWE-862/类加载 在野 · KEV 8/31 · 公开 PoC

PaperCut NG/MF 打印管理平台的 Web 管理接口被暴出两条可链式的零日：CVE-2026-81578（CVSS 8.8，CWE-862 权限不当）是认证绕过，未认证远程请求可在后台鉴权完成前触发管理动作；CVE-2026-82078（CVSS 9.4，不安全动态类加载）借此 foothold 篡改数据库驱动配置，让 PaperCut 按攻击者可控类名实例化任意 Java 字节码，在服务进程上下文执行任意代码。两者均无需认证。

Huntress 观测到最早利用出现在 8 月 26 日（早于厂商 8/27 公告）；WatchTowr 发现首版紧急补丁可被绕过，迫使 PaperCut 在 8/28 当天连发 Emergency Patch Release 2 覆盖 v24/v25/v26。公开 PoC 已流出；Shadowserver 统计约 1000 台实例仍直连公网。CISA 于 8 月 31 日将两条一并纳入 KEV。

值得关注：打印服务器常被视为背景基础设施，却掌有 credentials、连着文件系统与目录服务，是内网跳板的天然落点；「披露→在野→补丁被绕过→二补」压缩在 48 小时内，只打了第一版补丁的实例仍暴露。

公网 PaperCut 接口 CVE-2026-81578 认证绕过 篡改 DB 驱动配置 CVE-2026-82078 类加载 RCE 横向/勒索前置
2 严重

ServiceNow AI Platform 三连 CVSS 10.0 未认证 RCE（CVE-2026-18885/18886/74820 + CVE-2026-6876）

CVSS 10.0×3 · CWE-94/284/89 已修复 · 自托管需手动

ServiceNow 于 8 月 27 日发布公告，AI Platform / Now Platform 一次修掉四个漏洞，其中三个打满分：CVE-2026-18885（GraphQL Composite Data API 代码注入，未认证任意代码执行）、CVE-2026-18886（系统配置镜像上传超权提权至管理员）、CVE-2026-74820（动态 schema 的 ORDER BY 子句 SQL 注入）；外加 CVE-2026-6876（CVSS 8.7，Now Platform 脚本沙箱逃逸）。四个评分均 CVSS v4.0 向量 AV:N/AC:L/PR:N/UI:N。

SaaS 托管实例已由厂商推送修复；自托管实例需自行升级（Xanadu ≥ Patch 11 HF 7a、Yokohama ≥ Patch 12 HF 3b / Patch 13 HF 4 等）。截至 8/28 未观测到在野利用，也无公开 PoC。值得关注：ServiceNow 是 ITSM/HR/CMDB 的系统级记录源，85% 财富 500 强在用，未认证 10.0 = 一步击穿机密性/完整性/可用性。

3 严重

Next.js 双未认证 RCE：Windows 路径遍历 CVE-2026-75604（9.0）+ libheif AVIF 堆溢出（9.5，PoC 已公开）

CVSS 9.0 / 9.5 · CWE-22/堆溢出 修复 15.5.24/16.3.3 · PoC

Vercel 于 8 月 25 日提前发布紧急补丁，修掉两个均可未认证 RCE 的 Next.js 漏洞。CVE-2026-75604（CVSS 9.0）Windows 路径遍历：仅影响同用 Pages+App Router（未启 Cache Components）且底层为 Windows 文件系统的自托管部署，厂商明言无变通方案。其二是 libheif 堆缓冲区溢出（CVSS v4 9.5）：Next.js 经 sharp→libheif 解析 AVIF，特制文件触发两个不同位深 Alpha 平面，越界约 16384 字节；研究者已放出可复现 ASan 崩溃的 Python PoC。

仅当站点在 next.config.js 显式开启 image/avif 才暴露；Vercel 托管实例已免疫。值得关注：这是框架层 + 原生 C 库双重失守，补丁版直接关闭 AVIF 优化直到 libheif 上游修复；公开 PoC + 未认证 + 仅需诱导优化一张外链 AVIF，蠕虫化门槛极低。

4 严重

Ubiquiti 一波 21 漏洞横扫 UniFi 全家桶，多个 CVSS 10.0（认证绕过/命令注入/提权）

21 漏洞 · 多 CVSS 10.0 已修复 · 边缘设备

Check Point 周报汇总，Ubiquiti 一次性修复影响 UniFi Protect、Network、Access、Talk、UniFi OS 等产品的 21 个高危/严重漏洞，涵盖认证绕过、命令注入、权限提升，其中多个评分 CVSS 10.0。成功利用可取得受影响设备的管理员控制权。

值得关注：UniFi 设备是大量中小企业与家庭网络的边缘总控，管理员控制权 = 看得见内网流量、可 MITM、可横向进数据中心；单批 21 个、多满分，是「设好就忘」型网络设备被集中收割的羮影。

5 严重

ArgoCD MCP Server 绑定 0.0.0.0 无认证（CVE-2026-82456，CVSS 10.0）—— GitOps 供应链接管

CVSS 10.0 · CWE-1327 修复 0.9.0 · 无 PoC

argoproj-labs 的 argocd-mcp 0.8.0 在配置 ARGOCD_API_TOKEN 时，将 HTTP 传输绑定到所有网络接口（0.0.0.0）且接受无凭据的 MCP 会话。任何能访问该端口的攻击者，都可复用运维者存储的令牌调用完整工具面——创建 Application、触发 Sync、修改 Argo CD 资源，从而未认证接管整个 GitOps 流水线。

8/29 公开，CVSS 双版本均 10.0，影响 >=0.8.0 <0.9.0，修复版 0.9.0。值得关注：MCP Server 本用于把 AI 代理连到 GitOps，内网暴露即等于任何失陷主机/内鬼都能接管部署；危害是供应链攻击——攻击者可把 Application 指向自控 Git 仓库、sync 恶意 manifest 到集群埋后门。

速览区

6. Manchester Airports Group 约 870 万客户数据泄露

英国曼彻斯特、伦敦斯坦福德、东米德兰关三大机场运营方揭示网络攻击，约 870 万客户数据外泄，含联系方式、车牌、停车场/贵宾厅/快速通道/Wi-Fi 注册信息。

7. McKesson 约 2.84 亿患者记录泄露（ShinyHunters vishing→Okta）

美医药巨头 McKesson 确认第三方应用被未授权访问致数据外泄；ShinyHunters 借 vishing 攻突 Okta 账户，进而触达 Salesforce 与 Snowflake，外泄约 1TB、2.84 亿 patient 记录——身份与 SaaS 生态连锁失守范本。

8. 美国 ATF 遭网络攻击，Qilin 勒索列名泄露站

美国酒精、烟草、火器与爆炸物管理局（ATF）确认一台独立计算机遭入侵；Qilin 勒索検伏将其列入泄露站并认领。政府/关键机构成勒索常态化目标。

9. Boston Scientific 全球业务中断

美医疗器械巨头 Boston Scientific 遭遇网络攻击，造成网络中断并扰乱全球运营，订单处理与发货相关内部系统受影响，8/26 中断后启动恢复。医疗供应链可用性风险显现。

10. AI 威胁升级：加密上下文注入 + Amazon Kiro 提示注入

研究者提出 Cryptographic Context Injection，把恶意指令藏进加密内容绕过 AI 助手护栏（Grok 泄露对话、Gemini 生成应被拦内容）；Amazon Kiro 提示注入漏洞，恶意工作区文件可控制代理外传本地信息，已在 0.8.140 修复。

11. 美噖骨碰 QScan / QTRouter（中国关联 QTFY 针对关键基础设施）

美方宣布打掉中国关联组织 QTFY 运营的两个平台：QScan 感染联网设备，QTRouter 借失陷系统隐藏针对 NASA、美联储、能源部等政b击来源。国家级 APT 对关键基础设施的潜伏式入侵持续升级。
