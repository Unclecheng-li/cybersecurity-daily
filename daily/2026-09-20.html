SolarWinds ARM 硬编码密钥 CVE-2026-28326（CVSS 8.8）未认证 RCE：内置静态密钥即可伪造令牌拿下企业身份平面

2026-09-17 披露，SolarWinds Access Rights Manager 因 CWE-321 硬编码密钥，攻击者无需任何凭据即可伪造认证令牌、以服务身份执行任意命令；影响 2026.2 及此前所有版本，修复 ARM 2026.2.1。ARM 身处管理网段、以域特权账户运行，RCE 即意味着直接拿下 AD / Azure AD 身份治理平面。

1 高危

SolarWinds ARM CVE-2026-28326：CVSS 8.8 硬编码密钥未认证 RCE，身份管理平面被攻破（头条）

SolarWinds 2026-09-17 披露 · CWE-321 CVSS 8.8 · 影响 Access Rights Manager

SolarWinds 身份管理产品 Access Rights Manager（ARM）存在 CWE-321 硬编码加密密钥：产品内置一个所有安装完全相同的静态密钥。攻击者只要能网络触达 ARM 服务端口（CVSS 攻击向量为相邻网络 AV:A），即可用该密钥伪造认证令牌、以服务身份执行任意命令，全程无需任何凭据。

漏洞于 2026-09-17 随 ARM 2026.2.1 修复披露，影响 2026.2 及此前所有版本，由 Armadin 研究员 Kai Huang 负责任披露。SolarWinds 称暂无在野利用证据，但硬编码密钥一旦公开即会迅速被尝试。

值得关注：ARM 通常身处管理网段、以域特权服务账户运行，RCE 即意味着直接拿下企业身份平面（AD / Azure AD）；攻击者可借机轮换/窃取其管理的凭据，单点失守即牵连全组织。

ARM 端口网络可达 提取硬编码静态密钥 伪造认证令牌 未认证 RCE 接管身份平面 凭据轮换 / 横移
2 事件

OpenAI 社区论坛 HEIF Heist：libheif RCE + SSO 缺陷链接管员工账号与内部代码库

Hacktron AI 2026-09-18 披露 · 授权赏金 72 小时 · AI 代币 < $3000

三名研究员从 OpenAI 公开社区论坛（Discourse）一路打到内部 monorepo：入口是 Discourse 处理 HEIC/HEIF 上传时调用的 libheif 堆缓冲区溢出（上游已修但未被标记为安全问题、未回灌 Debian 12/13），上传特制图片即在论坛服务器 RCE。

借 OpenAI 单点登录（SSO）配置缺陷，论坛 RCE 的令牌可横跳至员工 ChatGPT / Codex 账号；研究者用被接管账号向内部仓库提交无害 PR 证明可达。AI 角色突出：Claude Opus 4.8 反复失败，Opus 5 发布后数小时内给出可用 ARM64 利用。

值得关注：边缘系统经 SSO 打通核心；上游修了不等于你修了；同一 libheif 缺陷还波及 Slack / Zoom / Meta / GitHub Enterprise / Next.js。

3 严重

Linux 内核三漏洞入 CISA KEV（9/19）+ 四枚本地提权公开 PoC

CISA KEV 2026-09-19 · BOD 26-04 CVSS 9.8 + 8.8 + 7.8 · 本地

CISA KEV 9/19 新增实战利用：CVE-2025-39682（CVSS 9.8，TLS 接收路径异常检查 → 内存泄露/DoS，本地已认证）、CVE-2026-53266（CVSS 8.8，ebtables SNAT OOB 写）、CVE-2025-39964（CVSS 7.8，af_alg 竞态）；修复截止日 2026-09-21，Red Hat 确认在野。

研究者 Asim Manizada 披露四枚本地提权（9/18 公开 PoC）：CVE-2026-80844「DirtyAH6」、CVE-2026-81000「TUNderflow」、CVE-2026-68121「PPPoEject」、CVE-2026-74469「DiagSpill」；其中三枚在启用非特权用户命名空间时可由普通本地用户触发。

值得关注：本地提权 + 容器逃逸风险叠加；多用户主机、容器节点、云主机应优先跟进发行版补丁，9/21 大限临近。

4 严重

Red Hat OpenShift Console CVE-2026-75885（CVSS 9.3）未认证 SSRF + DoS，暂无补丁

Red Hat OpenShift 2026-09-18 · CWE-918 CVSS 9.3 · 网络可达未认证

CVE-2026-75885（CVSS 9.3，CWE-918 SSRF）：/api/devfile/ 与 /api/devfile/samples/ 路由未包裹鉴权中间件，未认证即可访问；devfile 解析器对 parent.uri / Kubernetes URI 等发起出站请求且未校验目标。

console pod 可作为代理请求内部服务（云元数据、etcd、kubelet）并回显部分响应 → 内网侦察 / 防火墙绕过；另可借无 Content-Length 限制的大请求触发无界内存增长导致 DoS。

值得关注：Kubernetes 控制平面边缘未认证 SSRF，Red Hat 截至披露暂无可用缓解与修复包，需在网络层（ingress / WAF）临时拦截并强化内部服务鉴权与隔离。

5 高危

SiYuan 笔记 CVE-2026-93921/93922/93923：Electron XSS → 操作系统命令执行（≤ 3.8.4）

SiYuan 2026-09-18 · VulnCheck CVSS 8.8×2 + 5.3 · 修复 3.8.5

CVE-2026-93922（8.8/8.6）：Daily Note 选择器把笔记本名当原始 HTML 渲染不转义，存储型 XSS 在 Electron 渲染进程执行带 Node.js 权限的 JS → 操作系统命令执行。

CVE-2026-93923（8.8/8.6）：大纲 / 书签坞 HTML 未转义标题样式属性，可注入恶意样式以完全系统权限执行。CVE-2026-93921（5.3）：getDynamicIcon 端点访问控制绕过，只读令牌可读受限文档元数据。

值得关注：桌面端 Electron 应用 XSS 直出系统命令执行，默认启用 Node.js 集成即受影响，协作同步场景下可跨用户触发；升级 3.8.5。

速览区

6. Gyazo 数据泄露：2362 万用户记录 + 4.9 亿图片元数据

运营方 Helpfeel（京都）9/16 确认，9/11 攻击者利用图片上传服务器漏洞执行任意命令并访问数据库，泄露约 2362 万用户记录（姓名/邮箱/密码哈希/X 集成令牌等）与约 4.9 亿张图片元数据（图片 ID、上传 IP、EXIF、OCR 文本、私有图通行短语）；无支付信息。9/12 阻断路径、修复漏洞，9/15 报告日本个保委，服务暂停，用户须改密。

7. CrowdSec 遭 TanStack npm 供应链攻击牵连：170 私有仓库被复制

法国安全厂商 CrowdSec 9/18 披露，攻击者于 5/22 用一名已离职但未撤销 GitHub 权限的员工账户复制约 170 个私有仓库（代码 9/16 现身论坛）。源头为 5/11 TanStack npm 投毒（42 包 84 恶意版本，CVE-2026-45321，凭证窃取木马 Shai Hulud）攻陷该员工笔记本并盗取 OAuth 令牌；同一攻击还波及 Mistral AI、OpenAI。83 名用户邮箱与 51 名投资人信息暴露。

8. Totolink A3002MU 多个缓冲区溢出（CVE-2026-93739/93740/93738）

formWlEncrypt / formWlAc 函数对 submit-url 参数处理不当导致堆溢出，Tenable 9/18–19 标记为 critical 且公开利用代码可用，可远程触发，属消费级路由器高危面。

9. Windows 11 26H1 本地提权（CVE-2026-62721 / CVE-2026-85921）

两枚本地权限提升（至 SYSTEM 与 VTL1），需立即部署带外更新 KB5129194（9/19 漏洞汇总）；属 9 月补丁集群的后续 LPE，需本地初始访问。

10. WordPress WPComplete 插件 CVE-2026-77820 存储型 XSS

经 'empty' 短代码属性的存储型 XSS，≤ 2.9.9.0 全版本，需 contributor 及以上权限且限定专业版，Medium 严重度。

11. SolarWinds 同批补丁：Serv-U 16 枚漏洞 + WHD 两枚

除 ARM 外，Serv-U 修复 16 枚漏洞（CVE-2026-28302、28304–28317、28321 等，可致提权/RCE/未授权管理员账户创建）；Web Help Desk 同批修 CVE-2026-28323（9.8 SAML 绕过）与 CVE-2026-28299（8.2 拒绝服务）。
