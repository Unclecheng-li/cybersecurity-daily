Google Chromium V8 类型混淆漏洞 CVE-2026-85046：沙箱内 RCE 已入 CISA KEV（9/4）

攻击者借构造 HTML 页面在 Chromium 沙箱内执行任意代码，波及 Chrome / Edge / Opera 等全部 Chromium 内核浏览器；CISA 已列入 KEV（9/4），立即更新至已修复版本

1 严重

Google Chromium V8 类型混淆 RCE（CVE-2026-85046）—— 全平台浏览器入口沦陷（KEV 9/4，在野）

KEV 9/4 · CWE-843 类型混淆 在野利用 · 影响 Chrome/Edge/Opera

Chromium V8 引擎存在 类型混淆漏洞（CVE-2026-85046），远程攻击者通过构造的 HTML 页面即可在浏览器沙箱内部执行任意代码。由于 Google Chrome、Microsoft Edge、Opera 等主流浏览器均基于 Chromium 内核，该漏洞影响面覆盖几乎所有桌面浏览器用户。CISA 已于 2026-09-04 将其纳入已知被利用漏洞（KEV）目录。

漏洞机制/攻击方式：

  • 类型：类型混淆（CWE-843），触发于 V8 引擎对对象类型的错误处理
  • 攻击方式：用户访问恶意网页即触发，攻击者在沙箱内获得代码执行，无需任何交互外的条件
  • 影响范围：所有使用 Chromium 内核的浏览器（Chrome / Edge / Opera 等）；面向公众的 Web 是首要攻击面
  • 后果：会话接管、凭据窃取、后续载荷投递与横向移动

值得关注的原因：

  • 浏览器是绝大多数网络攻击的第一入口，沙箱逃逸类漏洞在野 = 用户无感知被控
  • 已入 CISA KEV，说明存在真实在野利用，拖延更新即持续暴露
  • 波及面极广（全平台 Chromium 系），企业终端与个人用户均需优先处置

2 高危

Starlette HTTP 请求/响应走私（CVE-2026-48710，KEV 9/2）—— 认证绕过

KEV 9/2 · CWE-444 可链 CVE-2026-42271

Starlette 存在 HTTP 请求/响应走私漏洞（CVE-2026-48710），攻击者可向 host 部分注入路径并前置到真实路径之前，当认证依赖重建 URL 的路径时导致认证绕过；官方指出可与 CVE-2026-42271 链式利用。

Starlette 是 FastAPI 等大量 Python Web 框架的底层依赖，走私 + 认证绕过意味着众多 API 服务在不知情下处于可绕过鉴权状态，需升级 Starlette 并复核反向代理配置。

3 严重

PaperCut NG/MF 链式 RCE（CVE-2026-81578 + CVE-2026-82078，KEV 8/31）—— 未授权 RCE

KEV 8/31 · CWE-306/470 双漏洞链式利用

PaperCut NG/MF 同时存在关键功能缺失认证（CVE-2026-81578）与不安全反射（CVE-2026-82078）：未授权攻击者可修改系统配置，并操纵参数在 PaperCut 服务进程安全上下文下执行应用 classpath 上的任意 Java 字节码。两漏洞可组合实现未授权远程代码执行。

打印管理服务器位于内网高信任区且常被忽视维护，未授权 RCE 即内网支点，已被 CISA 列入 KEV，需立即升级并排查异常配置改动。

4 高危

Gitea 代码注入（CVE-2026-60004，KEV 8/25）—— 自托管代码平台沦陷

KEV 8/25 · CWE-94 写权限即可触发

Gitea 存在 代码注入漏洞（CVE-2026-60004），拥有仓库写权限的攻击者可通过向 diffpatch API 端点发送恶意 patch，植入可执行的 Git hook，并以 Gitea 服务账户身份执行 shell 命令。

自托管代码平台是供应链核心环节，一旦被控即可篡改源码、注入后门、窃取 CI/CD 凭据；写权限门槛低，建议升级并收紧仓库写权限与 Webhook 配置。

5 高危

Linux 内核 IPv6 提权（CVE-2026-53362，KEV 8/27）—— 多发行版受影响

KEV 8/27 · CWE-269 影响 Suse/Red Hat 等

Linux 内核 IPv6 网络子系统存在权限提升漏洞（CVE-2026-53362），可借以提权；影响 Suse、Red Hat 及众多使用 Linux 的下游产品。

内核提权是容器逃逸与持久化的基础一步，波及面广（多发行版/云镜像），需及时跟进各发行版内核补丁，优先修复暴露面较大的主机。

速览区

6. Citrix NetScaler ADC/Gateway 越界（CVE-2026-8452，KEV 8/26）

内存边界操作不当可致拒绝服务，边界设备可用性受损，建议及时更新固件并收敛管理面。

7. ownCloud 不当认证（CVE-2023-49105，KEV 8/27）

已知受害者用户名且无签名密钥时，攻击者可未授权访问、修改或删除任意文件，云盘数据直接暴露。

8. Microsoft SQL Server RCE（CVE-2019-1068，KEV 8/26）

可在数据库引擎服务账户上下文执行代码，老旧实例风险尤高，建议评估并加固。

9. JFrog Artifactory 路径限制不当（CVE-2026-66384，KEV 8/27）

认证用户可越界写入预期 Docker 缓存路径之外，存在供应链投毒隐患，需收紧仓库权限。

10. Red Hat libuser/ABRT 本地提权（CVE-2015-3246/5287，KEV 8/26）

借竞态/符号链接攻击提权，相关产品可能已 EoL/EoS，建议迁移至受支持版本。

11. Ajax.NET Professional 反序列化（CVE-2021-23758，KEV 8/26）

经任意 .NET 类反序列化可致 RCE，产品可能已停服，建议停用并迁移。
