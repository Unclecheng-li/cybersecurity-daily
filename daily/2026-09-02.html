JFrog Artifactory 认证绕过在野利用（CVE-2026-82329，CVSS 9.8）—— 软件供应链核心被直击

CVSS 9.8 · CWE-287 认证绕过 在野利用 · 8/28 补丁

JFrog Artifactory 存在一个严重的认证绕过缺陷，在默认配置下，未认证、仅需网络可达的攻击者即可获取管理员权限。JFrog 于 8 月 28 日发布补丁（云实例已自动更新），但 WatchTowr 随后观测到攻击者在野 mint 管理员令牌。自托管实例需升级至 7.111.21 / 7.117.28 / 7.125.20 / 7.133.29 / 7.146.38 / 7.161.20 等对应版本。

值得关注：Artifactory 管理二进制、容器、软件包与 AI 模型的生命周期，管理员权限等于可投毒整条构建流水线与生产制品；补丁与在野利用几乎零时差，说明攻击者已自动化扫描未打补丁的自托管实例。此前同类问题 CVE-2026-66384 已被纳入 CISA KEV，该资产是重点猎杀目标。

2 严重

Langflow 未授权 root RCE 在野利用（CVE-2026-0768，CVSS 9.8）—— AI低代码平台成新猎物

CVSS 9.8 · CWE-94 代码注入 在野利用 · VulnCheck

AI 低代码平台 Langflow 的自定义组件编辑器代码校验器存在缺陷，用户可控字符串在执行前未充分校验，攻击者无需认证即以 root 执行任意 Python 代码。VulnCheck 观测到用于侦察与凭据窃取的在野利用（主要来自俄罗斯，英国蜜罐 360+ 次尝试）。所有 ≤ 1.4.2 版本受影响；该缺陷经 ZDI 于 2025 年 7 月上报，2026 年 1 月作为零日披露。

未授权 root RCE 直接拿下连着模型、数据仓库与云凭据的环境；2026 年 Langflow 多漏洞（CVE-2026-0769 / CVE-2025-3248 / CVE-2026-5027）被持续狩猎，该赛道已成攻击者重点。

3 严重

Orkes/Netflix Conductor 默认无认证未授权RCE在野（CVE-2026-58138，CVSS 9.8）—— 3000+企业工作流引擎后门

CVSS 9.8/9.3 · CWE-94 在野利用(8/21) · Exploit-DB

开源工作流引擎 Conductor（Orkes 维护，据厂商称运行于 3000+ 企业，含 LinkedIn、Twilio、Quest Diagnostics）的开源构建默认不启用认证，工作流 API 暴露在公网。INLINE/LAMBDA/DO_WHILE/SWITCH 任务在 GraalVM 上下文以 HostAccess.ALL 求值（等于关闭沙箱），攻击者可经 Java 反射调用系统命令。CVE 于 6 月 30 日发布，Empirical 遥测显示 8 月 21 日起已在野利用，Exploit-DB 已有武器化代码。修复版本 3.30.2。

“你不知道自己跑着它”的 9.8：开源核心广泛内嵌，很多部署不在资产清单；工作流引擎处于系统中心，默认容器常以 root 运行，控制编排层即控制所有下游系统。

4 严重

HPE Aruba AOS-CX 一次性披露多高危漏洞（CVE-2026-73749 RCE 9.8 + CVE-2026-73777/73778 认证绕过 8.1）

9.8 / 8.1 · 网络设备 9/1 披露 · 受影响交换机

HPE 于 9 月 1 日通过安全公告 HPESBNW05134 披露 AOS-CX 交换机操作系统一批漏洞：CVE-2026-73749 为未授权 RCE（CVSS 9.8，畸形输入处理不当，可发特制网络包完全控制交换机）；CVE-2026-73777 为 API 端点授权绕过（8.1）；CVE-2026-73778 为出厂默认弱口令导致的管理员越权（8.1，仅影响仍处出厂/ZTP 状态的设备）。

交换机是内网咽喉，未授权拿下即获得横向移动与流量嗅探支点；出厂默认口令类问题说明大量设备未做初始化加固，易被批量扫描利用。

5 严重

Ash AI（Elixir）提示模板注入致 RCE（CVE-2026-77956，CVSS 10.0）—— AI工具链×服务端代码执行，PoC 已公开

CVSS 10.0 · CWE-94 公开 PoC · 无需认证

Elixir 库 ash_ai（AshAi.Actions.Prompt 经 EEx.eval_string 求值）存在代码注入，远程未认证攻击者可通过向提示模板注入恶意内容执行任意 Elixir 代码。公开 PoC 已可用，无需认证、可经公网触发。任何把用户可控输入喂给 ash_ai 的应用面临整机沦陷。

提示注入不再只是“骗模型说话”，而是直接变成 RCE；满分 + 公开 PoC + 无认证，武器化门槛极低，暴露公网的 AI 端点立即承压。

速览区

6. GitHub Enterprise Server CVE-2026-18730 未授权 SSRF 暴露 Bearer Token

GHES 3.17.0–3.21.4 的未认证 Manage API 端点可被 SSRF 滥用，发出到攻击者 controlled 主机的请求，泄露可重放 gateway-to-agent bearer token。

7. Dell PowerStore CVE-2026-58574（CVSS 9.8）管理接口缺失认证

受限管理接口缺认证，网络可达的未认证攻击者可读取文件系统内部信息（配置、凭据、架构），为后续攻击铺路，需联系 Dell 获取补丁指导。

8. Google Cloud Build CVE-2026-19410（CVSS 9.4）授权绕过执行未审查代码

GitHub 触发器 comment control 不正确授权，远程攻击者可压制 webhook 通知、在构建环境执行未审查代码，绕过 CI/CD 代码审查闸门，构成供应链攻击；平台侧已于 6/24 修复。

9. CISA KEV 新增 TrueConf Server 双漏洞在野（CVE-2026-72529/72530），9/3 大限

自托管视频会议平台两漏洞被 Head Mare 自 7 月起利用替换客户端安装包投放后门；CISA 要求 FCEB 机构于 9 月 3 日前修复。

10. Aurora 勒索软件驱使 Cursor AI 实施手动作案（10+ 目标）

affiliates 通过告诉 Cursor “这是授权渗透测试”让其协助 NTLM 中继、Certipy 证书攻击，覆盖比利时、德国、苏格兰等多国至少 10 个目标。

11. Anthropic Claude 会话遭 infostealer 劫持 + Datadog 捕获 AWS root 密码喷射

Vidar/LummaC2/StealC 等窃密木马劫持 Claude 会话 Cookie 绕过认证；Datadog 观测到 7/24–8/23 针对 150+ 组织 AWS root 账户的月级密码喷射（无成功登录）。
