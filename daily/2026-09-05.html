Ivanti Connect Secure 预认证 RCE 双零日链 CVE-2026-8850(9.8)+8851：未授权 RCE 在野

CVE-2026-8850(9.8) 预认证 RCE 拿 root + CVE-2026-8851(8.2) 提权持久化 → 未授权 RCE；已入 CISA KEV(9/4)，影响 22.x/23.x，立即升级 + 隔离管理面 + 重置凭据

1 严重

Ivanti Connect Secure 预认证 RCE 双零日链 → 未授权 RCE 在野（CVE-2026-8850 CVSS 9.8 + CVE-2026-8851 CVSS 8.2）

CVSS 9.8/8.2 · CWE-94/269 在野利用 · KEV 9/4

Ivanti Connect Secure（原 Pulse Connect Secure）的 Web 管理面存在 预认证 RCE（CVE-2026-8850，9.8），攻击者无需任何凭据即可触发并拿到设备 root shell；权限提升（CVE-2026-8851，8.2）用于稳定化与持久化。两者组合即实现全程未授权远程代码执行。Ivanti 已确认在野利用，并纳入 CISA KEV（9/4 加入，FCEB 限 9/11 前修复）。受影响 22.x / 23.x 部分版本需立即升级、隔离管理面、重置全部凭据并排查 IOC。目前暂无公开 PoC，但已在野。

漏洞机制/攻击方式：

  • 类型：预认证 RCE（CWE-94）+ 权限提升/持久化（CWE-269）链式利用
  • 攻击方式：匿名请求直击 Web 管理面触发 RCE 拿 root，再以 8851 做持久化与凭据重置
  • 影响范围：Ivanti Connect Secure 22.x / 23.x 部分版本；暴露公网的 VPN / 远程访问网关
  • 后果：设备完全沦陷，成为内网横向移动与持久化支点

值得关注的原因：

  • 满分预认证 RCE 即"边界设备拿下 = 内网支点"，教科书级入口
  • 已入 KEV 且确认在野，仅打补丁不够，必须重镜像 + 重置凭据
  • 与 SonicWall 同属 9 月边界设备集中猎杀，Scattered Spider 已借其攻医疗/关基

2 高危

GitLab 路径遍历 → RCE（CVE-2026-7822，CVSS 9.6）—— 自托管代码平台沦陷

CVSS 9.6 · CWE-22/73 9/4 披露 · 17.11/18.1 修复

GitLab CE/EE 的导入 / 附件处理路径存在 路径遍历（CVE-2026-7822，9.6），未授权攻击者可写至任意路径并最终实现 RCE。修复版本：17.11.x / 18.1.x 等。自托管实例尤其危险——源码、CI/CD 变量、部署密钥一次性全暴露，且补丁节奏常被忽视，是供应链投毒的天然跳板。

路径遍历→RCE 利用链路成熟，灰黑产已有现成打法；拥有项目导入权限的认证用户或匿名面均可触发。自托管实例应视作准生产资产，尽快升级并收紧导入功能。

3 严重

Atlassian Confluence 未授权 RCE（CVE-2026-7990，CVSS 9.8）—— 企业知识库沦陷

CVSS 9.8 · CWE-94 9/4 紧急补丁

Confluence 的宏 / 模板渲染存在 未授权 RCE（CVE-2026-7990，9.8），攻击者可借匿名访问直接执行代码。Atlassian 已发布紧急补丁。

未授权 + 满分，无需账户即可拿 shell；知识库服务器通常信任度高，是横向移动的优质支点。同类产品历史上一经披露即被大规模扫描，暴露实例应优先处置。

4 高危

PyPI 供应链新投毒 "pyyaml-ng" / "reqs-helper" 簇 —— 窃取 CI 令牌

供应链 · 依赖混淆 9/4 下架 · 延续 OpenClaw

恶意包伪装成常用依赖（PyYAML / YAML 解析、requests 辅助），安装即运行 post-install 脚本，窃取 CI 令牌（GITHUB_TOKEN、云凭据）并回传 C2。已确认命中多个开源项目 CI 流水线，PyPI 已下架相关包。

依赖混淆 + typosquatting 双管齐下，CI 自动拉取即中招；窃的是高权限 CI 令牌，等于拿到仓库与云账户的"万能钥匙"，与 8 月 OpenClaw 事件同源。

5 高危

Palo Alto PAN-OS GlobalProtect 命令注入（CVE-2026-8142，CVSS 9.1）—— 防火墙管理面 RCE

CVSS 9.1 · CWE-78 9/4 修复

GlobalProtect 网关管理接口存在 命令注入（CVE-2026-8142，9.1），认证后（或配合弱口令 / 前置漏洞）可 RCE。PAN 已发布修复。

防火墙是网络边界的"总闸"，管理面被控即失去整张网络的信任根；与 Ivanti / SonicWall 同属"边界设备周"，攻击面高度重合，需优先于一般资产处置并收敛管理面可达性。

速览区

6. FortiManager 未授权 RCE（CVE-2026-7741，9.8，KEV 9/4）

集中管理平台单点沦陷即全网设备配置泄露，作为 FortiGate 的"控制面"尤为危险，建议立即升级并隔离管理通道。

7. Scattered Spider 借 Ivanti 零日攻医疗 / 关基

该团伙被指利用 Ivanti 8850 链入侵多家医疗与地方政府机构，部署勒索并窃取患者数据，与头条事件同源。

8. 大型零售商约 4000 万记录泄露

第三方供应商 API 缺陷致客户数据外泄，涉及姓名 / 邮箱 / 支付令牌，涉事方已启动通知与监测。

9. Ollama 远程模型窃取（CVE-2026-7133，8.8）

暴露的 Ollama API 可被 SSRF / 模型拉取，窃取私有模型权重与推理配置，AI 资产首次成为明确猎物。

10. TP-Link 路由器 0day（CVE-2026-6902，9.0）

多款家用 / SOHO 路由器未授权 RCE，僵尸网络已开始扫描利用，建议更新固件或隔离管理口。

11. F5 BIG-IP iControl REST 未授权 RCE（CVE-2026-6610，9.8）

管理面 RCE，与历史 CVE-2022-1388 同类，暴露实例应优先收敛管理面可达性。
